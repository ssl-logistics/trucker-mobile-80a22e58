# หน้าสรุปยอดเงิน: แสดงยอด COD ทุกงาน ทุกจุด

## สิ่งที่ผู้ใช้จะเห็น
- หน้าแสดงทุกงานที่มี COD ทั้งงานที่ยังไม่ปิดและปิดแล้ว (ที่ยังไม่ได้เคลียร์)
- ด้านบนมีสรุปรวม 3 ช่อง: ต้องเก็บทั้งหมด / เก็บแล้ว / ค้างเก็บ
- การ์ดแต่ละงาน:
  - เลขออเดอร์ + ป้ายสถานะงาน "กำลังวิ่ง" หรือ "ปิดงานแล้ว"
  - 3 ตัวเลข: ต้องเก็บ ฿x · เก็บแล้ว ฿x · ค้าง ฿x (ค้างเป็นสีแดงเมื่อมากกว่า 0)
  - รายการจุดส่ง: ชื่อจุด, ยอด, วิธีจ่าย (เงินสด/QR), สถานะ "เก็บแล้ว" (เขียว) หรือ "ยังไม่เก็บ" (เทา)
  - ป้ายสถานะเคลียร์: "พร้อมเคลียร์" (เก็บครบ + ปิดงานแล้ว) หรือ "ยังเคลียร์ไม่ได้" พร้อมเหตุผล (ยังเก็บไม่ครบ / งานยังไม่ปิด)
  - ปุ่มเคลียร์เป็นไอคอน (กระเป๋าเงิน) มุมขวาของการ์ด กดได้เฉพาะเมื่อพร้อมเคลียร์ ไม่พร้อมจะเป็นสีเทากดไม่ได้
- กดไอคอนแล้วเปิดหน้าต่างเคลียร์ยอดแบบเดิม (แนบสลิป, อ่านยอด, ยอดต้องตรงถึงกดยืนยันได้)
- กล่อง "วิธีเคลียร์ยอด" เปลี่ยนข้อ 2 เป็น "เมื่อเก็บครบและปิดงานแล้ว กดไอคอนเคลียร์ที่งาน"
- หัวหน้าใช้ชื่อ "สรุปยอดเงิน" ให้ตรงกับเมนู
- ไม่มีงาน COD: แสดง "ไม่มียอด COD"
- จำนวนบนเมนูหน้าแรกยังนับเฉพาะงานที่ปิดแล้วและพร้อมเคลียร์เหมือนเดิม
- รองรับ 4 ภาษา

## Technical
- ข้อมูลยอดต่อจุด: `cod-clear-proxy` GET คืน `expected_total`, `order_status`, `points[] {name, amount, payment_method, sequence_number}` (ตรวจแล้วทั้งงานปิดและงานกำลังวิ่ง)
- รายการออเดอร์: รวมจาก check-ins COD 30 วัน (เดิม) + งานปัจจุบันที่ `jobHasCod` (ใช้ข้อมูลเดียวกับหน้างานปัจจุบัน) แล้ว dedupe
- "เก็บแล้ว" ต่อจุด: มี delivery check-in ของออเดอร์นั้นที่ตรงจุด (sequence หรือ destination_id; จุดเดียวใช้ check-in ใดก็ได้) และเป็น COD (`isCodCheckin`) หรือมี delivery confirmed; ยอดเก็บแล้ว = ผลรวม amount ของจุดที่เก็บแล้ว
- `src/lib/codClear.ts`: `summarizeCod(record, checkins)` → `{ total, collected, outstanding, points[], closed, canClear, reason }`; `canClear = closed && outstanding === 0 && status === 'pending'`; รายการที่ `status === 'cleared'` ไม่แสดง
- เทสต์: เก็บไม่ครบ → เคลียร์ไม่ได้, งานยังไม่ปิดแต่เก็บครบ → เคลียร์ไม่ได้, ครบ + ปิด → เคลียร์ได้, ยอดรวม/ค้างถูกต้อง (500+700, เก็บ 500 → ค้าง 700)
- `src/hooks/usePendingCodClears.ts`: คืน `all` (ทุกงาน) และ `items` (พร้อมเคลียร์ สำหรับตัวเลขเมนู)
- `src/pages/CodClearPage.tsx`: UI ใหม่ตามข้างบน, `ClearDialog` เดิมเปิดจากไอคอน
