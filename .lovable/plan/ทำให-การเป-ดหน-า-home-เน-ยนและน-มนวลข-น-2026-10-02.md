# ทำให้การเปิดหน้า Home เนียนและนุ่มนวลขึ้น

## ปัญหาปัจจุบัน
- ตอนโหลดครั้งแรก (ยังไม่มีแคช) แสดง spinner กลางจอ แล้วการ์ดงาน "เด้ง" ขึ้นมาทีเดียว ทำให้รู้สึกกระตุก
- รูปโปรไฟล์ (avatar) บนหัวหน้าโหลดช้า — ต้องรอขอ presigned URL ทุกครั้ง ทำให้รูปค่อยๆ ปรากฏทีหลัง
- ตอนรีเฟรชเบื้องหลัง รายการงานอาจกระพริบ/เปลี่ยนตำแหน่งเมื่อข้อมูลใหม่เข้ามา

## สิ่งที่จะทำ (แก้เฉพาะ UI/การแสดงผล ไม่แตะตรรกะการดึงข้อมูล)

### 1. Skeleton การ์ดงานแทน spinner (src/pages/Home.tsx)
- เปลี่ยนตอนโหลดครั้งแรกจาก spinner "กำลังโหลด..." เป็น skeleton การ์ดงาน 3 ใบ หน้าตาใกล้เคียง JobCard จริง (แถบหัว, บรรทัดเส้นทาง, ปุ่ม) พร้อม animate-pulse
- ผล: ผู้ใช้เห็นโครงหน้าจอทันที เมื่อข้อมูลมา การ์ดจริงแทนที่ skeleton ตำแหน่งเดิม ไม่มีการ "เด้ง"

### 2. จำ URL รูปโปรไฟล์ไว้ใน localStorage (src/components/layout/AppHeader.tsx)
- หลังขอ presigned URL สำเร็จ เก็บลง localStorage (คีย์ตาม driver id)
- เปิดหน้าครั้งถัดไปแสดงรูปจาก URL ที่จำไว้ทันที แล้วค่อยอัปเดตเมื่อได้ URL ใหม่
- ถ้า URL เก่าหมดอายุ (รูปโหลดไม่ได้) ให้ fallback เป็น initials เหมือนเดิม

### 3. ลดการกระพริบตอนรีเฟรชเบื้องหลัง (src/pages/Home.tsx)
- ตอน silent refresh ไม่แตะ state การโหลด (ทำอยู่แล้ว) และเพิ่มการเปรียบเทียบข้อมูลก่อน setState: ถ้ารายการงานใหม่เหมือนเดิม (เทียบจาก id + สถานะ) ไม่ต้อง setState ใหม่ ลด re-render ที่ไม่จำเป็น

## ไฟล์ที่แก้
- `src/pages/Home.tsx` — skeleton ตอนโหลด + กัน re-render ซ้ำ
- `src/components/layout/AppHeader.tsx` — แคช URL รูปโปรไฟล์
