# เลื่อนหัวเรื่องหน้ารายละเอียดงานลง 14px

## สาเหตุที่หัวเรื่องชิดขอบบน

บรรทัด CSS รวมใน `src/index.css` (บรรทัด 284) ตั้งค่าด้านบนของหัวเรื่องทุกหน้าไว้เป็นช่องปลอดภัยของรอยแฉะเท่านั้น:

```css
.app-sticky-header {
  padding-top: env(safe-area-inset-top, 0px);
}
```

บรรทัดนี้อยู่นอก layer จึงชนะคลาส `py-3` ของหัวเรื่องหน้ารายละเอียดงาน ผลคือระยะด้านบนจริง = 0px บนจอที่ไม่มีรอยแฉะ (ตรวจด้วยการวัดค่าที่แสดงผลจริงใน preview: `paddingTop: 0px`, `paddingBottom: 12px`)

## สิ่งที่จะทำ (เฉพาะหน้ารายละเอียดงาน)

1. `src/components/job-detail/DomesticJobDetail.tsx` บรรทัด 1280 — เพิ่ม `style` ที่ตัว `<header>` เพื่อกำหนดระยะด้านบนขั้นต่ำ 14px โดยยังเคารพรอยแฉะของเครื่องที่มีรอยแฉะ:

```tsx
<header
  className="app-sticky-header text-white px-4 py-3 bg-[#dbedff]"
  style={{ paddingTop: "max(env(safe-area-inset-top, 0px), 14px)" }}
>
```

2. `src/components/job-detail/JobDetailLoadingState.tsx` — ใส่ระยะเดียวกันให้หัวเรื่องจำลองตอนโหลด เพื่อหัวเรื่องไม่กระโดดตำแหน่งตอนข้อมูลขึ้นมาแสดง

## ผลที่คาดว่าจะเห็น

ชื่องาน (เช่น OR20260820184) + ป้าย "ขนส่งภายในประเทศ" จะลอยลงจากขอบบน 14px แทนที่จะชิดขอบ ส่วนความสูงด้านล่างและสีพื้นหลังคงเดิม

## หมายเหตุทางเทคนิค

- ใช้ `style` ประจำตัวElement เพราะคลาส Tailwind (`pt-*`) จะแพ้กฎใน `src/index.css` ที่อยู่นอก layer — ใส่เป็นคลาสแล้วไม่ได้ผล
- หน้าอื่น (Home, Dashboard, ประวัติงาน, ค่าใช้จ่าย, โปรไฟล์ ฯลฯ) ไม่แตะ ตามที่เลือกไว้
- `JobDetailLoadingState.tsx` ใช้ร่วมกันกับหน้ารายละเอียดงานประมูลด้วย ดังนั้นโครงหัวเรื่องจำลองของหน้านั้นจะเลื่อนตามแค่ช่วงที่กำลังโหลด ส่วนหัวเรื่องจริงของหน้าประมูลไม่เปลี่ยน
- ตรวจผล: อ่าน `/tmp/observability/build-errors.log` ว่า build ผ่าน + วัดค่าที่แสดงผลจริงของหัวเรื่องใน preview ว่าได้ 14px
