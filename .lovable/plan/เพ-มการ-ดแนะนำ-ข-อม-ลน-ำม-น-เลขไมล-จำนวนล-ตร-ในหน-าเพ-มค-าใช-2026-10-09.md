# เพิ่มการ์ดแนะนำ "ข้อมูลน้ำมัน" (เลขไมล์/จำนวนลิตร) ในหน้าเพิ่มค่าใช้จ่าย

## สิ่งที่จะทำ (frontend เท่านั้น ไม่แตะ flow เดิม)

ไฟล์: `src/pages/AddExpensePage.tsx`, `src/contexts/LanguageContext.tsx`

1. **การ์ดแนะนำส่วนข้อมูลน้ำมัน** — ส่วน "ข้อมูลน้ำมัน" (เลขไมล์ + จำนวนลิตร) แสดงเฉพาะค่าใช้จ่ายประเภทน้ำมัน เมื่อส่วนนี้แสดงครั้งแรก จะมีกรอบสีส้มครอบส่วนนี้ พร้อมการ์ดอธิบาย:
   - หัวข้อ: "ข้อมูลน้ำมัน (ไม่บังคับ)"
   - คำอธิบาย: "กรอกเลขไมล์และจำนวนลิตรได้ถ้าต้องการ ไม่กรอกก็บันทึกได้ตามปกติ"
   - ปุ่ม "รับทราบ"
2. **เงื่อนไขการแสดง** (เหมือนการ์ดเมนูอื่น):
   - production: แสดงครั้งเดียวต่อบัญชี เก็บ localStorage key `fuel_details_intro_ack:<driverId>`
   - preview (hostname มี `id-preview--`): แสดงทุกครั้งเพื่อทดสอบ
   - แสดงเฉพาะเมื่อมีรายการค่าใช้จ่ายประเภทน้ำมัน (ส่วนข้อมูลน้ำมันแสดงอยู่จริง)
   - กด "รับทราบ" หรือเริ่มกรอกช่องเลขไมล์/ลิตร = นับว่ารับทราบ การ์ดหายไป
3. **ขนาดการ์ด** — กว้างคงที่ `w-64 max-w-[calc(100vw-2rem)]` ใต้ส่วนข้อมูลน้ำมัน ไม่บีบตามความกว้างช่อง
4. **ข้อความ 4 ภาษา** (ไทย/อังกฤษ/เกาหลี/จีน) เพิ่ม keys `expense.fuel_intro_title/desc/ack` ใน LanguageContext

## ตรวจสอบ
- `npx tsgo --noEmit -p tsconfig.app.json` ผ่าน + build OK
- เปิดหน้าเพิ่มค่าใช้จ่ายประเภทน้ำมันใน preview (จอ 393px) ยืนยันการ์ดแสดงถูกตำแหน่ง ไม่ล้นขอบจอ
