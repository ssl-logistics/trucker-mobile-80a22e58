# เปลี่ยนไอคอนธงไทย + ซ่อนปุ่ม debug บนมือถือ

## 1. เปลี่ยนไอคอนภาษาไทยเป็นรูปที่ส่งมาให้

- รูปที่ผู้ใช้ส่งมา (ธงไทยวงกลม 612x612) จะแปลงเป็น PNG ขนาดพอเหมาะ (~256x256 ลดขนาดไฟล์) แล้วแทนไฟล์เดิม `src/assets/flag-th.png`
- ไม่ต้องแก้โค้ดเพิ่ม เพราะ 3 จุดที่ใช้ธงไทย import ไฟล์เดียวกันหมด จะเปลี่ยนพร้อมกันทันที:
  - หน้าเข้าสู่ระบบ (SignIn) — ตัวเลือกภาษาบนหัวหน้า
  - หน้าสมัครสมาชิก (Register)
  - หน้าตั้งค่าภาษา (LanguagePage)
- ไอคอนภาษาอื่น (อังกฤษ เกาหลี จีน) ไม่แตะต้อง

## 2. ซ่อนปุ่ม debug ลอยบนเครื่องมือถือ

- ปุ่ม debug ลอย (แสดงเฉพาะ preview Lovable) จะไม่แสดงเมื่อเปิดจากเครื่องมือถือจริง ตรวจจาก user agent (Android/iPhone/iPad ฯลฯ)
- บนเดสก์ท็อปยังแสดงเหมือนเดิม รวมถึงกรณีตัวอย่างแสดงแบบจอแคบในเครื่องเดสก์ท็อป
- ยังคงใช้ `isPreviewHost()` เป็นเงื่อนไขหลักตามกติกาเดิม ไม่เขียนตรวจ host เองในไฟล์อื่น

## ตรวจสอบ

- เปิดหน้าเข้าสู่ระบบและหน้าตั้งค่าภาษาด้วย Playwright ยืนยันธงไทยใหม่แสดงถูกต้องทุกจุด
- จำลอง user agent มือถือยืนยันปุ่ม debug ไม่แสดง และจำลองเดสก์ท็อปยืนยันยังแสดง
- ตรวจ build log ไม่มี error
