# หน้าประวัติงาน: ใช้ skeleton ตอนโหลดแบบหน้ารายละเอียดงาน

## ปัญหา
ตอนเปิดหน้าประวัติงาน (ตอนยังไม่มีแคช) ข้อความ "กำลังโหลด..." แสดงเป็นตัวอักษรเปล่า ๆ ตรงกลางจอ ไม่เหมือนหน้ารายละเอียดงานที่แสดง skeleton พร้อมหัวเรื่อง

## การแก้ไข (UI เท่านั้น)
แก้ไฟล์เดียว: `src/pages/JobHistoryPage.tsx`

- import `JobDetailLoadingState` (ตัว skeleton เดียวกับหน้ารายละเอียดงาน)
- เมื่อ `loading === true` ให้ return `<JobDetailLoadingState />` ทั้งหน้าแบบ early return ก่อน header/แท็บ/ตัวกรอง เพื่อให้หน้าจอตอนโหลดเหมือนหน้ารายละเอียดงานเป๊ะ (มี header skeleton + การ์ด skeleton)
- เมื่อโหลดเสร็จ กลับมาแสดงหน้าประวัติตามเดิมทุกอย่าง

## สิ่งที่ไม่แตะ
- ตรรกการดึงข้อมูล แคช ตัวกรอง การแบ่งหน้า — ไม่เปลี่ยน
- `jobHistory.loading` ยังอยู่ใน i18n ตามเดิม (ไม่ใช้แล้วในหน้านี้ แต่ไม่ลบออกจากภาษา)

## ตรวจสอบ
- `bunx tsgo --noEmit` และ build ผ่าน
- เปิดหน้าประวัติงาน (ไม่มีแคช) ต้องเห็น skeleton เหมือนหน้ารายละเอียดงาน
