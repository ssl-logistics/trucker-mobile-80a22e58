# แก้ UI การ์ดแนะนำเมนู "เอกสาร" ที่เพี้ยน

## ปัญหา
การ์ดแนะนำเมนูใหม่ "เอกสาร" ใน `JobActionButtons.tsx` ใช้ `absolute left-0 right-0` ภายใต้ wrapper ของปุ่มใน grid 4 ช่อง ทำให้การ์ดกว้างเท่าช่องปุ่ม (~80px) ข้อความตกบรรทัดทีละคำ การ์ดยาวผิดปกติและทับเนื้อหาหน้างาน

## การแก้ไข (frontend เท่านั้น ไม่แตะ flow เดิม)

ไฟล์: `src/components/job/JobActionButtons.tsx`

1. **ปรับความกว้างการ์ด** — เปลี่ยนจาก `left-0 right-0` เป็นความกว้างคงที่ที่อ่านได้ เช่น `w-64 max-w-[calc(100vw-2rem)]` จัดกึ่งกลางใต้ปุ่มด้วย `left-1/2 -translate-x-1/2`
2. **ลูกศรชี้ปุ่ม** — คงลูกศรไว้กึ่งกลางการ์ด (ชี้ปุ่มเอกสาร) เหมือนเดิม
3. **กันล้นขอบจอ** — ใช้ max-w ตาม viewport เพื่อไม่ให้ล้นบนจอแคบ
4. คงพฤติกรรมเดิมทั้งหมด: แสดงครั้งเดียวต่อบัญชี (production), แสดงทุกครั้งใน preview, กด "รับทราบ" หรือกดปุ่มเอกสาร = รับทราบ, ข้อความ 4 ภาษาเหมือนเดิม

## ตรวจสอบ
- `npx tsgo --noEmit -p tsconfig.app.json` ผ่าน
- เปิดหน้างานใน preview (จอมือถือ 393px) ยืนยันการ์ดกว้างพออ่าน ไม่ตกบรรทัดทีละคำ ไม่ล้นขอบจอ
