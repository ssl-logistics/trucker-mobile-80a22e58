# แสดงการ์ดแนะนำเมนู "แจ้งซ่อม" ในหน้าตั้งค่า (preview แจ้งทุกครั้ง / production ครั้งเดียว)

## สิ่งที่จะทำ
- เข้าหน้าตั้งค่าครั้งแรก: จอมืดจางรอบ ๆ แถวเมนู **แจ้งซ่อม** ถูกไฮไลต์ด้วยกรอบสีส้ม (ครอบเมนู) และเลื่อนจอให้เห็นเมนูนี้
- ใต้/เหนือเมนูมีการ์ดข้อความ: "เมนูใหม่! แจ้งซ่อมรถ — แจ้งปัญหารถพร้อมรูป/คลิปและตำแหน่งได้ที่นี่" + ปุ่ม **รับทราบ**
- ข้อความเปลี่ยนตามภาษาแอปปัจจุบัน (ไทย/อังกฤษ/เกาหลี/จีน)
- กด **รับทราบ** → การ์ดหาย และบันทึกว่าบัญชีนี้ (ตาม user id คนขับ) รับทราบแล้ว
- กดเมนูแจ้งซ่อมตอนการ์ดแสดงอยู่ = นับว่ารับทราบ แล้วเปิดหน้าแจ้งซ่อมตามปกติ

## เงื่อนไขการแสดง (ตามที่ขอเพิ่ม)
- **หน้า preview** (URL ที่มี `id-preview--`): แสดงการ์ดใหม่ทุกครั้งที่เข้าหน้าตั้งค่า แม้กดรับทราบแล้ว — เพื่อให้ทดสอบได้ซ้ำ ๆ
- **production จริง** (โดเมนจริง/URL ที่เผยแพร่): แสดงครั้งเดียวต่อบัญชี — กดรับทราบแล้วเข้าระบบครั้งต่อไปไม่แจ้งอีก; บัญชีใหม่ที่ยังไม่เคยกดจะเห็นการ์ดนี้

## รายละเอียดทางเทคนิค
- แก้ `src/pages/SettingsPage.tsx`: ref ที่แถวแจ้งซ่อม, overlay + ring ไฮไลต์ + การ์ด tooltip
- เก็บสถานะใน localStorage key `repair_menu_intro_ack:<driverId>` (driverId จาก `user.id` / `auth_driver_id`) — ไม่ลบตอนออกจากระบบ จึงไม่แจ้งซ้ำกับบัญชีเดิม
- ตรวจสภาพแวดล้อมจาก `window.location.hostname.includes('id-preview--')` → ถ้าเป็น preview ข้ามการเช็คสถานะรับทราบ (แสดงทุกครั้ง); production เช็คตามปกติ
- เพิ่มคำแปล `settings.repair_intro_title`, `settings.repair_intro_desc`, `settings.repair_intro_ack` 4 ภาษาใน `LanguageContext.tsx`
- ไม่แตะตรรกะเมนูหรือหน้าอื่น; ตรวจ tsgo + build
