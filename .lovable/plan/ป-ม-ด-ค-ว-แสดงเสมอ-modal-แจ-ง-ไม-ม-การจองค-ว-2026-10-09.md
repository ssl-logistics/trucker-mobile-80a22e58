# ปุ่ม "ดูคิว" แสดงเสมอ + Modal แจ้ง "ไม่มีการจองคิว"

## สิ่งที่ต้องแก้

### 1. ปุ่มดูคิวแสดงเสมอ (src/pages/CurrentJobsPage.tsx)
- ตอนนี้ปุ่มดูคิวแสดงเฉพาะงานที่ `getQueueInfo(job)` ไม่ null (มีข้อมูลคิว/จองคิวเท่านั้น)
- แก้ให้แสดงปุ่มดูคิว **ทุกการ์ดงาน** เสมอ (ลบเงื่อนไข `queueInfo &&` ออกจากการเรนเดอร์ปุ่ม)
- เมื่อกดปุ่ม:
  - งานที่มีข้อมูลคิว/จองคิว → ส่งข้อมูลคิวเดิม (myQueue, currentQueue, ...)
  - งานที่ **ไม่มี** การจองคิว → ส่ง `{ orderNumber: job.order_number }` ให้ dialog ไปดึงข้อมูลสดเอง
- การ์ดแนะนำเมนูใหม่ (ring ส้ม + ปุ่มรับทราบ) ยังทำงานเหมือนเดิม: ไฮไลต์งานแรกที่มีข้อมูลคิวจริงเท่านั้น

### 2. Modal แสดง "ไม่มีการจองคิว" (src/components/job/JobQueueDialog.tsx)
- Dialog รับ `orderNumber` แล้วดึงข้อมูลจาก `get-qtruck-queue` เหมือนเดิม
- เมื่อ API ตอบกลับว่าไม่มีคิว (ไม่สำเร็จ/ไม่มีข้อมูล) → แสดงข้อความใหม่ **"ไม่มีการจองคิว"** พรไอคอนแทนข้อความเดิม "ยังไม่มีข้อมูลคิว"
- เปลี่ยนข้อความที่ state `notFound` ให้ใช้ key ใหม่ `currentJobs.queueNoBooking`

### 3. เพิ่มคำแปล 4 ภาษา (src/contexts/LanguageContext.tsx)
เพิ่ม key `currentJobs.queueNoBooking` ใกล้กับ key queue เดิม ครบ 4 ภาษา:
- ไทย: 'ไม่มีการจองคิว'
- อังกฤษ: 'No queue booking'
- เกาหลี: '대기열 예약이 없습니다'
- จีน: '暂无排队预约'

## ไม่แตะ
- Flow เดิมทั้งหมด (เช็คอิน/SOP/POD/QTruck webhook) คงเดิม
- Edge function `get-qtruck-queue` ไม่แก้ — ใช้ข้อมูลสดจากเดิม
- การแสดงผลข้อมูลคิวจริงใน modal คงเดิมทุกอย่าง

## ตรวจสอบ
- `npx tsgo --noEmit` + build ผ่าน
- ทดสอบในแอป: ปุ่มดูคิวเห็นทุกการ์ด, งานไม่มีจองคิวเปิด modal ขึ้น "ไม่มีการจองคิว" ตามภาษาที่ตั้ง
