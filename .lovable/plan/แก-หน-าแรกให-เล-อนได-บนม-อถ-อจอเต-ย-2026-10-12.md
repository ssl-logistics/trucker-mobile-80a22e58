# แก้หน้าแรกให้เลื่อนได้บนมือถือจอเตี้ย

## สาเหตุที่ตรวจพบ

หน้าเข้าสู่ระบบกำหนดความสูงเท่าหน้าจอและซ่อนเนื้อหาที่เกินทั้งหน้าหลัก กล่องฟอร์ม และตัวฟอร์ม เมื่อความสูงมือถือไม่พอ ส่วนเปลี่ยนภาษาด้านล่างจึงถูกตัดและไม่สามารถเลื่อนลงไปหาได้

## สิ่งที่จะทำ

1. ปรับหน้าเข้าสู่ระบบให้ใช้ความสูงขั้นต่ำตามพื้นที่หน้าจอจริง และยอมให้เลื่อนแนวตั้งเฉพาะเมื่อเนื้อหาสูงกว่าจอ
2. เอาการซ่อนส่วนเกินออกจากกล่องฟอร์มและตัวฟอร์ม เพื่อให้เมนูภาษาอยู่ต่อท้ายเนื้อหาและเลื่อนถึงได้
3. คงหน้าตาเดิมบนมือถือที่มีความสูงเพียงพอ รวมถึงภาพด้านบน ตำแหน่งฟอร์ม ปุ่ม และระยะขอบปลอดภัย
4. ตรวจบนขนาดมือถือปัจจุบันและมือถือความสูงสั้น ว่าสามารถเลื่อนถึงตัวเลือกภาษาและกดเปลี่ยนภาษาได้

## ขอบเขต

- แก้เฉพาะหน้าเข้าสู่ระบบและการเลื่อนบนมือถือ
- ไม่เปลี่ยนขั้นตอนเข้าสู่ระบบ ข้อมูล ภาษา หรือ API
