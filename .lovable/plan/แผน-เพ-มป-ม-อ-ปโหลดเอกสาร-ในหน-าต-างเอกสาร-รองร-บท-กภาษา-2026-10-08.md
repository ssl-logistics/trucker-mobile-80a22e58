# แผน: เพิ่มปุ่ม "อัปโหลดเอกสาร" ในหน้าต่างเอกสาร + รองรับทุกภาษา

## ปัญหาตอนนี้

- หน้าต่าง "เอกสาร" (JobDocumentsSheet) เมื่อเลือกไฟล์/ถ่ายรูปแล้ว ระบบส่งไฟล์เข้า API ทันที ไม่มีขั้นตอนให้ตรวจดูไฟล์และกดยืนยัน
- ผู้ใช้ต้องการ: กรอกหัวข้อ/รายละเอียด → เลือกไฟล์ → เห็นรายการไฟล์ที่เลือก → กดปุ่ม "อัปโหลด" เพื่อส่ง

## สิ่งที่จะทำ (frontend อย่างเดียว)

### 1. `src/components/job/JobDocumentsSheet.tsx`

- เพิ่ม state `pendingFiles` เก็บไฟล์ที่เลือกไว้ (ยังไม่ส่ง) — เลือกได้หลายครั้ง สะสมในลิสต์เดียว
- เลือกไฟล์/ถ่ายรูปเสร็จ → เพิ่มเข้าลิสต์รอส่ง แสดงชื่อไฟล์ + ปุ่มลบ (กากบาท) แต่ละรายการ
- แสดงปุ่ม **"อัปโหลดเอกสาร"** เมื่อมีไฟล์รอส่งอย่างน้อย 1 ไฟล์:
  - ปุ่มกดไม่ได้ถ้ายังไม่กรอกหัวข้อ หรือกำลังอัปโหลดอยู่
  - กดแล้วค่อยแปลง base64 + เรียก `uploadDriverDocument` (โค้ดส่งเดิม ไม่เปลี่ยน payload)
  - สำเร็จ → ย้ายไฟล์ไปลิสต์ "แนบแล้ว", ล้างลิสต์รอส่ง, toast สำเร็จ
  - ล้มเหลว → toast ผิดพลาด ไฟล์ยังอยู่ในลิสต์รอส่งให้กดใหม่ได้
- ระหว่างอัปโหลดแสดง spinner บนปุ่ม และล็อกช่องกรอก/ปุ่มแนบ

### 2. `src/contexts/LanguageContext.tsx`

เพิ่ม/ปรับคีย์ครบ 4 ภาษา (th/en/ko/zh):
- `docs.upload` — อัปโหลดเอกสาร / Upload Documents / 문서 업로드 / 上传文件
- `docs.pendingFiles` — ไฟล์ที่เลือก (รออัปโหลด) / Selected files (pending) / 선택된 파일 (대기 중) / 已选文件（待上传）
- `docs.removeFile` — ลบไฟล์นี้ / Remove / 삭제 / 删除
- ตรวจคีย์เดิมที่ใช้ในหน้าต่างนี้ (`docs.title`, `docs.attach`, `docs.docTitlePlaceholder`, `docs.descriptionPlaceholder`, `docs.uploading`, `docs.uploadSuccess`, `docs.uploadFailed`, `docs.titleRequired`, `docs.emptyUploaded`, `docs.takePhoto`, `docs.chooseFromGallery`) ให้มีครบทั้ง 4 ภาษา เพิ่มที่ขาด

## ไม่แตะ

- รูปแบบข้อมูลที่ส่งไป API `driver-documents` (order_number / title / description / driver_name / files_base64) — คงเดิมตามที่ตกลง
- flow เช็คอิน / SOP / POD / OCR / ลายเซ็น
- ปุ่ม "เอกสาร" บนแถบปุ่มงานและไอคอน

## ตรวจสอบหลังแก้

- `npx tsgo` + build ผ่าน
- เปิดเมนูเอกสาร → กรอกหัวข้อ → แนบไฟล์ → เห็นลิสต์รอส่ง + ปุ่มอัปโหลด → กดอัปโหลดแล้วส่งสำเร็จ
- สลับภาษาแอปแล้วข้อความในหน้าต่างเอกสารเปลี่ยนตาม
