# แก้ปุ่มปิดมุมขวาหาย และหน้าต่างเช็คอินรับตู้ยังโหลดนาน (แก้แค่หน้าจอ)

## สาเหตุ (ตรวจแล้ว)
- **ปุ่ม X หาย:** ตอนโหลดเสร็จ แถบหัวข้อของหน้า (สีฟ้า) อยู่ชั้นบนกว่าปุ่ม X เลยทับปุ่มจนมองไม่เห็น (ตอนกำลังโหลดยังไม่มีแถบหัวข้อ ปุ่มจึงเห็น)
- **โหลดนาน:** หน้าเช็คอินรับตู้ตั้งใจใช้ข้อมูลงานที่ส่งมาจากหน้างานเพื่อเปิดเร็ว แต่เช็คเลขงานผิดช่อง เลยไม่ตรงกัน แล้วไปดึงรายการงานทั้งหมดของคนขับจากระบบ 6 รอบก่อนแสดง

## หลังแก้
- ปุ่ม X มุมขวาบนเห็นตลอด ทั้งตอนโหลดและหลังโหลด อยู่บนแถบหัวข้อ
- เปิดหน้าต่างเช็คอินรับตู้ / คืนตู้ จากหน้างานแล้วเห็นข้อมูลทันที (ชื่อลาน, วันรับตู้, เส้นทาง)
- ข้อมูลเพิ่มเติมจากระบบ (ถ้ามี) เติมให้เบื้องหลังโดยไม่ต้องรอ
- ปุ่มเช็คอินล็อกชั่วครู่ระหว่างตรวจสถานะเหมือนรอบที่แล้ว
- ขั้นตอนและข้อมูลที่ส่งไประบบไม่เปลี่ยน

## Technical details
- `JobStepRoutes.tsx` / `JobActionButtons.tsx`: ตัวครอบปุ่ม X เปลี่ยน `z-[60]` เป็น `z-[110]` (สูงกว่า `.app-sticky-header` z-index 100)
- `ContainerCheckInPage.tsx` `loadJobDetail`: fast path จับคู่ `stateJob.order_number || stateJob.order_code || stateJob.id` กับ `jobId`; การ map ใช้ `order_code: foundJob.order_number || foundJob.order_code`; หลังแสดงจาก state แล้ว ดึงงานจาก API แบบไม่ await เพื่อเติมช่องที่ว่าง (ไม่ทับค่าที่มี)
