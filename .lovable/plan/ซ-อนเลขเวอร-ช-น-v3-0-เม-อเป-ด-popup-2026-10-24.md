# ซ่อนเลขเวอร์ชัน v3.0 เมื่อเปิด popup

## ปัญหา
ป้าย "v3.0" ลอยอยู่บนสุดของทุกอย่าง จึงไปทับปุ่มปิด (X) ของ popup เช็คอิน

## ที่จะแก้
- ซ่อน "v3.0" อัตโนมัติขณะมี popup / หน้าต่างลอยเปิดอยู่ (popup เช็คอิน, ค่าใช้จ่าย, เอกสาร, แจ้งปัญหา ฯลฯ)
- ปิด popup แล้วเลขเวอร์ชันกลับมาแสดงตามเดิม
- หน้าอื่นไม่เปลี่ยน

## รายละเอียดเทคนิค
- `src/App.tsx` (ป้ายเวอร์ชัน): ใช้ MutationObserver บน `document.body` ตรวจว่ามี `[role="dialog"][data-state="open"]` หรือ `[role="alertdialog"]` อยู่ไหม ถ้ามีให้ซ่อนป้าย
