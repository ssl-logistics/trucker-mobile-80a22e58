# เปิดหน้าต่างขั้นตอนครั้งแรกให้เร็วขึ้น + เปลี่ยนปุ่มย้อนกลับเป็นปุ่มปิดมุมขวา

## 1. กดครั้งแรกโหลดนาน (หน้าเช็คอินรับตู้ / คืนตู้)
สาเหตุ: หน้าจอรอดึงประวัติเช็คอินทั้งหมดของคนขับจากระบบให้เสร็จก่อน ถึงจะแสดงข้อมูล ทั้งที่ข้อมูลงานส่งมาจากหน้างานแล้ว

หลังแก้:
- เปิดหน้าต่างแล้วเห็นข้อมูลงาน (ลาน, ที่อยู่, เลขตู้) ทันที
- ระหว่างตรวจสถานะเช็คอินเบื้องหลัง ปุ่มเช็คอินจะกดไม่ได้ชั่วครู่ (มีวงโหลดเล็กๆ ที่ปุ่ม) เพื่อกันเช็คอินซ้ำ
- ถ้าเปิดจากลิงก์ตรง (ไม่มีข้อมูลจากหน้างาน) ยังโหลดแบบเดิม
- ขั้นตอนและข้อมูลที่ส่งไม่เปลี่ยน

## 2. ปุ่มในหน้าต่าง
- เอาปุ่มลูกศรย้อนกลับมุมซ้ายบนออก (เฉพาะตอนเปิดเป็นหน้าต่าง)
- ใส่ปุ่ม X ปิดมุมขวาบน กดแล้วปิดหน้าต่างกลับไปหน้างาน (เหมือนแตะนอกหน้าต่าง)
- ใช้กับทุกหน้าต่างขั้นตอน (เช็คอินรับตู้, ยืนยันรับตู้, SOP, POD, คืนตู้) และหน้าต่างดู/เพิ่มค่าใช้จ่าย
- เปิดเต็มหน้า (จากแจ้งเตือน/ลิงก์ตรง) ยังมีปุ่มย้อนกลับเหมือนเดิม

## Technical details
- `ContainerCheckInPage.tsx` `loadJobDetail`: หลัง `setJob(mappedJob)` เรียก `setLoading(false)` ทันที และรัน `checkExistingCheckin` แบบไม่ await พร้อม state `statusSyncing` ที่ disable ปุ่มเช็คอิน (รูปแบบเดียวกับ `DeliveryDetailPage`)
- `JobStepRoutes.tsx`: เพิ่มปุ่ม X (`absolute right-3 top-3 z-[60]`) เรียก `close()`; ซ่อนปุ่มย้อนกลับในหัวหน้าขั้นตอนด้วย class ตัวครอบ (`[&_header_button:first-child]:hidden` + `[&_.sticky.top-0_>button:first-child]:hidden` / ตัวที่มี ChevronLeft) — ตรวจทีละหน้าด้วย Playwright
- `JobActionButtons.tsx` Sheet ค่าใช้จ่าย: ทำแบบเดียวกัน ปุ่ม X เรียก `setExpenseSheet(null)`
