# ทำงานในหน้าประวัติ (ในประเทศ + ต่างประเทศ) เป็น Read-only สมบูรณ์

## เป้าหมาย
งานที่เปิดจากหน้าประวัติ (`?from=history`) ให้ "กดดูได้อย่างเดียว" — ไม่มีการอัปเดท/แก้ไขใดๆ ทั้งสิ้น ทั้งงานในประเทศและต่างประเทศ

## จุดที่ปัจจุบันยังแก้ไขได้จากหน้าประวัติ (ตรวจสอบแล้ว)
1. **ปุ่ม "ปิดงาน" ในการ์ดประวัติ** — `HistoryJobCard.tsx` มีปุ่ม self-close ที่ยิง `updateOrderStatus` เปลี่ยนสถานะงาน → ลบออก (เปิดจากประวัติห้ามอัปเดท)
2. **ปุ่ม "เพิ่มค่าใช้จ่าย"** — `JobActionButtons.tsx` ยังแสดงปุ่มเพิ่ม/ดูค่าใช้จ่ายจาก history (ภายใน 3 วัน) → ซ่อนปุ่ม "เพิ่มค่าใช้จ่าย" เมื่อมาจากประวัติ คงปุ่ม "ดูค่าใช้จ่าย" ไว้เพื่อดูอย่างเดียว
3. **หน้าค่าใช้จ่ายแก้ไขได้** — `JobExpensesPage.tsx` มีลบรายการ/ลบรูป/อัปโหลดรูปใบเสร็จ → ถ้าเปิดมาจาก flow ประวัติ ให้เป็นโหมดดูอย่างเดียว (ซ่อนปุ่มลบ/เพิ่มรูป/อัปโหลด)
4. **แก้ไขรูปภาพ (EditablePhoto)** — ปัจจุบันแก้รูปได้ภายใน 3 วันหลังจบงาน ในหน้า `PickupSummaryPage`, `DeliveryDetailPage`, `ContainerSummaryPage` → บังคับ `canEdit = false` เมื่อ `fromHistory` (ดูรูปได้ แต่ไม่มีปุ่มแก้ไข)
5. **ปุ่ม action ในหน้ารายละเอียดงาน** — `DomesticJobDetail.tsx` กันไว้หลายจุดแล้ว แต่บางปุ่ม (เช็คอิน/SOP/POD/คืนตู้) ยังไม่ได้ disable ด้วย `isFromHistory` โดยตรง → เพิ่มเงื่อนไข `isFromHistory` ให้ปุ่มทุกปุ่มที่ trigger การอัปเดท กันเหนียวทุกเส้นทาง

## ไฟล์ที่จะแก้
- `src/components/history/HistoryJobCard.tsx` — ลบปุ่ม "ปิดงาน" + dialog ยืนยัน + logic `handleCloseJob`
- `src/components/job/JobActionButtons.tsx` — ซ่อนปุ่ม "เพิ่มค่าใช้จ่าย" เมื่อ `isFromHistory`
- `src/pages/JobExpensesPage.tsx` — รองรับ read-only mode (ซ่อนลบ/แก้ไข/อัปโหลด)
- `src/components/photo/EditablePhoto.tsx` — `fromHistory` = ไม่แสดงปุ่มแก้ไขเสมอ
- `src/components/job-detail/DomesticJobDetail.tsx` — เพิ่ม `isFromHistory` ในเงื่อนไข disabled ของปุ่มเช็คอิน/SOP/POD/คืนตู้

## หมายเหตุ
- การ "ดู" ทุกอย่างยังเหมือนเดิม: รูปภาพ, สรุป SOP, ค่าใช้จ่าย, ไทม์ไลน์
- กฎเดิมที่อนุญาตแก้รูปภายใน 72 ชม. และแก้ค่าใช้จ่ายจากประวัติ จะถูกแทนที่ด้วยกฎ read-only นี้ (จะอัปเดต memory)
- ไม่แตะ backend / API / schema

## ทดสอบ
- เปิดงานในประเทศและงานต่างประเทศ (BL/Booking) จากหน้าประวัติ → ไม่มีปุ่มที่บันทึก/อัปเดทได้ทุกจุด
- เปิดงานเดียวกันจากหน้างานปัจจุบัน → ปุ่มทำงานปกติ
