# แก้หน้างานเลื่อนกลับขึ้นบนสุดหลังเลื่อนไปจุดล่าสุด

## สาเหตุ
เมื่อเปิดหน้างาน แอปมีตัว "รีเซ็ตกลับบนสุด" ทุกครั้งที่เปลี่ยนหน้า ซึ่งทำซ้ำอีกหลายรอบ (ถึงประมาณ 0.4 วินาที) ส่วนหน้างานเริ่มเลื่อนไปจุดล่าสุดตั้งแต่ 0.2 วินาที — การรีเซ็ตรอบหลังจึงดึงจอกลับขึ้นบนสุด

## แก้ไข
- หน้างาน: เริ่มเลื่อนไปจุดล่าสุดหลังจากการรีเซ็ตกลับบนสุดเสร็จแล้ว (หลัง ~0.5 วินาที) และเลิกสั่งเลื่อนขึ้นบนสุดซ้ำเอง
- ตัวรีเซ็ตกลับบนสุด: หยุดรีเซ็ตรอบที่เหลือทันทีถ้าหน้านั้นสั่งเลื่อนไปจุดเองแล้ว เพื่อไม่ให้แย่งกันอีก
- ไม่เปลี่ยนกติกาว่าเลื่อนไปจุดไหน (งานยังไม่เริ่ม/เสร็จหมด = อยู่บนสุดเหมือนเดิม)

## Technical details
- `DomesticJobDetail.tsx` auto-scroll effect: remove the immediate scrollTo(0); start first attempt at ~500ms; before scrolling set `window.__skipScrollReset = Date.now()`.
- `App.tsx` `ScrollToTopOnRouteChange`: `reset()` returns early if `__skipScrollReset` was set after the route change began.
