# ปรับ UI สำรองจ่ายในหน้าเพิ่มค่าใช้จ่าย

## เป้าหมาย
ทำให้ตัวเลือก "สำรองจ่าย" ใช้งานง่ายขึ้นโดยเปลี่ยนจาก Checkbox เป็น Switch และจัดให้อยู่ในบรรทัดเดียวกับช่องราคา โดยไม่แก้ไขช่องราคา

## ขอบเขต
- แก้ไขเฉพาะ `src/pages/AddExpensePage.tsx`
- ช่องราคา (label, input, placeholder, formatting) คงเดิม
- ตรรกะการส่งค่า `isAdvance` / `advance_amount` คงเดิม
- ใช้ `Switch` จาก `src/components/ui/switch.tsx` ที่มีอยู่แล้ว

## ขั้นตอนการทำงาน
1. เพิ่ม import `Switch` ใน `src/pages/AddExpensePage.tsx`
2. เปลี่ยนโครงสร้างส่วนราคา + สำรองจ่ายจาก:
   - Label "ราคา *" + Input แยก
   - Checkbox "สำรองจ่าย" อยู่ด้านล่าง
   เป็น:
   - Label "ราคา *" + Input คงเดิม
   - ในแถวเดียวกับช่องราคา (หรือแถวถัดไปแต่อยู่ในบรรทัดเดียวกัน) แสดง Label "สำรองจ่าย" + Switch ทางขวา
3. ผูก Switch กับ state `expense.isAdvance` เหมือนเดิม
4. ตรวจสอบ responsive บนหน้าจอมือถือ (ความกว้าง ~393px)

## ผลลัพธ์ที่คาดหวัง
- ผู้ใช้เห็นช่องราคาและสวิตช์สำรองจ่ายอยู่ใกล้กัน
- แตะ/ปัดสวิตช์เปิดปิดสำรองจ่ายได้สะดวย
- ไม่กระทบตรรกะการบันทึกค่าใช้จ่ายหรือการส่ง API
