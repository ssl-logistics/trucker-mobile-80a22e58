# แก้หน้าจุดส่งสินค้าโหลดนาน

## สาเหตุ
ข้อมูลจุด (ชื่อ, ที่อยู่, ผู้ติดต่อ) มีอยู่แล้วจากหน้างาน แต่หน้านี้ยังรอดึงประวัติเช็คอินทั้งหมดของคนขับจากระบบ และรอข้อมูลการชำระเงินอีกรอบ ก่อนจะแสดงอะไร จึงค้าง "กำลังโหลด..." นาน

## สิ่งที่จะแก้ (แก้แค่การแสดงผล ขั้นตอนเหมือนเดิม)
1. แสดงข้อมูลจุดทันทีที่เปิด ไม่ต้องรอ
2. หน้างานส่งสถานะของจุดนั้นมาด้วย (เช็คอินแล้วหรือยัง / ส่ง POD แล้วหรือยัง) ปุ่มจึงถูกต้องตั้งแต่แรก
3. ดึงประวัติเช็คอินและข้อมูลชำระเงินพร้อมกันอยู่เบื้องหลัง แล้วอัปเดตสถานะให้ตรงกับระบบ ระหว่างนั้นปุ่มดำเนินการขึ้นสถานะกำลังโหลดสั้นๆ กันกดซ้ำ
4. เปิดจากลิงก์ตรง (ไม่มีข้อมูลจากหน้างาน) ยังทำงานแบบเดิม

## Technical details
- `DeliveryDetailPage.loadJobDetail`: หลัง `setDestination(...)` เรียก `setLoading(false)` ทันที; ย้ายส่วน `getDriverCheckins` + query `job_applications` เป็น `Promise.all` ที่ไม่ block และใช้ state `statusSyncing` ปิดปุ่ม action ระหว่างรอ
- `DomesticJobDetail` (ปุ่มจุดส่ง): เพิ่ม `checkedInAt`/`podCompletedAt` ใน navigate state; หน้า delivery ใช้เป็นค่าเริ่มต้นของ `jobApplication`/`destination`
- ไม่แก้ payload, API ที่เรียก, ลำดับขั้นตอน
