# เพิ่มช่องเลขไมค์และจำนวนลิตร สำหรับค่าน้ำมัน

## สิ่งที่ผู้ใช้จะเห็น
- เมื่อเลือกประเภท "ค่าน้ำมัน" (Fuel) หรือ "ค่าน้ำมันดรอป" (Fuel Drop) ในหน้าเพิ่มค่าใช้จ่าย จะมีช่องเพิ่ม 2 ช่องต่อจากช่องราคา:
  - เลขไมค์ (กม.) — ตัวเลข ใส่คอมมาอัตโนมัติ
  - จำนวนลิตร — ตัวเลข ทศนิยมได้ 2 ตำแหน่ง
- ไม่บังคับกรอก เว้นว่างได้
- ประเภทอื่นไม่แสดงช่องนี้; เปลี่ยนประเภทจากน้ำมันเป็นอย่างอื่นจะล้างค่าที่กรอกไว้
- ป้ายและตัวอย่างในช่องรองรับ 4 ภาษา (ไทย/อังกฤษ/เกาหลี/จีน)

## รายละเอียดทางเทคนิค
- `src/pages/AddExpensePage.tsx`: เพิ่ม `mileage` และ `fuelLiters` ใน state รายการค่าใช้จ่าย (ค่าเริ่มต้นว่าง, reset ตอนล้างฟอร์ม); ตัวช่วย `isFuelType(type)` ตรวจ `fuel` / `fuel_drop`; แสดงช่องเฉพาะเมื่อเป็นประเภทน้ำมัน
- ตอนบันทึก (payload `transport-expenses`): ถ้ามีค่า ส่ง `mileage` (ตัวเลข) และ `fuel_liters` (ตัวเลข) เพิ่ม และต่อท้าย `notes` เช่น `เลขไมค์ 123,456 กม. / 50.25 ลิตร` เพื่อให้ข้อมูลไม่หายแม้ระบบปลายทางยังไม่รองรับช่องใหม่
- `src/contexts/LanguageContext.tsx`: เพิ่ม `expense.mileage`, `expense.mileagePlaceholder`, `expense.fuelLiters`, `expense.fuelLitersPlaceholder` ครบ 4 ภาษา
- ไม่แตะหมวดรายจ่ายจาก API หรือตรรกะอื่น
