# แก้แจ้งซ่อมส่งไม่ได้เมื่อไม่มีทะเบียนรถในโปรไฟล์

## ปัญหา
หน้าแจ้งซ่อมซ่อนช่องทะเบียนรถไว้และดึงจากโปรไฟล์อัตโนมัติ แต่ถ้าบัญชีไม่มีข้อมูลทะเบียน (plate_number / auth_truck_plate ว่าง) กดส่งแล้วขึ้นแจ้งเตือนแดง "ไม่พบข้อมูลรถสำหรับส่งรายงาน" และผู้ใช้แก้เองไม่ได้เพราะไม่มีช่องให้กรอก

## วิธีแก้
- ถ้าดึงทะเบียนจากโปรไฟล์ได้ → หน้าจอเหมือนเดิมทุกอย่าง (ไม่มีช่องทะเบียน)
- ถ้าดึงไม่ได้ → แสดงช่องกรอก "ทะเบียนรถ *" เป็นช่องแรกของหน้า ให้ผู้ใช้พิมพ์เอง (บังคับกรอก)
- ค่าที่กรอกถูกส่งไปกับรายงานเหมือนเดิม (payload `license_plate` ไม่เปลี่ยน)
- ข้อความเตือน "ไม่พบข้อมูลรถ" ยังคงเป็นกันพลาดสุดท้าย (แทบไม่เกิดแล้ว)

## ที่โดนแก้
- `src/pages/RepairReportPage.tsx`
  - เปลี่ยน `licensePlate` จากค่าคงที่กลับเป็น state ที่ prefill จากโปรไฟล์
  - เพิ่มเงื่อนไขแสดงช่องกรอกทะเบียนเฉพาะเมื่อ prefill ว่าง (label + Input + เครื่องหมาย *)
  - `resetForm()` ล้างเฉพาะรายละเอียด/รูปเหมือนเดิม — ทะเบียนที่กรอกเองคงไว้เผื่อส่งใบถัดไป
- `src/contexts/LanguageContext.tsx`
  - เพิ่มคีย์ `repairReport.plateLabel` / `repairReport.platePlaceholder` กลับมา (4 ภาษา th/en/ko/zh)

## การตรวจสอบ
- `bunx tsgo --noEmit` + ดู build log
- Playwright: seed โปรไฟล์ที่ไม่มีทะเบียน → ช่องทะเบียนต้องโผล่, กรอกแล้วส่งผ่าน; seed โปรไฟล์ที่มีทะเบียน → ไม่มีช่องทะเบียนเหมือนเดิม
