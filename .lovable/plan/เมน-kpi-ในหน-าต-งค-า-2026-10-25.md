# เมนู KPI ในหน้าตั้งค่า

## สิ่งที่ผู้ใช้จะเห็น
- หน้าตั้งค่า: เพิ่มเมนู "KPI" (ไอคอนกราฟ) ต่อจากเมนูข้อมูลรถ กดเปิดหน้า KPI
- หน้า KPI แสดงผลของคนขับเป็น %:
  - ตรงตำแหน่งเช็คอิน (location_pass_pct) พร้อม "ผ่าน x / y จุด"
  - ตรงเวลานัด (time_pass_pct) พร้อม "ผ่าน x / y จุด"
  - สัดส่วนงาน (load_pct) พร้อม "x จาก y งานของบริษัท"
  - งานที่ยังเปิดอยู่ (จำนวน + เลขออเดอร์)
- แต่ละค่าแสดงเป็นวงกลม/แถบ % สีเขียว (≥80) เหลือง (50–79) แดง (<50); ไม่มีข้อมูลเทียบ แสดง "-"
- เลือกช่วงเวลา: วันนี้ / 7 วัน / 30 วัน (ค่าเริ่ม 30 วัน) — หลายวันรวมเป็น % เฉลี่ยจากจำนวนผ่าน/ตรวจทั้งหมด
- รายการรายวันด้านล่าง; หมายเหตุ "อัปเดตทุกเที่ยงคืน" และเกณฑ์ (ระยะ ≤5 กม., เวลาต่าง ≤20 นาที) จาก API
- ไม่มีข้อมูล: "ยังไม่มีข้อมูล KPI"; รองรับ 4 ภาษาของแอป

## Technical
- เรียก `driver-kpi` ผ่านพร็อกซีฝั่งเซิร์ฟเวอร์ใหม่ `driver-kpi-proxy` ใช้ `EXPRESS_RENT_API_KEY` (key เดียวกับเช็คอิน) — เลี่ยงปัญหา CORS แบบที่เจอกับ driver-cod-clear; CORS รวม `x-app-secret`
- ค้นด้วย `license_plate` ของคนขับ (fallback `driver_name`), `from`/`to` ตามช่วงที่เลือก
- `src/lib/driverKpi.ts`: `aggregateKpi(rows)` รวม passed/checked → % (null เมื่อ checked=0) + เทสต์
- `src/pages/KpiPage.tsx`, route `/kpi` (ProtectedRoute), เมนูใน `SettingsPage.tsx`, คำแปลใน `LanguageContext.tsx`
