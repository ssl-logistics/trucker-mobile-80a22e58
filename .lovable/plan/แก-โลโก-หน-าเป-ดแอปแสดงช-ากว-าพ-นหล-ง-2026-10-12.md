# แก้โลโก้หน้าเปิดแอปแสดงช้ากว่าพื้นหลัง

## ปัญหา
หน้า splash ตอนเปิดแอปแสดงพื้นหลังและแสงเขียวก่อน แล้วโลโก้ "The Truckers" ค่อยโหลดมาแสดงทีหลัง เพราะโลโก้เป็นไฟล์ภาพแยก (PNG ~53KB) ที่เบราว์เซอร์ต้องดาวน์โหลดและถอดรหัสหลังหน้าจอแสดงแล้ว ทำให้เห็นจอเปล่าก่อนแล้วโลโก้เด้งขึ้นมา

## แนวทางแก้ (แก้เฉพาะ UI ของ splash ไม่แตะ logic อื่น)

1. **ฝังโลโก้ไว้ในตัวแอปเลย (inline data URI)**
   - ย่อโลโก้ให้พอดีขนาดที่แสดงจริงบน splash (แสดงกว้างสุด ~256px จึงเตรียมไฟล์ที่ความกว้าง 512px พอสำหรับหน้าจอ hi-res) แล้วเข้ารหัสเป็น base64 ฝังในไฟล์โมดูลใหม่ เช่น `src/assets/splashLogo.ts`
   - ผลคือโลโก้อยู่ในตัว JavaScript ของแอปแล้ว แสดงได้ทันทีตั้งแต่เฟรมแรก ไม่ต้องรอดาวน์โหลดไฟล์ภาพแยก
   - ไฟล์ `src/assets/trucker-icon-mark.png` เดิมคงไว้ (ยังใช้ที่อื่นได้ถ้าต้องการ) แต่ splash จะใช้โมดูลใหม่แทน

2. **ปรับ `src/components/StartupSplash.tsx` ให้ใช้โลโก้ตัวใหม่**
   - เปลี่ยน import จากไฟล์ PNG เป็นโมดูล base64
   - โครงหน้าจอ พื้นหลัง แสงเขียว วงแหวนโหลด และเวลาแสดง 3 วินาที เหมือนเดิมทุกอย่าง

## ไม่แตะ
- เวลาแสดง 3 วินาที, การ preload ข้อมูลเบื้องหลัง, การจางออก, flow ทั้งหมดของแอป

## ตรวจสอบ
- Build ผ่าน
- ทดสอบด้วย Playwright: เปิดแอปใหม่ เช็คว่าเฟรมแรกของ splash มีทั้งพื้นหลังและโลโก้พร้อมกัน ไม่มีจังหวะจอเปล่าแล้วโลโก้เด้งทีหลัง
