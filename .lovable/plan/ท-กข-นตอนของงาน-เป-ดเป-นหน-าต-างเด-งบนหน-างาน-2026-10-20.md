# ทุกขั้นตอนของงาน เปิดเป็นหน้าต่างเด้งบนหน้างาน

ตอนนี้แค่จุดเพิ่มที่เปิดเป็นหน้าต่างเด้ง ส่วนจุดหลัก (รับตู้, จุดรับสินค้า, จุดส่งสินค้า, คืนตู้) ยังเปิดเป็นหน้าใหม่ จะเปลี่ยนให้ทุกจุดเปิดเป็นหน้าต่างเด้งขึ้นจากด้านล่างบนหน้างานเดิม โดยหน้างานยังเห็นอยู่ด้านหลัง

## ขั้นตอนที่จะเปิดเป็นหน้าต่างเด้ง
- รับตู้: เช็คอินรับตู้, ยืนยันรับตู้/SOP ตู้, สรุปตู้
- จุดรับสินค้า: เช็คอิน, SOP, สรุปการรับสินค้า
- จุดส่งสินค้า (ทุกจุด): เช็คอิน, POD/ลายเซ็น
- คืนตู้
- ดูค่าใช้จ่าย / เพิ่มค่าใช้จ่าย (จากทุกจุด)

## การทำงาน
- ขั้นตอนเหมือนเดิมทุกอย่าง แก้แค่หน้าตา
- ถ้าขั้นตอนหนึ่งพาไปขั้นต่อไป (เช่น เช็คอิน → SOP) จะเปลี่ยนเนื้อหาในหน้าต่างเดิม ไม่เปิดหน้าใหม่
- กดย้อนกลับหรือกดปิด/ทำเสร็จ จะปิดหน้าต่างแล้วเห็นหน้างานพร้อมสถานะใหม่
- กล้อง, สแกนตู้ (OCR), เซ็นชื่อ ใช้ได้ในหน้าต่างเหมือนเดิม
- ถ้าเปิดจากลิงก์แจ้งเตือนหรือเปิดตรงๆ (ไม่ได้มาจากหน้างาน) ยังแสดงเป็นหน้าเต็มเหมือนเดิม

## Technical details
- ใช้รูปแบบ modal route ของ React Router: `DomesticJobDetail` / `JobDetailPage` เวลาเรียก navigate ไปหน้าขั้นตอน ส่ง `state.backgroundLocation = location` (ทำใน helper เดียว `navigateStep`)
- `App.tsx`: render `<Routes location={backgroundLocation || location}>` ตามเดิม และถ้ามี backgroundLocation ให้ render ชุด route ขั้นตอน (`/job/:jobId/{container-checkin,container-sop,container-summary,pickup,sop,pickup-summary,delivery,delivery/:id,delivery-sop,delivery-sop/:id,expenses,add-expense,extra-point/...}`) อีกครั้งภายใน `StepSheet` (Sheet ล่าง สูง 95vh, เลื่อนในหน้าต่าง)
- การ navigate ต่อระหว่างขั้นตอนส่งต่อ `backgroundLocation` อัตโนมัติผ่าน wrapper ของ `useNavigate` ใน StepSheet context; ถ้า path ปลายทางเป็น `/job/:jobId` (กลับหน้างาน) หรือ `navigate(-1)` ถึงหน้างาน → ปิด sheet
- หน้าขั้นตอนที่ใช้ `min-h-screen`/header sticky ปรับให้พอดีใน sheet ผ่าน class ตัวครอบ (ไม่แก้ logic ในหน้า)
- คงหน้าต่างเช็คอินจุดเพิ่มและหน้าต่างค่าใช้จ่ายที่ทำไว้
