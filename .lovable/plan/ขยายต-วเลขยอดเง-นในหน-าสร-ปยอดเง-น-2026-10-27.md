# ขยายตัวเลขยอดเงินในหน้าสรุปยอดเงิน

- ตัวเลขในกล่องดรอปดาวน์ "ยอดเงินโอนจากลูกค้า (บาท)" / "ยอดเงินสดที่ต้องโอนคืนบริษัท (บาท)": ใหญ่ขึ้นและหนาขึ้น (2xl -> 3xl, ตัวหนา)
- ตัวเลข ต้องเก็บ / เก็บแล้ว / ค้าง ทั้งด้านบนหน้าและในการ์ดงาน: ใหญ่ขึ้น 1 ขั้น (lg -> xl)
- แก้แค่หน้าตา ยอดเงินไม่เปลี่ยน

## Technical
`CodClearPage.tsx`: บรรทัด 166 `text-2xl font-semibold` -> `text-3xl font-bold`; บรรทัด 113, 118, 119, 147-149 `text-lg` -> `text-xl`
