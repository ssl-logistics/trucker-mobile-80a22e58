# ทำให้กด "กลับ" จากหน้าจุดรับ แล้วหน้ารายละเอียดงานขึ้นทันที

## สาเหตุ
เวลากดปุ่มกลับ หน้ารายละเอียดงานจะโหลดใหม่ตั้งแต่ต้นทุกครั้ง โดยดึงรายการงานทั้งหมดของคนขับจากระบบหลายรอบ (คนขับบริษัทดึงถึง 9 รอบ) แล้วค่อยหางานนั้น ระหว่างนั้นหน้าจอเป็นแค่โครงเทาว่าง ๆ ทั้งที่ข้อมูลงานเคยโหลดไว้แล้วตอนเข้าหน้านี้ครั้งแรก

## สิ่งที่จะแก้
1. จำข้อมูลงานที่โหลดล่าสุดไว้ในเครื่อง (ต่อเลขออเดอร์)
2. เมื่อกลับมาหน้ารายละเอียดงาน ให้แสดงข้อมูลที่จำไว้ทันที ไม่ขึ้นหน้าโหลดเต็มจอ
3. จากนั้นค่อยดึงข้อมูลล่าสุดเบื้องหลัง แล้วอัปเดตหน้าจอเงียบ ๆ (สถานะเช็คอิน/SOP ยังอัปเดตตามจริง)
4. ถ้าไม่มีข้อมูลที่จำไว้ (เปิดครั้งแรก) ทำงานเหมือนเดิม

พฤติกรรมอื่น (ประวัติแบบอ่านอย่างเดียว, งานโอน, ปุ่มต่าง ๆ) ไม่เปลี่ยน

## รายละเอียดทางเทคนิค
- `JobDetailPage.tsx`: แคช `job` + `jobApplication` ใน memory map + sessionStorage key ตาม order_code (ตัด /NN) หลัง `loadJobDetail` สำเร็จ
- ตอน mount / `location.key` เปลี่ยน: ถ้ามีแคช ให้ `setJob/setJobApplication` จากแคชและ `setLoading(false)` ทันที แล้วเรียก `loadJobDetail({ silent: true })` ที่ไม่ `setLoading(true)`
- ตรวจด้วย Playwright: เข้า `/job/<order>` → `/pickup` → กดกลับ วัดเวลาจนเนื้อหาแสดง ก่อน-หลัง
