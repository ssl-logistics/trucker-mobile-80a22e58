# แสดง "รหัสตู้" บนการ์ดงานต่างประเทศ

## สาระสำคัญ
งานต่างประเทศที่มาจากเลขออเดอร์ชุดเดียวกัน เช่น `OR20260922002/01` และ `OR20260922002/02`
ปัจจุบันบนการ์ดแสดงแค่ป้าย "Booking demo0101" เหมือนกันทั้งสองงาน มองไม่ออกว่าอันไหนคืองานไหน
สิ่งที่ต่างกันคือเลขท้ายหลัง `/` (01 / 02) ซึ่งก็คือ "รหัสตู้" ที่ต้องการให้เห็น

## จะเพิ่มอะไร
บนการ์ดงานต่างประเทศในหน้างานปัจจุบัน จะแสดง "รหัสตู้" เพิ่มขึ้นอีกรายการ:

```text
[Booking demo0101]                         22/09/2026 | 20:06
------------------------------------------------------------
ผู้ส่ง : โรงงานบางบ่อ
[International (BL)]
   เลขตู้ : TCLU1234567 / TCLU7654321     <- แสดงเมื่อมีเลขจริง
   รหัสตู้ : 01                            <- แสดงเสมอถ้าเลขออเดอร์มี /
------------------------------------------------------------
●  โรงงานบางบ่อ
   |
   ...
```

- **รหัสตู้** = ตัวเลขที่อยู่หลัง `/` สุดท้ายของเลขออเดอร์ (`OR20260922002/01` → `01`)
- แสดงเฉพาะงานต่างประเทศ (มี BL / Booking / job_type international) และเฉพาะเมื่อเลขออเดอร์มี `/` จริง
- แสดงทั้งกรณีที่มีและไม่มีเลขตู้ — เคส `OR20260922002/01` และ `/02` ตอนนี้ยังไม่มีเลขตู้ จึงจะเห็นแค่รหัสตู้ ทำให้แยกงานกันได้
- ถ้าเลขออเดอร์ไม่มี `/` (งานในประเทศ / งานปกติ) จะไม่แสดงอะไรเลย การ์ดคงเดิม
- ตำแหน่ง: ใต้ป้ายประเภทงาน ติดกับแถวเลขตู้ ใช้รูปแบบเดียวกัน (ไอคอน + คำกำกับตัวเล็ก + ค่าตัวหนา)

## ขอบเขต
- แก้ไขเฉพาะหน้างานปัจจุบัน ตามที่ยืนยันแล้วว่าจะไม่เพิ่มในหน้าจออื่น
- หน้าแรก หน้าประวัติ และหน้ารายละเอียดงาน: ไม่แตะต้อง

## รายละเอียดทางเทคนิค
1. **src/pages/CurrentJobsPage.tsx** (บล็อกที่เรนเดอร์แถวเลขตู้ บรรทัด 1241-1254)
   - เพิ่มตัวช่วย `getContainerCode(orderNumber)`: คืนส่วนหลัง `/` สุดท้าย เช่น `OR20260922002/01` → `01`, ไม่มี `/` → `null`
   - เรนเดอร์แถว "รหัสตู้" ต่อจากแถวเลขตู้ ภายใต้เงื่อนไข international เดียวกัน
   - แถวเลขตู้คงเกณฑ์เดิม (แสดงเมื่อมีเลขจริง) แต่ถ้าไม่มีเลขตู้เลย มีรหัสตู้ ก็ยังแสดงรหัสตู้
2. **src/contexts/LanguageContext.tsx** — เพิ่ม key `jobDetail.containerCode` ครบ 4 ภาษา ข้าง ๆ `jobDetail.containerNumber`
   - th: `รหัสตู้` | en: `Container Code` | ko: `컨테이너 코드` | zh: `箱号代码`
3. **ตรวจโค้ด** — `bunx tsgo --noEmit -p tsconfig.app.json`, ดู `/tmp/observability/build-errors.log`, บันทึกงานลง roadmap.md
4. **ยืนยันภาพ** — Playwright จำลองงานต่างประเทศ 2 ออเดอร์ (`/01`, `/02` ตัวหนึ่งมีเลขตู้ อีกตัวไม่มี) แล้วดูว่าแยกกันออกบนการ์ด
