# หน้า KPI: เปลี่ยนเป็นกราฟให้ดูง่าย

## สิ่งที่จะเปลี่ยน
- 3 ช่องเล็ก (ตรงตำแหน่ง / ตรงเวลา / สัดส่วนงาน) เปลี่ยนเป็นแถบแนวนอน 3 แถบ ยาวตาม % และมีสีตามระดับ (เขียว / เหลือง / แดง) พร้อมตัวเลข % และ "ผ่าน x จาก y" ใต้แถบ
- ตาราง "รายวัน" เปลี่ยนเป็นกราฟเส้น 3 เส้น (ตรงตำแหน่ง, ตรงเวลา, สัดส่วนงาน) แกน 0-100% เรียงวันจากเก่าไปใหม่ มีคำอธิบายสีเส้นด้านล่าง กดที่จุดแล้วเห็นค่าของวันนั้น
- วงกลมคะแนนรวม, รายการงานที่ยังเปิด และหมายเหตุด้านล่างคงเดิม
- รองรับ 4 ภาษาเหมือนเดิม

## รายละเอียดทางเทคนิค
- `src/pages/KpiPage.tsx`: แทน `Mini` grid ด้วย progress bars ใช้ token สีเดิม (`toneBg`); แทนตารางรายวันด้วย recharts `LineChart` (มีในโปรเจกต์แล้ว) ใช้สีจาก CSS variables, วันที่ไม่มีค่าให้เว้นช่วง (`connectNulls`)
