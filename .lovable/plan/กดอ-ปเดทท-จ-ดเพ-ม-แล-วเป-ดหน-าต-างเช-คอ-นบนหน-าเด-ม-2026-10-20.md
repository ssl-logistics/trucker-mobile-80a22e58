# กดอัปเดทที่จุดเพิ่ม แล้วเปิดหน้าต่างเช็คอินบนหน้าเดิม

ใช้ได้ครับ ขั้นตอนและข้อมูลที่ส่งเหมือนเดิมทุกอย่าง เปลี่ยนแค่หน้าตา: เมื่อกด "อัปเดท" ที่จุดดรอปตู้ / รับตู้ที่ดรอปไว้ / จุดส่ง-รับสินค้าเพิ่ม จากเดิมที่เปิดไปอีกหน้า จะเปิดเป็นหน้าต่างเด้งขึ้นมาบนหน้างานเดิมแทน

## ในหน้าต่างจะมี (ครบเหมือนจุดอื่น)
- ชื่อขั้นตอน (เช่น ดรอปตู้ / รับตู้ที่ดรอปไว้ / ส่งสินค้า) และชื่อสถานที่
- แถวปุ่มเหมือนจุดปกติ: ดูค่าใช้จ่าย, เพิ่มค่าใช้จ่าย, เอกสาร, แจ้งปัญหา
- ปุ่มถ่ายรูป / เลือกจากคลังรูป แนบได้หลายรูป ลบรูปได้ (ต้องมีอย่างน้อย 1 รูป)
- รูปที่เคยแนบไว้แล้ว (ถ้ามี)
- ช่องหมายเหตุ
- ปุ่ม "ยืนยัน" และ "ยกเลิก"

## หลังกดยืนยัน
- ส่งข้อมูลเหมือนเดิมทุกอย่าง
- ปิดหน้าต่าง การ์ดเปลี่ยนเป็นสีเขียว "สำเร็จ" ทันที ขั้นตอนถัดไปปลดล็อค
- ถ้าระบบตอบผิดพลาด แสดงข้อความในหน้าต่างเลย ไม่ปิด

## ไม่เปลี่ยน
- กฎการล็อคปุ่ม, จุดหลัก (รับตู้/SOP/POD/คืนตู้) และงานที่ไม่มีจุดเพิ่ม ยังเหมือนเดิม
- กดที่ตัวการ์ดยังเปิดหน้ารายละเอียดจุด (ดูรูป, รายจ่าย, เอกสาร) ได้เหมือนเดิม

## Technical details
- แยกฟอร์ม + การส่งจาก `ExtraPointCheckinPage.tsx` ออกเป็นคอมโพเนนต์ `ExtraPointCheckinForm` ใช้ร่วมกัน
- สร้าง `ExtraPointCheckinSheet` (Drawer/Sheet) ใน `DomesticJobDetail.tsx`; `openExtraCheckin` เปลี่ยนจาก navigate เป็นเปิด sheet พร้อม type/pt/title
- เมื่อส่งสำเร็จเรียก `recordExtraCheckin` + dispatch `EXTRA_POINT_EVENT` เพื่อรีเฟรชสถานะการ์ด
- ปุ่มเช็คอินในหน้ารายละเอียดจุดก็ใช้ sheet เดียวกัน; คง route หน้าเดิมไว้เผื่อลิงก์เก่า
