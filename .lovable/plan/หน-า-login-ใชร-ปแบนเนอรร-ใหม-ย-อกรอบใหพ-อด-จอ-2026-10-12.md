# หน้า Login: ใชรู้ปแบนเนอรร์ใหม้ + ย่อกรอบใหพ้อดีจอ

## สิ่่งท่ีผ้้ใชจ้ะได

- หน้าเข้้าสู่ระบบใชรู้ปแบนเนอรร์ใหม้ (1200x480) เต็มกว้้างจอ ความส้้ง ~118–177px ตามความส้้งของจอ
- หน้า Login พอดิีจอพอດี **ไมต่องเลื่่อนลงอีก** (ตรวจทุุกขนาดจอท่ี testing)
- โลโก้ "The Truckers" รถ ล้อ และถนนยังเห็็นครบ ไม่ถุกตัดออก

## ขั้่นตอนการทำงาน

1. แปลงรูปท่ีส่่งมาเป็็น WebP ใหเ้ບาส้่นลง (จาก 697KB เป็็น ~120KB) แล้้วน้าเข้้าระบบแฟ้่ม (CDN) ใหเ้ป็็นรของแอป
2. แกไ้ `src/pages/SignIn.tsx` 3 จุุด
   - ใชรู้ปใหม้แทนรูปเก่่า
   - ความส้้งกรอบ: `max(72px, min(22vh, calc(100dvh - 450px)))` (450px = พื้่นท่ีฟอรม์+เมนูภาษาท่ีวัดไดจ้ริง)
   - ใส่วิธีตัดขอบใหเ้น้ไปตัดด้ายซ้้าย (โลโก้ชิดขอบขวา) แทนการตัดกลาาง
3. โหลดรูปไว้ล่วงหน้้าระหว้่างหน้้าโลโก้ 4 วินาที เพื่่อไมม่ีจังหวะรูปโผล่มาทีหลัง
4. ลบรูปเก่่าออกจากโปรเจกตต์ (ไมม่ีหน้้าอ่ืนใชแ้ล้้ว)
5. ตรวจดว้ย Playwright บนจอความส้้ง 805 / 740 / 700 / 667 / 640 / 600 / 568: ไมม่ี scroll, โลโก้+รถ+ล้อครบ, ฟอรม์และเมนูภาษาเข้้าถึง
6. บันทึกลง roadmap.md และเก็็บข้้อมูรรูป/ขนาดไว้ใน memory
