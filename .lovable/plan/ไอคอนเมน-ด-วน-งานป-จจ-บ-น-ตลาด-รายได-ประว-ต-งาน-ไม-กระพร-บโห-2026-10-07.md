# ไอคอนเมนูด่วน (งานปัจจุบัน / ตลาด / รายได้ / ประวัติงาน) ไม่กระพริบโหลดใหม่

## สาเหตุ
- ไอคอน 4 ตัวเป็นไฟล์แยก แต่ละหน้าสร้างแถบหัวใหม่ ทำให้รูปต้องโหลด/ถอดรูปซ้ำทุกครั้งที่เปิดหน้าแรก → เห็นช่องว่างแวบหนึ่งก่อนไอคอนขึ้น
- ไฟล์ใหญ่กว่าขนาดที่ระบบฝังในแอปให้อัตโนมัติ จึงไม่ได้ติดมากับตัวแอป

## สิ่งที่จะแก้
- ฝังไอคอนทั้ง 4 ตัว (รวมรูปพื้นหลังแถบหัวถ้าเล็กพอ) เข้าไปในตัวแอปเลย ไม่ต้องโหลดจากไฟล์แยก → แสดงทันทีทุกครั้ง
- จองพื้นที่ไอคอนไว้ตายตัว ไม่ให้เมนูขยับตอนแสดง
- ไม่เปลี่ยนหน้าตา ลำดับ หรือการกดเมนู

## รายละเอียดทางเทคนิค
- `AppHeader.tsx`: import ไอคอนด้วย `?inline` (data URI) เช่น `import currentJobIcon from "@/assets/current-job-icon.svg?inline"`; ลบโค้ด preload `new Image()` ที่ไม่จำเป็นแล้ว
- คง `w-16 h-16` + `width/height` บน `<img>`
- ตรวจด้วย Playwright: สลับหน้า home → current-jobs → home แล้วดูว่าไม่มีคำขอโหลดไอคอนซ้ำ
