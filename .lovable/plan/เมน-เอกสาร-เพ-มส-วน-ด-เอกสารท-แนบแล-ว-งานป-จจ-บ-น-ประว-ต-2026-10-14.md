# เมนูเอกสาร: เพิ่มส่วน "ดูเอกสารที่แนบแล้ว" (งานปัจจุบัน + ประวัติ)

## ผลที่จะได้

หน้าต่าง "เอกสาร" จะแสดงเอกสารของออเดอร์นั้นครบชุด ดึงด้วยรหัสออเดอร์โดยตรงตามสเปก `order-documents` ที่แนบมา:

1. **ลายเซ็นรับ-ส่ง** — รูปลายเซ็น + ไฟล์หลักฐานแนบ แยกจุดรับ/จุดส่ง
2. **เอกสารที่คนขับส่ง** — หัวข้อ, คำอธิบาย, ชื่อคนขับ/ทะเบียน, เวลาส่ง, ไฟล์ (รูป/PDF)
3. **ไฟล์ B/L หรือ Booking** — เฉพาะงานต่างประเทศที่มีไฟล์

กดที่ไฟล์เพื่อเปิดดู: รูปเปิดในหน้าต่างขยายในแอป, PDF เปิดแท็บใหม่

ใช้ได้ทั้งหน้างานปัจจุบันและหน้าประวัติ (ปุ่มเอกสารแสดงอยู่แล้วทั้งสองหน้า) — หน้าประวัติเป็น "ดูอย่างเดียว": แสดงรายการเอกสาร แต่ซ่อนฟอร์มแนบไฟล์ใหม่

**ส่วนแนบเอกสาร (อัปโหลด) คงเดิมทุกอย่าง ไม่แตะ**

## รายละเอียดการแก้

### 1. Edge function ตัวกลาง `get-order-documents` (ใหม่, ใน Lovable Cloud)
- ตามสเปก key ของเส้นเอกสาร (`ORDER_DOC_API_KEY`) ห้ามฝังในโค้ด — เก็บเป็น secret ฝั่งเซิร์ฟเวอร์ ฟังก์ชันรับ `order_number` แล้วยิง GET ไปที่ `$BASE/order-documents?order_number=...` (URL-encode เพราะเลขงานมี `/`) พร้อม header `x-api-key`
- ส่งผล `results[0]` กลับให้แอป (เช็ก `found` — ถ้าไม่พบงานแจ้งกลับ)
- **รอ key จากผู้ใช้**: จะขอ key ผ่านหน้าต่างเก็บ secret ของระบบตอนเริ่มทำ — ระหว่างยังไม่มี key ฟังก์ชันตอบ error ชัดเจน หน้าแอปแสดง "โหลดเอกสารไม่สำเร็จ" พร้อมปุ่มลองใหม่ (ส่วนแนบเอกสารยังใช้ได้ปกติ)

### 2. `src/components/job/JobDocumentsSheet.tsx`
- ดึงเอกสารเมื่อเปิดหน้าต่าง (fetch on open) ผ่าน edge function ด้วย `orderNumber` เต็ม (ไม่ตัด suffix `/NN` — สเปกรับเลขงานเต็ม)
- แสดง 3 หมวดตามโครงสร้างคำตอบ: `signatures[]`, `driver_documents[]`, `bl_booking` — ซ่อนหมวดที่ไม่มีข้อมูล
- สถานะ: กำลังโหลด (skeleton) / โหลดไม่สำเร็จ (ข้อความ + ปุ่มลองใหม่) / ไม่มีเอกสาร (ข้อความว่าง)
- กดไฟล์: `kind: image` เปิดดูเต็มใน dialog, `kind: pdf` เปิดแท็บใหม่ (ลิงก์ signed อายุ 1 ชม. — ดึงใหม่ทุกครั้งที่เปิดหน้าต่าง ไม่ cache ข้ามวัน)
- อัปโหลดสำเร็จ → รีเฟรชรายการอัตโนมัติ
- โหมดอ่านอย่างเดียว (จากหน้าประวัติ): ซ่อนฟอร์มแนบ แสดงเฉพาะรายการ

### 3. `src/components/job/JobActionButtons.tsx`
- ส่งโหมดอ่านอย่างเดียว (`isFromHistory`) เข้า `JobDocumentsSheet`

### 4. `src/contexts/LanguageContext.tsx`
- คีย์ใหม่ครบ 4 ภาษา (th/en/ko/zh): ชื่อหมวด (ลายเซ็น / เอกสารที่คนขับส่ง / ไฟล์ B/L–Booking), `docs.loadFailed`, `docs.retry`, ป้ายจุดรับ/จุดส่ง

## ไม่แตะ

- ฟอร์มอัปโหลดเอกสารเดิม (`driver-documents` POST) ทุกบรรทัด
- flow เช็คอิน/SOP/POD, QTruck, การเงิน

## หมายเหตุ

- ลิงก์ไฟล์เป็น signed URL อายุ 1 ชม. ตามสเปก — แอปดึงใหม่ทุกครั้งที่เปิดหน้าต่าง จึงไม่มีปัญหาลิงก์หมดอายุ
- ตรวจ `npx tsgo --noEmit -p tsconfig.app.json` + build ต้องผ่าน
