# เปลี่ยนรูปธงไทยในเมนูเปลี่ยนภาษา

## สรุป

เอารูปธงไทยวงกลม พื้นหลังโปร่งใสที่ส่งมา (500x500, PNG โปร่งใส) มาใช้แทนรูปเดิมทั้งหมด 3 จุด: หน้าเข้าสู่ระบบ, หน้าสมัครสมาชิก, หน้าตั้งค่าภาษา ไม่แตะรูปธง EN/KO/CN และไม่มีผลกับ API หรือ flow

## สิ่งที่จะทำ

1. เตรียมรูปให้พอดีกับการแสดงผล
- รูปที่ส่งมามีพื้นที่ว่างรอบวงกลมประมาณ 23% (วงกลมจริงกินพื้นที่ 57–442 จาก 500) ถ้าใส่ตรง ๆ ธงจะดูเล็กกว่าธงชาติอื่นในเมนูเดียวกัน
- จะครอปให้เหลือเฉพาะวงกลม แล้วย่อลงเป็น 256x256 (จุดที่แสดงจริงมีขนาด 16–32 px) และบันทึกทับ `src/assets/flag-th.png`
- คงความโปร่งใสของ PNG ไว้ ไม่ใส่กรอบ สีพื้น หรือเงาเพิ่ม

2. ปรับการแสดงผลในหน้าเข้าสู่ระบบ
- `src/pages/SignIn.tsx` บรรทัด 707 ปุ่มตัวเลือกภาษากำลังแสดงธงเป็นกรอบสี่เหลี่ยม (`w-5 h-4 object-cover rounded-sm`) ซึ่งจะทำให้ธงวงกลมถูกตัดขอบซ้ายขวา ให้เปลี่ยนเป็นวงกลม `w-5 h-5 rounded-full object-cover` เหมือนหน้าสมัครสมาชิก
- จุดอื่นแสดงเป็นวงกลมอยู่แล้ว (`w-6 h-6` ใน dropdown ของ SignIn, `w-5 h-5` ใน Register, `w-8 h-8` ใน LanguagePage) จึงไม่ต้องแก้

3. ตรวจสอบ
- เปิดหน้าจริงทั้ง 3 จุดด้วย Playwright (มุมมองมือถือ 393x805) ดูว่าธงไทยเป็นวงกลม ไม่ถูกตัดขอบ ไม่มีกรอบขาว และขนาดเท่าธงอื่นในรายการเดียวกัน
- ตรวจว่า build ผ่านปกติ

## รายละเอียดทางเทคนิค

- ไฟล์ปลายทาง: `src/assets/flag-th.png` (ทับของเดิม 256x256 RGB พื้นขาว) เป็น RGBA โปร่งใส
- แหล่งที่มา: `/mnt/user-uploads/istockphoto-1032082664-612x612-removebg-preview.png`
- ขั้นตอน: crop bbox (57,57,443,443) → resize 256x256 → save PNG (RGBA)
- import เดิมทั้ง 3 ไฟล์ (`SignIn.tsx`, `Register.tsx`, `LanguagePage.tsx`) ใช้ path `@/assets/flag-th.png` เดิม จึงไม่ต้องแก้ import
- class ที่แก้: `src/pages/SignIn.tsx` บรรทัด 707 จาก `w-5 h-4 object-cover rounded-sm` เป็น `w-5 h-5 rounded-full object-cover`
