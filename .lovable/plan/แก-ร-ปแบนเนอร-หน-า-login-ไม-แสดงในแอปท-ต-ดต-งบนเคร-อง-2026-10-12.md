# แก้รูปแบนเนอร์หน้า Login ไม่แสดงในแอปที่ติดตั้งบนเครื่อง

## สาเหตุ
แอปที่ติดตั้งบนมือถือโหลดหน้าเว็บจากไฟล์ภายในเครื่อง ไม่ใช่จากเว็บไซต์ รูปแบนเนอร์ถูกอ้างด้วยที่อยู่แบบสั้น (`/__l5e/assets-v1/...`) ซึ่งใช้ได้เฉพาะบนเว็บ preview/เว็บที่เผยแพร่ — ในแอปจึงหาไฟล์ไม่เจอ

## สิ่งที่จะทำ
1. เก็บรูปแบนเนอร์ (WebP ที่มีมุมโค้งโปร่งใส ~117KB) ไว้ในตัวแอปโดยตรง เป็น `src/assets/login-hero.webp` แล้ว import แบบปกติ — รูปจะถูกรวมไปกับแอปตอน build ใช้ได้ทั้งเว็บและแอปบนเครื่อง ไม่ต้องใช้อินเทอร์เน็ตด้วย
2. แก้ `SignIn.tsx` และ `StartupSplash.tsx` ให้ใช้ไฟล์นี้แทน pointer
3. ลบ asset บน CDN และ pointer เดิม
4. ตรวจรูปภาพแสดงใน preview (มุมโค้งครบ, ไม่ต้องเลื่อนจอ) และบันทึกกฎใน AGENTS.md: รูปที่ใช้ในแอปมือถือต้องรวมไว้ในตัวแอป ไม่ใช้ CDN path แบบสั้น

## หลังแก้
ต้อง build และติดตั้งแอปใหม่ (`npm run build` → `npx cap sync`) รูปจึงจะแสดงบนเครื่อง
