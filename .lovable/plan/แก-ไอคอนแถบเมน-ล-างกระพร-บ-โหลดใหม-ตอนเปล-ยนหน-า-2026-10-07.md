# แก้ไอคอนแถบเมนูล่างกระพริบ/โหลดใหม่ตอนเปลี่ยนหน้า

## สิ่งที่จะเปลี่ยน
- ไอคอน หน้าแรก / แดชบอร์ด / ตั้งค่า ในแถบเมนูล่าง จะแสดงทันทีไม่กระพริบเวลาเปลี่ยนหน้า
- หน้าตาไอคอน สี ลำดับ และการทำงานของปุ่ม เหมือนเดิมทุกอย่าง

## รายละเอียดทางเทคนิค
- `BottomNavigation.tsx`: เปลี่ยน import ไอคอน svg ทั้ง 6 ไฟล์เป็น `?inline` (ฝังเป็น data URI ไม่ต้องโหลดจากเครือข่าย) เหมือนที่แก้ใน AppHeader แล้ว
- เพิ่ม `decoding="sync"` และ `draggable={false}` ที่ `<img>`
- ตรวจ tsgo + build ผ่าน
