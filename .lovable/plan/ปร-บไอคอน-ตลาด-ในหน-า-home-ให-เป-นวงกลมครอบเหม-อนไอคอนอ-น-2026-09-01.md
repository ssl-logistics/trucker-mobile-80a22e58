# ปรับไอคอน "ตลาด" ในหน้า Home ให้เป็นวงกลมครอบเหมือนไอคอนอื่น

## เป้าหมาย
- ไอคอน "ตลาด" ใน quick menu ของ `AppHeader` ต้องแสดงเป็นวงกลมครอบ เหมือนกับไอคอน "งานปัจจุบัน" และ "รายได้"
- คงรูปแบบการใช้งานและการนำทางไป `/market` ไว้เหมือนเดิม

## สิ่งที่ตรวจสอบแล้ว
- Quick menu อยู่ใน `src/components/layout/AppHeader.tsx` บรรทัด ~140
- ไอคอนแต่ละตัวอยู่ใน container `w-16 h-16 flex items-center justify-center` แต่ไอคอน `market-icon.png` เป็นรูปร้านค้าสี่เหลี่ยม ไม่มีวงกลมครอบ
- ไอคอนอื่น (current-job-icon.svg, income-icon.svg) เป็น SVG ที่มีวงกลมครอบอยู่แล้วในตัวไฟล์

## แนวทางแก้ไข
1. สร้างไอคอน "ตลาด" ในรูปแบบวงกลมครอบ
   - ตัวเลือก A (แนะนำ): สร้าง SVG ใหม่ `src/assets/market-icon.svg` เป็นรูปร้านค้าภายในวงกลม พื้นหลังสีฟ้า/ขาว ให้เข้าชุดกับไอคอนอื่น
   - ตัวเลือก B: ใช้ CSS ครอบ PNG เดิมด้วยวงกลม (border-radius: 50%) + พื้นหลังสี แต่ภาพร้านค้าอาจถูกตัดไม่สวย
2. อัปเดต `AppHeader.tsx`
   - เปลี่ยน import `marketIcon` จาก PNG เป็น SVG ใหม่
   - ตรวจสอบว่า container และขนาดยังคงเท่ากับไอคอนอื่น (`w-16 h-16 object-contain`)
3. ตรวจสอบ i18n
   - คีย์ `home.market` มีอยู่แล้ว (`ตลาด`) ไม่ต้องเพิ่ม
4. ตรวจสอบ build
   - รัน TypeScript check และ build ให้ผ่าน

## หมายเหตุ
- จะไม่ลบไฟล์ `src/assets/market-icon.png` เดิมออก เพื่อให้สามารถกลับมาใช้ได้หากต้องการ
- ไม่เปลี่ยนแปลง logic การแสดงผล freelance-only หรือการนำทาง
