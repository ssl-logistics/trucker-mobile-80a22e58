# การ์ดแนะนำครั้งแรกที่หน้าเซ็นลายเซ็น

## สิ่งที่จะทำ
เพิ่มการ์ดแนะนำในหน้าต่าง "ลายเซ็นผู้รับ/ผู้ส่ง" แสดงครั้งแรกที่เปิดหน้าต่างนี้ เหมือนการ์ดแนะนำเมนูใหม่ที่ทำไว้ก่อนหน้า (เอกสาร / แจ้งซ่อม / ดูคิว / สำรองจ่าย / ข้อมูลน้ำมัน)

1. **การ์ดแนะนำด้านบนของหน้าต่างลายเซ็น**
   - กรอบสีส้ม + ข้อความอธิบายสั้น ๆ ว่าให้ผู้รับ/ผู้ส่งกรอกชื่อและเซ็นชื่อในกรอบก่อนกดยืนยัน
   - ปุ่ม "รับทราบ" — กดแล้วการ์ดหายไป เซ็นลายเซ็นได้ตามปกติ
   - เริ่มเซ็นบนกรอบลายเซ็นเลยก็ถือว่ารับทราบ การ์ดหายไปเช่นกัน
2. **แสดงครั้งเดียวต่อบัญชี**
   - จำสถานะในเครื่องด้วย key ของตัวเอง `signature_intro_ack:<driverId>` แยกจากการ์ดเมนูอื่น
   - บัญชีใหม่ยังเห็นการ์ดครั้งแรก
   - ข้อยกเว้น: หน้า preview (id-preview--) แสดงทุกครั้งเพื่อให้ทดสอบ
3. **รองรับ 4 ภาษา** (ไทย/อังกฤษ/เกาหลี/จีน) ตามภาษาที่ใช้ตอนนี้
4. ไม่แตะ flow เซ็นลายเซ็น อัปโหลด หรือการยืนยันเดิม

## รายละเอียดเชิงเทคนิค
- `src/components/job/SignatureDialog.tsx`:
  - เพิ่มข้อความ intro ใน TEXT (4 ภาษา): `intro_title`, `intro_desc`, `intro_ack`
  - state `showIntro` เริ่มจาก localStorage `signature_intro_ack:<driverId>` (อ่าน driver id จาก localStorage เหมือนหน้าอื่น) + เงื่อนไข isPreviewHost แสดงทุกครั้ง
  - การ์ดอยู่เหนือช่องกรอกชื่อ มี ring สีส้มรอบส่วนกรอกชื่อ+กรอบเซ็น
  - กด "รับทราบ" หรือเริ่มเซ็น (pointer down บน canvas) → บันทึก ack และซ่อนการ์ด
- ไม่เปลี่ยนการอัปโหลดลายเซ็น / upload-to-s3 / onSigned
