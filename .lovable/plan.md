# แผน: แสดงรหัส Invoice ที่การ์ดจุดส่งสินค้า (งานในประเทศ)

## เป้าหมาย
การ์ด "จุดส่งสินค้า" ในหน้ารายละเอียดงาน (`src/components/job-detail/DomesticJobDetail.tsx`) แสดงรหัส invoice เสมอ — ถ้ามีข้อมูลแสดงค่าจริง ถ้าไม่มีแสดง `-`

## ข้อมูล (ยืนยันจากไฟล์ JSON ที่อัปโหลด)
- แต่ละจุดส่ง (destination) มีฟิลด์ `invoice_number` ของตัวเอง เช่น `"invoice_number": "test34"`
- งานจุดเดียว (fallback card) ใช้ตรรกะแมปหลายฟิลด์ตามเดิมของระบบ: `invoice_number`, `inv_no`, `destination_invoice_number`, `destination_bill_of_lading`, และ `csv_extra_data`

## การเปลี่ยนแปลง
1. **การ์ดหลายจุดส่ง** (map ตาม destinations): เพิ่มแถว "Invoice" แสดง `dest.invoice_number || '-'` — แสดงเสมอแม้ไม่มีค่า
2. **การ์ดจุดเดียว (fallback)**: ปัจจุบันแสดงเฉพาะตอนมี `destination_bill_of_lading` — ปรับให้แสดงเสมอ โดยใช้ลำดับ fallback เดิมของระบบ และแสดง `-` ถ้าไม่มีข้อมูลเลย
3. ใช้ label เดิมจากระบบแปลภาษา (`job.invoice`) รองรับ 4 ภาษาตามเดิม วางตำแหน่งถัดจากข้อมูลผู้ติดต่อ/โทรศัพท์ ให้สอดคล้องกับการ์ดเดิม

## สิ่งที่ไม่เปลี่ยน
- flow เช็คอิน / SOP / POD / คืนตู้ และ payload ที่ส่ง API ทั้งหมด
- การ redirect หลังงานจบ (แผนนั้นยังไม่ทำตามที่สั่ง)
- หน้าตาและข้อความอื่นของการ์ด

- typecheck (`tsgo`) + build ผ่าน
