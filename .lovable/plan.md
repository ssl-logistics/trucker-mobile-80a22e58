# เช็คอินเสร็จ ปิดหน้าต่างทันที ปุ่มเปลี่ยนเลย (งานในประเทศ)

## สิ่งที่คนขับจะเห็น
- กดเช็คอินสำเร็จ หน้าต่างปิดทันที (ไม่รอโหลดอย่างอื่นต่อในหน้าต่าง)
- ปุ่มของจุดที่เพิ่งเช็คอินเปลี่ยนสถานะทันที แล้วระบบดึงข้อมูลล่าสุดเงียบๆ ด้านหลัง

## ไม่เปลี่ยน
- ตำแหน่งจอหลังกลับมาหน้างาน คงพฤติกรรมเดิม
- ขั้นตอนเช็คอิน / SOP / POD / COD และข้อมูลที่ส่งไประบบ
- เปิดจากแจ้งเตือน/ลิงก์ตรง ยังเป็นหน้าเต็มเหมือนเดิม

## Technical details
- หน้าเช็คอินที่เปิดในหน้าต่าง (DeliveryDetailPage ฯลฯ): เมื่อเช็คอินสำเร็จ บันทึก optimistic check-in แล้ว navigate กลับ `/job/:id` ทันที (ปิด modal) งานเบื้องหลังที่เหลือทำแบบ non-blocking
- `DomesticJobDetail.tsx`: ตอนโหลดหลังปิด modal ให้ merge optimistic cache ก่อนแสดงปุ่ม เพื่อให้ปุ่มเปลี่ยนทันทีโดยไม่รอ API
- ตรวจด้วย Playwright: เช็คอินในหน้าต่าง → หน้าต่างปิดทันที และปุ่มเปลี่ยน
