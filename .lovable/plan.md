# รูปด้านบนหน้า Login: สั้นลงโดยไม่ดูบีบ

## สิ่งที่ผู้ใช้จะได้

- กรอบรูปด้านบนของหน้าเข้าสู้ระบบสั้นลง (จาก ~322px เหลือ ~242px บนจอมือถือทั่วไป) แต่โลโก้ รถ ล้อ และถนนยังเห็นครบ
- ภาพไม่ยืด ไม่บีบ เพราะใช้วิธี "ตัดขอบออก" ไม่ใช่ "ดึงภาพให้เข้ากรอบ"
- หน้า Login ยังเลื่อนลงถึงเมนูภาษาได้เหมือนเดิมบนจอเตี้ย

## ขั้นตอนการทำงาน

1. ใช้รูปใหม่ที่ผู้ใช้ส่งมา (อัตราส่วนกว้าง ~1.6:1) วางแทนที่รูปเดิมในตำแหน่งเดิม
2. ลดความสูงกรอบรูปในหน้า Login จาก 40vh เป็น 30vh พร้อมกำหนดความสูงขั้นต่ำ ~170px เพื่อจอสั้นไม่เสียสัดส่วน
3. คงกติกาเดิมของหน้า Login: ฟอร์มเต็มความกว้าง, ระยะบน pt-12, เลื่อนได้เมื่อจอสั้น, ไม่ซ่อนเนื้อหาส่วนเกิน
4. ตรวจด้วย Playwright บนจอ 393x805 และจอเตี้ย 393x568: โลโก้/รถ/ล้อครบ, ไม่มีรอยยืดบีบ, ฟอร์มและเมนูภาษาเข้าถึงได้
5. บันทึกงานนี้ลง roadmap.md และเก็บข้อเท็จจริงเรื่องรูป/ขนาดลง memory

## รายละเอียดทางเทคนิค

- ไฟล์รูป: `public/lovable-uploads/login-background-2.png` (เดิม 375x380 px RGBA PNG, 177KB) — วางไฟล์ใหม่ทับชื่อเดิม หรือใส่ชื่อใหม่แล้วแก้ path ในโค้ด
- ขนาดแนะนำ: 1200x740 px, PNG หรือ WebP, ไม่เกิน ~300KB
- จุดแก้โค้ด: `src/pages/SignIn.tsx` บรรทัด 346-348
  - `<div className="relative h-[40vh] flex-shrink-0">` → `relative h-[30vh] min-h-[170px] flex-shrink-0`
  - `<img ... className="absolute inset-0 w-full h-full object-cover" src="/lovable-uploads/login-background-2.png" />` คง `object-cover` ไว้ (กันภาพยืด) และใช้ `object-center`
- ผลข้างเคียงที่ควรทราบ: ถ้าภาพใหม่ยังไม่ได้สัดส่วน ~1.6:1 ระบบจะตัดขอบบน-ล่างออกเพื่อไม่ให้เห็นรอยขาว
- หน้า "ลืมรหัสผ่าน" และ "ตั้งรหัสผ่านใหม่" ใช้อีกไฟล์ (`src/assets/login-background.png` 1125x1140, 1.3MB) — จะเปลี่ยนให้ตรงกันต่อเมื่อผู้ใช้สั่ง
