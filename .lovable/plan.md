# ระยะห่างขอบบน 14px สำหรับหัวเรื่องทุกหน้า (แก้ที่เดียว)

## เป้าหมาย

หัวเรื่องsticky ทุกหน้าในแอปจะไม่ชิดขอบบนอีกต่อไป — มีระยะห่างอย่างน้อย 14px (บนมือถือที่มีรอยแฉะ/Notch จะใช้ค่ารอยแฉะถ้ามากกว่า) แก้ที่สไตล์กลางตัวเดียวที่ทุกหน้าใช้อยู่ร่วมกัน หน้าแรกและเมนูหลัก (Home / รายการงาน / แชท / ตั้งค่า) คงไว้เหมือนเดิม

## สิ่งที่ทำได้ตรวจสอบแล้ว

- สไตล์กลาง `.app-sticky-header` ใน `src/index.css` บรรทัด 284-286 ตั้ง `padding-top: env(safe-area-inset-top, 0px)` ซึ่งบนจอไม่มีรอยแฉะ = 0px และชนะ Tailwind `py-*` (เพราะอยู่นอก layer) ทำให้หัวเรื่องทุกหน้าชิดขอบบน
- หน้าที่ใช้ `.app-sticky-header` รวม 28 จุด (จุดรับสินค้า, จุดส่งสินค้า, SOP/Container Check-in, Summary, ประวัติงาน, ค่าใช้จ่าย, รายได้, ประมวลราคา, บัญชี, โปรไฟล์, การแจ้งเตือน, ภาษา, ข้อกำหนด, ติดต่อ, ข้อมูลรถ, แชทในห้องสนทนา ฯลฯ) ทุกจุดมี padding ภายในของตัวเอง (`py-3` / `py-4` / `p-3`) และไม่มีสไตล์กันรอยแฉะของตัวเอง — จึงได้รับผลพร้อมกันหมดจากการแก้ที่เดียว
- `src/pages/Home.tsx` บรรทัด 1269 ใช้ `.app-sticky-wrapper` ครอบหัวเรื่องของหน้าแรกไว้ด้านใน ซึ่งหัวเรื่องของหน้าแรกจัดการระยะขอบบนของมันเองแยกอีกแบบ และไม่ได้ใช้ class `.app-sticky-header` — การแก้ครั้งนี้จึงไม่แตะหน้าแรก/เมนูหลัก ตามที่เลือกไว้

## แผนการแก้ไข

1. `src/index.css` บรรทัด 284-286 — เปลี่ยนค่า padding-top ของ `.app-sticky-header` จาก
   ```text
   padding-top: env(safe-area-inset-top, 0px);
   ```
   เป็น
   ```text
   padding-top: max(env(safe-area-inset-top, 0px), 14px);
   ```
   นี่คือจุดแก้เดียวที่หัวเรื่องทุกหน้ารับผลพร้อมกัน

2. ลบค่าที่เขียนครอบไว้เฉพาะหน้าออก เพื่อให้ระยะห่างมีที่มาเดียว (ผลลัพธ์เท่าเดิม 14px ไม่มีการกระโดด):
   - `src/components/job-detail/DomesticJobDetail.tsx` บรรทัด ~1281 — ลบ `style={{ paddingTop: "max(env(safe-area-inset-top, 0px), 14px)" }}`
   - `src/components/job-detail/JobDetailLoadingState.tsx` บรรทัด ~14 — ลบ `style={{ paddingTop: 'max(env(safe-area-inset-top, 0px), 14px)' }}`

3. เพิ่ม entry ใน `roadmap.md` บันทึกการแก้ครั้งนี้

## ผลที่คาดว่าจะเห็น

- หัวเรื่อง "จุดรับสินค้า Hi-Q Food Products Co., Ltd." และหัวเรื่องทุกหน้าในแอปจะห่างจากขอบบน 14px (จากเดิม 0px)
- หัวเรื่องหน้าแรก/เมนูหลักเหมือนเดิม ไม่ขยับ
- มือถือที่มีรอยแฉะ (Notch) ยังกันรอยแฉะได้เหมือนเดิม เพราะใช้ค่ามากกว่าระหว่างรอยแฉะกับ 14px
- โครงหน้าจอตลอดูโหลดของหน้างานปกติและหน้างานประมูลเลื่อนตามหัวเรื่องจริง เพราะใช้สไตล์กลางเดียวกัน

## การตรวจสอบ

- `bunx tsgo --noEmit` ผ่าน
- `/tmp/observability/build-errors.log` ต้องขึ้น build OK
- Playwright: สอดส้างหน้าจอท่ีใชหหัวเรื่อง `.app-sticky-header` แล้ววัด computed `padding-top` ต้องได้ 14px (เดิม 0px) พร้อมยืนยันว่าหัวเรื่องของหน้าแรกไม่เปล่ียนแปลง

## หมายเหตุ

- ค่า 14px เล็กน้อยก่าบางหนาที่ใช `py-4` (16px) และมากกว่าบางหนาที่ใช `py-3` (12px) — เป็นระยะเดียวกันทั่วทั้งแอปตามที่ไดรับเลือก
- หนาอื่น ๆ ในเมนูหลักที่ใชหัวเรื่องคนละแบบ (เชน หัวเรื่องดานบนของหนาแรก) จะยังชิดขอบบนเหมือนเดิม เพราะไมไดใช class นี้
