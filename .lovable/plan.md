# การแนบเลขไมล์และจำนวนลิตรเข้ากับ OCR (อธิบาย — ไม่มีการแก้ไข)

## การทำงานปัจจุบัน (ทำเสร็จแล้ว)

1. ผู้ใช้เลือกประเภท "ค่าน้ำมัน" หรือ "ค่าน้ำมันดรอป" แล้วถ่ายรูปใบเสร็จ
2. รูปถูกส่งไปที่ `ocr-extract` พร้อมบอกประเภทค่าใช้จ่าย
3. ตัวอ่าน OCR หาตัวเลขเพิ่มจากยอดเงินเดิม:
   - เลขไมล์ (`odometer_km`) — จากข้อความเช่น "Odo", "เลขไมล์"
   - จำนวนลิตร (`fuel_liters`) — จากข้อความเช่น "Liters", "ลิตร", "25.5 L"
4. หน้าเพิ่มค่าใช้จ่ายเติมค่าลงช่องกรอกอัตโนมัติ เฉพาะเมื่อช่องยังว่าง (ไม่ทับค่าที่พิมพ์เอง)
5. ถ้าอ่านไม่เจอ ช่องว่างไว้ให้กรอกเอง ไม่มี error

## ข้อจำกัดที่ตกลงไว้

- สองค่านี้ยังไม่ถูกส่งไประบบค่าใช้จ่ายตอนบันทึก (จะเพิ่มทีหลังตามคำสั่ง)
- การกรอกค่าใช้จ่ายแบบเดิมและการอ่านยอดเงินทำงานเหมือนเดิมทุกอย่าง

## ไม่มีงานใหม่ในแผนนี้

ข้อความนี้เป็นการอธิบายการทำงานที่มีอยู่แล้ว ไม่มีการแก้ไขโค้ด
