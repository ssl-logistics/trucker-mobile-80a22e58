# งานต่างประเทศ: สแกน QR ที่จุดรับตู้เปล่า

## สิ่งที่ผู้ใช้ต้องการ
งานต่างประเทศ (BL/Booking) ให้มีขั้นตอนสแกน QR ที่การ์ดจุดรับตู้เปล่า (จุดที่เลือกในหน้าจอ) เหมือนงานในประเทศ — ส่วนเช็คอินและแนบหลักฐานยังใช้ flow API เดิมทั้งหมด ไม่เปลี่ยน

## สิ่งที่จะทำ
1. เอาเงื่อนไขยกเว้นงานต่างประเทศออกจากขั้นตอนสแกน: หลังเช็คอินที่จุดรับตู้เปล่า ปุ่มหลักบนการ์ดเปลี่ยนเป็น "สแกนโหลดสินค้า" (ข้ามได้) แล้วค่อยเป็น "แนบหลักฐาน" ตามเดิม
2. สแกนสำเร็จ → ยิงเส้น queues/scan ของระบบคิวเหมือนงานในประเทศ (external_ref = เลขออเดอร์, station_token = ค่าจาก QR, key อยู่ฝั่งเซิร์ฟเวอร์) แบบไม่รอผล
3. แสดงแถบสีเขียว "สแกนโหลดสินค้าแล้ว (เวลา)" บนการ์ดจุดรับตู้เปล่าของงานต่างประเทศด้วย
4. เก็บสถานะในเครื่องต่อออเดอร์เหมือนเดิม — ครั้งถัดไปไม่ถามซ้ำ

## ไม่เปลี่ยน
- flow เช็คอิน / แนบหลักฐาน / SOP / ลายเซ็น ของทุกประเภทงาน (ใช้ API เดิมทั้งหมด)
- จุดส่ง, จุดคืนตู้, การดูจากประวัติ

## Technical details
- `DomesticJobDetail.tsx`:
  - `needsLoadingQr`: ลบเงื่อนไข `!job.bl_no && !job.booking_no` ออก (เหลือ: ไม่ใช่ history, ยังไม่เคยสแกน, เช็คอินจุดรับแล้ว, ยังไม่ยืนยัน SOP จุดรับ)
  - แถบสถานะเขียว (~บรรทัด 2013): ลบเงื่อนไข `!job.bl_no && !job.booking_no` ออก
  - `handleLoadingQrDone` ใช้ของเดิม (ยิง qtruck-queue-scan อยู่แล้ว) — ไม่ต้องแก้
- ไม่แตะ edge function หรือ i18n (คำแปล loadingQr.* มีครบแล้ว)
