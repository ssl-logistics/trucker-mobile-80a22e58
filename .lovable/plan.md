# สลับลำดับไอคอนในแถบเมนู: เอกสาร มาก่อน แจ้งปัญหา

## สิ่งที่จะแก้
ใน `src/components/job/JobActionButtons.tsx` ย้ายปุ่ม "เอกสาร" ขึ้นมาก่อนปุ่ม "แจ้งปัญหา"

ลำดับใหม่: ดูค่าใช้จ่าย → เพิ่มค่าใช้จ่าย → เอกสาร → แจ้งปัญหา

## รายละเอียดเทคนิค
- ย้ายบล็อกปุ่มเอกสาร (บรรทัด ~100-107) ขึ้นไปไว้ก่อนบล็อกปุ่มแจ้งปัญหา (บรรทัด ~90-98)
- ตรรกะซ่อน/แสดงปุ่มและจำนวนคอลัมน์ (grid-cols) คงเดิม ไม่เปลี่ยน
- มีผลทุกหน้าที่ใช้แถบเมนูนี้ (SOP, เช็คอินตู้, สรุปตู้, จุดรับ, จุดส่ง ฯลฯ)
- ตรวจด้วย npx tsgo + build
