# แก้ชื่อปุ่มเปลี่ยนหน้าการแจ้งเตือน

## สิ่งที่ตรวจพบ
- ปุ่มก่อนหน้าและถัดไปใน `NotificationsPage` เรียก `t('common.previous')` และ `t('common.next')`
- คีย์ทั้งสองมีคำแปลเฉพาะภาษาจีน แต่ยังไม่มีในภาษาไทย อังกฤษ และเกาหลี
- ระบบแปลภาษาคืนชื่อคีย์เมื่อไม่พบคำแปล ทำให้ fallback ที่เขียนด้วย `||` ไม่ทำงานและปุ่มแสดงตัวแปรตรง ๆ

## การแก้ไข
1. เพิ่มคำแปล `common.previous` และ `common.next` ให้ครบภาษาไทย อังกฤษ และเกาหลีใน `LanguageContext`
2. คงการทำงานของปุ่มและ pagination เดิมทั้งหมด เปลี่ยนเฉพาะข้อความที่แสดง
3. ตรวจหน้าแจ้งเตือนในภาษาไทยเริ่มต้นให้ปุ่มแสดง “ก่อนหน้า” และ “ถัดไป” และตรวจว่าไม่แสดง translation key อีก

## รายละเอียดทางเทคนิค
- ไฟล์ที่แก้: `src/contexts/LanguageContext.tsx`
- ไม่เปลี่ยน API, ฐานข้อมูล หรือ logic การแบ่งหน้า
