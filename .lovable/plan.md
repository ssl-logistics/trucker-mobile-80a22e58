# ทำใหปุ่ "มดูลข้อมูลงาน" เดนกวาปุ่ "มดคูิว"

## ปญหา

ในการ์ดงานปจจุบน ปุ "มดูลข้อมูลงาน" เปนแบบขาวขอบบาง (ไมมีสสีัน) สว น "ปุมดคูิว" เปนสสีันเขียวเตม็ ปุม จึงดดู นกวาปมุ ที่ตองการให เดน

## สิงที่จะแก

สลบั ลำดบั ความเดนของสองปุมใหตรงกบั ที่ตองการ

- ปุ "มดูลข้อมูลงาน" เปนสสีันเขียวเตม็ ตวั อกั ษรสขี าว (ปุมหลกของแอป)
- ปุ "มดคูิว" เปนแบบขาวขอบบาง ตวั อกั ษร/ไอคอนสสีัน (ปุมรอง)
- สองปมุ ยงั อยคู ี่แถวเดยี วกนั 2 ชองเทาเดมิ ขนาดสงู เทาเดมิ ตวั อกั ษรขนาดเดมิ
- ไอคอนรายการคิวยังอยู ในปุมดคูิวตามเดมิ
- กรอบสมของ การดแนะนำ "ดคูิว" (ครังแรก) ยงั ทำงานเดมิ

## ผลที่คาดหวง

เมอื ดหู นารายการงานปจจุบน ปมุ "ดูลข้อมูลงาน" จะเดนตามสุด (สสีันเตม็ ) สว น "ดคูิว" จะถอยลงเปนปุมรอง (ขาวขอบบาง) การกดทังสองยงิ ไດผลเดมิ ทกุ อยา ง (เปิดหนารายละเอยี ดงาน / เปิดหนตางขอมูลคิว) ไม เกยี่ วกบั งานน ี้

## ขอบเขต

แกเฉพาะรปู แบบภายนอกของปมุ ในหนารายการงานปจจุบน

- ไมแก การเปิดหนตางคิว ขอมูลคิว การแนะนำคิว (การด) หรอื การเกบ็ cache รายการงาน
- ไมแก flow งาน (เชค็ อิน / SOP / POD / QR / QTruck)
- หนาอื่ นที่มมี ปุ "มดูลข้อมูลงาน" ไม เกยี่ วของในงานน ี้

## รายละเอยี ดทางเทคนิค

- ไฟล: `src/pages/CurrentJobsPage.tsx` ชวงบรรทัด 1453-1476 (แถวปมุ ใต การดงาน)
- ปุ "มดูลข้อมูลงาน": เปลี่ ยนจาก `variant="outline"` เปน `variant="default"` (ใชส ี `--primary` 158 64% 40% ตามระบบสีของแอป)
- ปุ "มดคูิว": เปลี่ ยนจาก `variant` หลก (default) เปน `variant="outline"` และคง `h-11 w-full gap-2 text-base font-medium` + ไอคอน `ListOrdered`
- ไมมสี ี hardcode เพิ่ มเติม ใช semantic token ของ Button ทังคู
- การตรวจสม: build/ตรวจชนิ ดผาน + เปิ ดหน "ารายการงานปจจุบน" ใน preview แบบเขาสู่ระบบแลว ถา ยรปู การดงานและวดส ีพื้นหลงของปมุ ดวย Playwright: ปมุ "ดูลข้อมูลงาน" ตองไดส ีพนื หลงเปนเขียว (primary) สว นปุม "ดคูิว" ตองเป นขาวม ขอบ
