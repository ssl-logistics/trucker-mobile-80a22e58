# ปุ่ม "ดูข้อมูลงาน" เปิดเป็นหน้าต่างเด้งขึ้นมา (แก้แค่หน้าตา)

## สิ่งที่คนขับจะเห็น
- หน้า "งานปัจจุบัน": กด "ดูข้อมูลงาน" แล้วรายละเอียดงานเด้งขึ้นมาจากด้านล่าง ทับรายการงาน (ไม่เปลี่ยนไปหน้าใหม่)
- ข้างในหน้าต่างเหมือนหน้ารายละเอียดงานเดิมทุกอย่าง: การ์ดจุด, ปุ่มโทร/เส้นทาง/อัปเดต, ค่าใช้จ่าย, เอกสาร
- กดขั้นตอนต่อ (เช็คอิน, SOP, POD, รับ/คืนตู้) เนื้อหาเปลี่ยนอยู่ในหน้าต่างเดิม ไม่เปิดหน้าใหม่
- ปิด: ปัดลงหรือกดย้อนกลับ กลับมาที่รายการงาน และรายการรีเฟรชสถานะล่าสุด
- เปิดจากแจ้งเตือน / ลิงก์ตรง / ประวัติงาน / งานประมูล: ยังเปิดเต็มหน้าเหมือนเดิม

ขั้นตอน ปุ่มล็อก และข้อมูลที่ส่งไประบบ เหมือนเดิมทั้งหมด

## รายละเอียดทางเทคนิค
- `JobStepRoutes.tsx`: เพิ่มกรณีพื้นหลังเป็น `/current-jobs` — ถ้าเปิด `/job/:id` (และหน้าขั้นตอน `/job/:id/...` ของงานเดียวกัน) ต่อจากหน้ารายการ ให้คง `/current-jobs` ไว้ข้างหลังและ render หน้างาน/ขั้นตอนใน Sheet เดียว (ไม่ซ้อน 2 ชั้น); ปิดแล้ว navigate กลับ `/current-jobs` และ remount เพื่อรีเฟรช
- กรณีเดิม (เปิดขั้นตอนจากหน้างานเต็มจอ) ยังทำงานเหมือนเดิม
- `CurrentJobsPage.tsx` ไม่ต้องแก้ logic `handleOpenJob` (ยัง navigate พร้อม state job เดิม)
