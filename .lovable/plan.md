# หน้าเปิดแอป: แสดง 4 วินาที + เส้นโหลดหนาขึ้น + หมุนนุ่มนlider

## สิ่ งที่แก้
1. **แสดงนานขึ้ น** — หน้าโลโก้แสดง 4 วินาที (จาก 3 วินาที) แล้วจางออก 300ms เหมือนเดิม
2. **เส้นโหลดหนาขึ้ น** — วงแหวนโหลดหนาจาก 2px เป็น 5px
3. **หมุนนุ่ มนliderขึ้ น** — เปลี่ ยนวงแหวนจากเส้ นขอบ 2 มุม (กระตุกตอนสลັบมุม) เป็นเส้ นโคงสีนุ่ นตเนื้ อ งกั น (สี เขียวเข้ มทางหัว ไล้ จางลงเรื่ อ ย ๆ จนหาย) หมุนดว้ ยความเร็ วเท่ าเดิม 1.1 วินาที/รอบ

## ไมไ่ ปลี่ ยน
- โลโก้, แสงพื้ นหลัง, ความเร็ วหมุน, การโหลดข้ อ มู ลเบื้ อ งหลังระหว่ างแสดง (preload) คงเดิม
- ไมม่ ีขอ้ ความ และไมม่ ีกรอบรอบโลโก้ ตามทกี่ ำหนดไว้ก่ อนหน้ า

## รายละเอี ยดเทคนิ ค
- `src/components/StartupSplash.tsx`
  - `DISPLAY_DURATION_MS` 3000 → 4000 (EXIT_DURATION_MS 300 คงเดิม)
  - วงแหวน: ใช้ พื้ นหลัง conic-gradient (primary เข้ ม → ไล้ จาง → โปร่ง) พร้ อ ม radial mask ให้ เป็ นห่ วง ความหนา 5px, เส้ นผ่ านศู นย์ กลาง 40px, `animate-spin` linear 1.1s และ `motion-reduce:animate-none`
- `src/index.css` — เพิ่ ม class `splash-ring-arc` (conic-gradient + mask); คง keyframes `splashRingSpin`/`splashLogoFloat`/`splashGlowPulse` เดิม
