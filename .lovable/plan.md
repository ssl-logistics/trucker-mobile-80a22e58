# หาสาเหตุการ์ดแนะนำเมนูไม่แสดงใน preview ของคุณ

## สิ่งที่ยืนยันแล้ว

- โค้ดการ์ดแนะนำทั้ง 6 เมนูถูกต้อง: ใช้ `isPreviewHost()` ตัวกลาง (ครอบคลุม `id-preview--...`, `*.lovable.app`, localhost) — บน preview ควรแสดงทุกครั้ง
- ทดสอบจำลองบัญชีในเครื่อง: การ์ดแจ้งซ่อมในหน้าตั้งค่าแสดงปกติแม้เคยกดรับทราบแล้ว
- log จาก preview ของคุณ (06:37): แอปโหลดปกติ ไม่มี error, ดึงงานได้ 6 รายการ — แต่ยังบอกไม่ได้ว่าทำไมการ์ดไม่ขึ้นบนบัญชีจริงของคุณ

## สิ่งที่จะทำ (ดีบั๊กแบบเห็นผลทันที)

เพิ่ม **แถบดีบั๊กชั่วคราว** ที่แสดงเฉพาะบน preview host เท่านั้น (ไม่แสดงบนโดเมนจริง):

1. กล่องเล็กมุมล่างของจอ แสดงผลการตรวจแต่ละการ์ดแบบเรียลไทม์ เช่น
   ```text
   previewHost: true
   แจ้งซ่อม: ควรแสดง / ไม่แสดง เพราะ...
   ดูคิว: ไม่แสดง เพราะไม่มีงานในลิสต์ / เพราะ ack แล้ว
   ```
2. เปิดหน้าตั้งค่าและหน้างานปัจจุบันใน preview แล้วอ่านค่าจากแถบนี้ — จะรู้ทันทีว่าเงื่อนไขไหนที่ทำให้การ์ดไม่ขึ้นบนบัญชีของคุณ
3. เมื่อเจอสาเหตุ แก้ให้ถูกจุด แล้วเอาแถบดีบั๊กออก

## ขอบเขต

- แถบดีบั๊กแสดงเฉพาะ preview host เท่านั้น ผู้ใช้จริงบนโดเมนจริงไม่เห็น
- ไม่แตะ flow, API, หรือรูปแบบการ์ดเดิม
