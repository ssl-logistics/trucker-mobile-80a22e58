# เปลี่ยนหน้าต่างขั้นตอนงาน จากเด้งขึ้นด้านล่าง เป็นหน้าต่างกลางจอ (แก้แค่หน้าตา)

## สิ่งที่คนขับจะเห็น
- กด "อัปเดท" ที่จุดไหนก็ได้ในหน้างาน (รับตู้, จุดรับ/ส่งสินค้า, จุดเพิ่ม, จุดดรอป, คืนตู้) ขั้นตอนจะขึ้นเป็นหน้าต่างกลางจอ ไม่เลื่อนขึ้นมาจากด้านล่างแล้ว
- พื้นหลังมืดลง เห็นหน้างานอยู่ด้านหลัง
- หน้าต่างกว้างเกือบเต็มจอ สูงไม่เกินประมาณ 90% ของจอ มุมโค้งทั้ง 4 ด้าน เลื่อนดูเนื้อหาข้างในได้ ไม่มีแถบจับด้านบน
- ข้างในเหมือนเดิมทุกอย่าง: หัวข้อ + ปุ่มย้อนกลับ, ดูค่าใช้จ่าย / เพิ่มค่าใช้จ่าย / เอกสาร / แจ้งปัญหา, ถ่ายรูป, สแกนตู้, เซ็นชื่อ
- หน้าต่างเช็คอินจุดเพิ่ม และหน้าต่างดู/เพิ่มค่าใช้จ่ายที่เปิดซ้อน ก็เปลี่ยนเป็นกลางจอเหมือนกัน
- ปิดได้โดย กดย้อนกลับ, แตะพื้นหลัง หรือทำขั้นตอนเสร็จ แล้วกลับมาหน้างานพร้อมสถานะใหม่

## ไม่เปลี่ยน
- ขั้นตอน, ปุ่มล็อก, ข้อมูลที่ส่งไประบบ เหมือนเดิม
- หน้างานปัจจุบัน "ดูข้อมูลงาน" ยังเปิดเต็มหน้า
- เปิดจากแจ้งเตือน / ลิงก์ตรง ยังเป็นหน้าเต็ม

## Technical details
- `JobStepRoutes.tsx`: เปลี่ยน `Sheet side="bottom"` เป็น `Dialog`/`DialogContent` (w-[94vw] max-w-lg, max-h-[90vh], overflow-y-auto, rounded-2xl, p-0, ซ่อนปุ่ม X เดิม, `[&_.min-h-screen]:min-h-full`), ลบแถบจับ; logic `bgRef`/`close`/`reloadKey` คงเดิม
- `ExtraPointCheckinSheet.tsx`: เปลี่ยนเป็น Dialog กลางจอขนาดเดียวกัน
- `JobActionButtons.tsx` (expenseMode="sheet"): Sheet ค่าใช้จ่ายเปลี่ยนเป็น Dialog กลางจอ ซ้อนได้
