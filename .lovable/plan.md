# เมนูเอกสาร: เพิ่มส่วน "ดูเอกสารที่แนบแล้ว" (ทั้งหน้างานปัจจุบันและหน้าประวัติ)

## ผลที่จะได้

หน้าต่าง "เอกสาร" (ที่เปิดจากปุ่มเอกสารบนหน้ารายละเอียดงาน) จะมี 2 ส่วน:

1. **เอกสารที่แนบแล้ว** — ดึงรายการเอกสารของออเดอร์นั้นจากระบบหลังบ้านมาแสดง (ชื่อเอกสาร/หัวข้อ, ชื่อไฟล์, เวลาที่แนบ) กดที่รายการเพื่อเปิดดูไฟล์ได้ (รูปเปิดดูในหน้าต่างขยาย, PDF เปิดในแท็บใหม่)
2. **แนบเอกสารใหม่** — ฟอร์มอัปโหลดเดิม ทำงานเหมือนเดิมทุกอย่าง

ใช้ได้ทั้งหน้างานปัจจุบันและหน้าประวัติ (ปุ่มเอกสารแสดงอยู่แล้วทั้งสองหน้า — หน้าประวัติจะเป็น "ดูอย่างเดียว": แสดงรายการเอกสาร แต่ซ่อนส่วนแนบไฟล์ใหม่)

หลังอัปโหลดสำเร็จ รายการจะรีเฟรชทันทีเพื่อให้เห็นไฟล์ที่เพิ่งแนบ

## รายละเอียดการแก้

### 1. `src/lib/externalApi.ts`
- เพิ่มฟังก์ชัน `getDriverDocuments(orderNumber)` → GET `driver-documents?order_number=...` (ทดสอบแล้วว่า endpoint นี้มีอยู่จริง ตอบ `{ success, order_number, count, data: [] }`)

### 2. `src/components/job/JobDocumentsSheet.tsx`
- ดึงรายการเอกสารเมื่อเปิดหน้าต่าง (fetch on open) ด้วย `getDriverDocuments(baseOrderNumber)`
- รองรับโครงสร้างข้อมูลที่ยืดหยุ่น (ตอนนี้ยังไม่มีออเดอร์ที่มีเอกสารจริง เลย parse แบบปลอดภัย: รองรับทั้งรายการไฟล์แยกและกลุ่มที่มี `files` ย่อย, อ่าน `file_url`/`file_name`/`title`/`created_at` ถ้ามี)
- แสดงสถานะ: กำลังโหลด (skeleton), โหลดไม่สำเร็จ (ข้อความ + ปุ่มลองใหม่), ไม่มีเอกสาร (ข้อความ "ยังไม่ได้แนบเอกสาร" ที่มีอยู่)
- กดรายการ → รูปภาพเปิดดูเต็มใน dialog, PDF/ไฟล์อื่นเปิดแท็บใหม่
- อัปโหลดสำเร็จ → รีเฟรชรายการอัตโนมัติ
- รับ prop `readOnly` (หรือเช็กจาก history context) → โหมดอ่านอย่างเดียวซ่อนฟอร์มแนบไฟล์ แสดงเฉพาะรายการ
- `resetForm()` เดิมยังล้างเฉพาะฟอร์ม ไม่ล้างรายการที่ดึงมา

### 3. `src/components/job/JobActionButtons.tsx`
- ส่งโหมดอ่านอย่างเดียว (`isFromHistory`) เข้า `JobDocumentsSheet`

### 4. `src/contexts/LanguageContext.tsx`
- คีย์ใหม่ครบ 4 ภาษา (th/en/ko/zh): `docs.attachedList` (เอกสารที่แนบแล้ว), `docs.loadFailed`, `docs.retry`, `docs.viewFile`

## ไม่แตะ

- ฟอร์มอัปโหลดเดิม, flow เช็คอิน/SOP/POD, QTruck, การเงิน
- ไม่แก้ฝั่งหลังบ้าน (ใช้ GET endpoint ที่มีอยู่แล้ว)

## หมายเหตุ

- ตอนนี้ยังไม่มีออเดอร์ที่มีเอกสารจริงในระบบ (ทดสอบ GET แล้วได้ `data: []` ทุกออเดอร์) — โค้ดจะ parse แบบยืดหยุ่นและจะตรวจสอบกับข้อมูลจริงอีกครั้งหลังมีการแนบเอกสารจริง
- ตรวจ `npx tsgo --noEmit -p tsconfig.app.json` + build ต้องผ่าน
