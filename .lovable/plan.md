# เช็คอินเสร็จแล้ว ปุ่มเปลี่ยนทันที และหน้างานอยู่ที่เดิม (งานในประเทศ)

## ปัญหา
หลังเช็คอิน/ส่งงานในหน้าต่างเสร็จ หน้าต่างปิดแล้ว หน้างานด้านหลังโหลดใหม่ทั้งหน้า ทำให้:
- ปุ่มสถานะเปลี่ยนช้า (รอโหลดข้อมูลใหม่)
- จอเด้งกลับไปบนสุด แล้วค่อยเลื่อนลงมาที่จุดเดิม

## สิ่งที่จะแก้ (แก้แค่หน้าตา/การแสดงผล)
- ปิดหน้าต่างแล้ว หน้างานไม่โหลดใหม่ทั้งหน้า จออยู่ที่ตำแหน่งเดิม ไม่เด้งขึ้นบน
- ปุ่มของจุดที่เพิ่งเช็คอินเปลี่ยนสถานะทันที (ใช้ข้อมูลเช็คอินที่เพิ่งบันทึกในเครื่อง) แล้วดึงข้อมูลล่าสุดเงียบๆ ด้านหลัง
- ไม่เลื่อนจออัตโนมัติซ้ำหลังปิดหน้าต่าง

## ไม่เปลี่ยน
- ขั้นตอนเช็คอิน / SOP / POD / COD และข้อมูลที่ส่งไประบบ
- เปิดจากแจ้งเตือน/ลิงก์ตรง ยังเป็นหน้าเต็มเหมือนเดิม

## Technical details
- `JobStepRoutes.tsx`: เลิกใช้ `reloadKey` remount ของ `<Routes>`; ตอนปิดหน้าต่างให้ `window.dispatchEvent(new Event('job-step-closed'))` แทน
- `DomesticJobDetail.tsx`: ฟัง `job-step-closed` → รวม optimistic check-in cache ทันที แล้ว silent refetch check-ins/job (ไม่ set loading, ไม่ reset `autoScrolledOrderRef`) จอเลยคงตำแหน่ง
- ตรวจด้วย Playwright: เลื่อนลงไปจุดส่ง เช็คอินในหน้าต่าง ปิด แล้ว scrollTop เท่าเดิม และปุ่มเปลี่ยนทันที
