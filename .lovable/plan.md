# งานต่างประเทศ: เพิ่มขั้นสแกน QR (ไม่แตะ flow เดิม)

## หลักการ
ไม่แก้ไข flow เดิมเลย — การส่ง API หลังบ้าน (เช็คอิน, SOP, POD, สถานะคิว processing/completed) คงเดิมทั้งหมด หน้าบ้านเพิ่มแค่ขั้นสแกน QR อย่างเดียว

## จุดที่เพิ่มขั้นสแกน (ข้ามได้)
- **Booking (ขาออก)**: การ์ด "จุดรับสินค้า" — หลังเช็คอิน ปุ่มหลักเปลี่ยนเป็น "สแกนโหลดสินค้า" แล้วค่อยเป็น "แนบหลักฐาน"
- **BL (ขาเข้า)**: การ์ด "จุดส่งสินค้า" — หลังเช็คอิน ปุ่มหลักเปลี่ยนเป็น "สแกนโหลดสินค้า" ก่อนเข้าหน้าอัปโหลดเอกสารขนส่ง/ยืนยัน POD
- จุดรับตู้เปล่า/ตู้หนักและจุดคืนตู้ไม่เพิ่ม

## พฤติกรรมการสแกน (เหมือนงานในประเทศ)
- สแกนสำเร็จ → ยิงเส้น queues/scan ของระบบคิว (external_ref = เลขออเดอร์, station_token = ค่าจาก QR) แบบไม่รอผล + แถบเขียว "สแกนโหลดสินค้าแล้ว (เวลา)" บนการ์ดนั้น
- กด "ข้าม" หรือกล้องเปิดไม่ได้ → ไปขั้นถัดไปได้เลย ไม่ยิงเส้น scan
- สถานะสแกนเก็บต่อออเดอร์ในเครื่อง — ครั้งถัดไปไม่ถามซ้ำ

## Technical details
- `DomesticJobDetail.tsx`:
  - `needsLoadingQr` (การ์ดจุดรับสินค้า): เปลี่ยนจาก `!job.bl_no && !job.booking_no` เป็น `!job.bl_no`
  - แถบเขียวบนการ์ดจุดรับสินค้า (~2013): เงื่อนไขเดียวกัน
  - การ์ดจุดส่ง (~2045+): เพิ่ม `needsLoadingQrDelivery = !!job.bl_no && isCheckedIn && !isPodCompleted && !loadingQr && !isFromHistory` — ปุ่มหลักเปลี่ยน label เป็น loadingQr.button และเปิด LoadingQrScanDialog แทน navigate; แถบเขียวเมื่อสแกนแล้ว
  - `handleLoadingQrDone` ใช้ของเดิม (บันทึก localStorage + ยิง qtruck-queue-scan)
- ไม่แตะ DeliveryDetailPage / DeliverySOPCheckInPage / edge function / i18n
