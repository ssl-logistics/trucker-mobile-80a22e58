# ผลตรวจ: การ์ดแนะนำใน preview

## สิ่งที่ตรวจแล้ว (ทดสอบจริงในเครื่อง)
จำลองบัญชีที่ **เคยกด "รับทราบ" แล้ว** เปิดหน้าตั้งค่าใน preview — การ์ดแนะนำเมนูแจ้งซ่อม **แสดงขึ้นมาปกติ** ตามที่ออกแบบ (preview แสดงทุกครั้ง ไม่สนการกดรับทราบเก่า) ยืนยันว่าโค้ดล่าสุดทำงานถูกต้อง

## ข้อสรุปสาเหตุที่บัญชีของคุณยังไม่เห็น
1. **แท็บ preview ยังเป็นโค้ดเก่า** — การแก้เพิ่งเสร็จ ถ้าแท็บ preview เปิดค้างไว้ก่อนแก้ ต้องกดรีเฟรชหน้า preview 1 ครั้ง
2. **การ์ด "ดูคิว" ขึ้นเฉพาะเมื่อมีงานในลิสต์** — การ์ดนี้ผูกกับงานใบแรก ถ้าหน้างานปัจจุบันยังโหลดงานไม่เสร็จหรือไม่มีงาน การ์ดจะยังไม่แสดง
3. การ์ดแต่ละใบแสดงเฉพาะหน้าของตัวเอง: แจ้งซ่อม = หน้าตั้งค่า, เอกสาร = หน้ารายละเอียดงาน, ดูคิว = หน้างานปัจจุบัน, สำรองจ่าย/ไมล์น้ำมัน = หน้าเพิ่มค่าใช้จ่าย, ลายเซ็น = หน้าต่างเซ็นชื่อ

## แผนดำเนินการ
1. ไม่มีการแก้โค้ดเพิ่ม — ตรวจสอบแล้วว่าทำงานถูกต้อง
2. ขอให้ทดสอบ: กดรีเฟรชหน้า preview แล้วเปิดหน้าตั้งค่า → การ์ด "เมนูใหม่! แจ้งซ่อมรถ" ต้องขึ้นทันที
3. ถ้ารีเฟรชแล้วยังไม่ขึ้น แจ้งว่าหน้าไหน/เมนูไหน ผมจะตรวจเจาะจงต่อ
