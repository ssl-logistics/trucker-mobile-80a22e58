# หน้าสรุปยอดเงิน: ให้ข้อมูลอัปเดตทันที

## สิ่งที่ผู้ใช้จะเห็น
- เปิดหน้าแล้ว ข้อมูลเดิมขึ้นก่อนเหมือนเดิม แต่แต่ละงานจะอัปเดตเป็นข้อมูลล่าสุดทันทีที่โหลดเสร็จ ไม่ต้องรอให้ครบทุกงาน
- งานที่เคลียร์แล้วหรือไม่มียอดค้างแล้ว หายจากรายการทันที
- ยอดเก็บแล้ว/ค้าง และสถานะงาน (กำลังวิ่ง/ปิดงานแล้ว) ตรงกับข้อมูลล่าสุด
- เคลียร์ยอดสำเร็จ งานหายทันทีและหน้าโหลดข้อมูลใหม่
- กลับเข้าแอปหรือกลับมาหน้านี้ ข้อมูลรีเฟรชเอง และมีปุ่มดึงข้อมูลใหม่ข้างหัวข้อ
- ถ้าโหลดไม่สำเร็จ แสดงข้อมูลเดิมพร้อมข้อความว่าอาจไม่ใช่ข้อมูลล่าสุด

## Technical
- `usePendingCodClears`: ใช้ `onProgress` ทุกครั้ง โดยรวมกับ cache: งานที่โหลดแล้วใช้ค่าใหม่ ส่วนงานที่ยังไม่ถึงใช้ค่าเดิม; เมื่อจบให้แทนที่ทั้งหมด
- รีเฟรชเมื่อ `visibilitychange` / focus; รีเฟรชหลังเคลียร์ยอด และลบงานนั้นออกจาก state และ cache ทันที
- `getCodClear` / `getDriverCheckins`: ส่งพารามิเตอร์กันแคช (`_t`) และให้ proxy ตอบ `Cache-Control: no-store`
- ตั้ง flag error เมื่อโหลดไม่สำเร็จ; เพิ่มข้อความใน 4 ภาษา
- เพิ่ม test สำหรับการรวมข้อมูลใหม่กับ cache (งานที่เคลียร์แล้วหายไป, ยอดใหม่แทนยอดเดิม)
