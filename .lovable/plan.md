# ให้งานที่ "ส่งครบแล้ว" เคลียร์ยอดได้ทันที (เฉพาะหน้าสรุปยอดเงิน)

## สิ่งที่จะเปลี่ยน
- งานที่ส่งครบแล้ว (completed / delivered) จะขึ้นเป็น "พร้อมเคลียร์" และกดไอคอนกระเป๋าเงินได้ ไม่ต้องรอปิดงาน
- ข้อความ "ยังเคลียร์ไม่ได้: งานยังไม่ปิด" จะแสดงเฉพาะงานที่ยังวิ่งอยู่เท่านั้น
- ป้ายสถานะ "ส่งครบแล้ว" / "ปิดงานแล้ว" ยังแสดงเหมือนเดิม
- หน้าอื่นและการแจ้งเตือนไม่เปลี่ยน
- ระบบหลักรองรับแล้ว: หลังแก้จะทดสอบส่งเคลียร์จริงกับ OR20261027001 เพื่อยืนยัน

## รายละเอียดทางเทคนิค
- `src/lib/codClear.ts`: เงื่อนไข canClear รับ `closed`, `completed`, `delivered`
- `src/pages/CodClearPage.tsx`: ปลดล็อกปุ่มสำหรับ completed/delivered
- ปรับเทสต์: completed → canClear true
