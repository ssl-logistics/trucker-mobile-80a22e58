# ลดการมองเห็นหน้า LINE Callback บนมือถือ

หน้า `/auth/line/callback` (ไฟล์ static) จะแสดงในเบราว์เซอร์ในแอปหลัง LINE redirect กลับมา ปัจจุบันผู้ใช้เห็นหน้าเขียวพร้อมกล่อง debug และปุ่ม "เปิดแอป The Trucker" ค้างอยู่จนกว่าจะกดเอง

## เป้าหมาย
ให้ผู้ใช้แทบไม่เห็นหน้านี้ — กลับเข้าแอปอัตโนมัติให้เร็วที่สุด และไม่โชว์ข้อมูลเทคนิค

## สิ่งที่จะทำ

1. ซ่อนกล่อง debug จากผู้ใช้ทั่วไป
   - ยังเก็บ log ไว้ใน `console.log` เหมือนเดิม
   - แสดงกล่อง debug เฉพาะเมื่อเปิด URL ด้วย `?debug=1` (สำหรับตรวจสอบภายหลัง)

2. ยิง deep link ทันทีตั้งแต่วินาทีแรก
   - ปัจจุบันหน่วง 500ms (Android) / 800ms (iOS) → เปลี่ยนเป็นยิงทันทีเมื่อสคริปต์ทำงาน
   - ไม่รอ bridge write ให้เสร็จก่อน (bridge จะยิงคู่ขนานอยู่แล้ว)
   - ถ้ายังไม่กลับแอปภายในประมาณ 1.2 วินาที ค่อยลองซ้ำอีกครั้ง (Android ลอง intent URL ต่อ)

3. ปรับหน้าให้เป็นแค่หน้าเปลี่ยนผ่าน
   - เริ่มต้นแสดงเพียงสปินเนอร์เล็ก ๆ บนพื้นเขียว ไม่มีข้อความ "สำเร็จ" และไม่มีปุ่มใหญ่
   - ถ้าหลังผ่านไป ~2.5 วินาทีแล้วหน้ายังมองเห็นอยู่ (deep link ไม่ทำงาน) ค่อยเผยข้อความ + ปุ่ม "เปิดแอป The Trucker" และลิงก์ใช้งานต่อบนเว็บตามเดิม
   - ใช้ `document.visibilityState` เป็นตัวตัดสิน — ถ้าแอปเปิดสำเร็จ หน้าจะถูกซ่อนและไม่มีอะไรโผล่มาให้เห็น

4. ไม่แตะ logic การ auth
   - การเขียน bridge `line_pending_auth`, รูปแบบ payload base64url, intent URL และ fallback บนเว็บ คงเดิมทั้งหมด
   - การรับ deep link / `browserFinished` ฝั่งแอปไม่เปลี่ยน

## ไฟล์ที่แก้
- `public/auth/line/callback/index.html` (ไฟล์เดียว)

## หมายเหตุ
หน้านี้เป็นไฟล์ static ที่โฮสต์บนโดเมนเว็บ ดังนั้นหลัง Publish จะมีผลกับแอปที่ build ไปแล้วทันที ไม่ต้อง build APK/IPA ใหม่
