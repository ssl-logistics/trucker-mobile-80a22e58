# แก้การย้อนกลับจากงานในประวัติ

## สาเหตุที่ตรวจพบ

งานจากหน้าประวัติเปิดหน้ารายละเอียดพร้อมสถานะอ่านอย่างเดียวแล้ว แต่หน้าชั้นถัดไปบางหน้ายังย้อนกลับด้วยลิงก์แบบงานปัจจุบันและไม่ได้ส่งสถานะ `from=history` ต่อ เช่น หน้าเช็คอินจุดรับและหน้าเช็คอินตู้ นอกจากนี้ เมื่อโหลดข้อมูลงานไม่สำเร็จ บางหน้ายังส่งผู้ใช้ไป `/current-jobs` โดยตรง จึงเกิดอาการกดย้อนกลับแล้วหลุดไปหน้างานปัจจุบัน

## สิ่งที่จะทำ

1. ใช้ตัวตรวจสถานะประวัติส่วนกลางกับหน้ารายละเอียดและหน้าปฏิบัติงานทุกชั้น ไม่พึ่งเฉพาะพารามิเตอร์ใน URL
2. ส่งสถานะอ่านอย่างเดียวต่อทั้งใน URL และข้อมูลนำทางทุกครั้งที่เปิดจุดรับ, SOP, จุดส่ง, รับ/คืนตู้, สรุปรูป และค่าใช้จ่าย
3. ปรับปุ่มย้อนกลับในหน้าชั้นถัดไป:
   - ถ้ามาจากประวัติ ให้กลับหน้ารายละเอียดงานเดิมโดยยังเป็นอ่านอย่างเดียว
   - จากหน้ารายละเอียดหลัก ให้กลับ `/job-history`
   - ถ้าโหลดงานประวัติไม่สำเร็จ ให้กลับ `/job-history` แทน `/current-jobs`
4. ปิดการเปลี่ยนเส้นทางอัตโนมัติของหน้าที่พบว่าเช็คอินแล้วไม่ให้ทำสถานะประวัติหลุด
5. คงพฤติกรรมของงานปัจจุบันไว้เหมือนเดิมทั้งหมด

## ตรวจสอบหลังแก้

- เปิดงานในประเทศและต่างประเทศจาก `/job-history`
- เข้าและย้อนกลับจากจุดรับ, SOP, จุดส่ง, รับตู้, คืนตู้, หน้าสรุป และค่าใช้จ่าย
- ทุกหน้าต้องคงโหมดอ่านอย่างเดียว และย้อนกลับถึงหน้าประวัติ ไม่ไป `/current-jobs`
- ทดสอบงานปัจจุบันแยกอีกครั้งเพื่อยืนยันว่าปุ่มและเส้นทางเดิมไม่เปลี่ยน
