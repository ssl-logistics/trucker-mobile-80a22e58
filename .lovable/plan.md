# แนบเอกสารได้ทีละไฟล์ (แนบใหม่ = ลบอันเดิม)

ตอนนี้งานเอกสาร ("เอกสาร" ในหน้างาน) แนบได้หลายไฟล์พร้อมกัน แล้วสะสมไว้ในลิสต์ "ไฟล์ที่เลือก (รออัปโหลด)" เช่น 7820.xlsx กับ 531(1).xlsx จะอยู่ด้วยกันจนกว่าจะกดยืนยัน

จะแก้ให้เหลือไฟล์เดียวที่รอส่ง: เลือกไฟล์ใหม่เมื่อไร ไฟล์ที่รออยู่เดิมจะถูกลบออกทันที

## จะทำอะไร

1. **เปลี่ยนพฤติกรรมตอนเลือกไฟล์** — จาก "ต่อท้ายลิสต์" เป็น "แทนที่ทั้งลิสต์" เหลือไฟล์ล่าสุดไฟล์เดียว ครอบคลุมทั้ง 3 ทาง: ถ่ายรูปใหม่ / เลือกจากแกลเลอรี / แนบไฟล์จากเครื่อง
2. **ปิดการเลือกหลายไฟล์ในหน้าต่างเลือกไฟล์ของเครื่อง** — จังหวะกดเลือกจากเครื่องหรือจากแกลเลอรี จะเลือกได้ทีละไฟล์เดียว ไม่ขึ้นลิสต์หลายไฟล์ให้กดค้างเลือกอีก
3. **หน้าตาหลังเลือก** — แสดงไฟล์ที่รอส่งเพียงรายการเดียว พร้อมปุ่มกากบาทลบ และปุ่ม "อัปโหลดเอกสาร" เหมือนเดิม ถ้ายังไม่ได้กรอกหัวข้อ ปุ่มอัปโหลดยังกดไม่ได้เหมือนเดิม
4. **การส่งข้อมูลไม่เปลี่ยน** — ยังคงส่งไป API `driver-documents` พร้อม รหัสออเดอร์ หัวข้อ รายละเอียด ชื่อคนขับ และไฟล์แบบ base64 (รูปแบบเดิมทุกอย่าง) เพียงแต่ `files_base64` จะมีไฟล์เดียว
5. **ข้อความ** — ใช้คำเดิมที่รองรับ 4 ภาษา (ไทย/อังกฤษ/เกาหลี/จีน) ไม่ต้องเพิ่มข้อความใหม่

## ผลที่ผู้ใช้จะเห็น

- เลือกไฟล์แล้วเห็นรายการรอส่ง 1 ไฟล์
- เลือกไฟล์ใหม่ทับ → ไฟล์เดิมหาย เหลือไฟล์ใหม่
- ไฟล์ที่ส่งสำเร็จแล้วยังแสดงในรายการ "แนบแล้ว" เหมือนเดิม ไม่หาย
