# หน้าแรก: ไม่โหลดใหม่ทุกครั้ง + ไอคอน/รูปขึ้นเร็วขึ้น

## ปัญหาที่พบ
- หน้าแรกมีแคชรายการงานอยู่แล้ว แต่ทุกครั้งที่เปิดหน้า ระบบยิงโหลดแบบ "ไม่เงียบ" ทำให้ขึ้นวงกลม "กำลังโหลด..." ทุกครั้งเมื่อแคชว่าง (0 รายการ) — ตามภาพที่ส่งมา
- รูปในแถบหัวไฟล์ใหญ่: พื้นหลังหัว ~343KB, ไอคอนตลาด ~900KB จึงขึ้นช้า; ไอคอนเมนูโหลดหลังหน้าแสดงแล้ว

## สิ่งที่จะแก้
1. **ไม่โหลดใหม่ทุกครั้ง**
   - เก็บเวลาที่โหลดล่าสุดไว้คู่กับแคช ถ้าเปิดหน้าแรกซ้ำภายใน 60 วินาที ใช้แคชเลย ไม่ยิงใหม่
   - ถ้ามีแคช (แม้ว่าเป็น 0 รายการ) ให้รีเฟรชเบื้องหลังแบบเงียบ ไม่ขึ้นวงกลมโหลด
   - วงกลมโหลดจะขึ้นเฉพาะครั้งแรกที่ยังไม่เคยมีแคชเลย
   - การรีเฟรชอัตโนมัติตามรอบเดิม / ตอนกลับมาที่แอป ยังทำงานเหมือนเดิม
2. **ไอคอนและรูปขึ้นเร็ว**
   - บีบอัดรูปใหญ่ (พื้นหลังหัว, ไอคอนตลาด) เป็นไฟล์เล็กลงมาก (webp) หน้าตาเหมือนเดิม
   - สั่งให้เบราว์เซอร์โหลดรูปหัวและไอคอนเมนูล่วงหน้าตั้งแต่เปิดแอป
   - จำลิงก์รูปโปรไฟล์ไว้ ไม่ต้องขอลิงก์ใหม่ทุกครั้งที่เข้าหน้าแรก (ระหว่างนั้นแสดงตัวอักษรย่อ)

## Technical details
- `src/pages/Home.tsx`: เพิ่มคีย์ `home_cache_ts_v1_<driverId>`; ใน useEffect initial load ใช้ `silent = hasCache`, ข้ามการ fetch ถ้า `now - ts < 60s`; `writeHomeCache` อัปเดต ts; spinner เงื่อนไข `isLoadingFactoryJobs && !hasCache`
- `src/assets`: สร้าง `cover-header.webp`, `market-icon-new.webp` (resize ตามขนาดแสดงจริง) แล้วเปลี่ยน import ใน `AppHeader.tsx`
- `AppHeader.tsx`: `<img decoding="async" fetchpriority="high">` สำหรับไอคอนเมนู; preload รูปหัว/ไอคอนตอนโหลดแอป (`new Image()` ใน App หรือ `<link rel=preload>`)
- แคช presigned URL รูปโปรไฟล์ใน localStorage พร้อมเวลาหมดอายุ
- ไม่แตะเส้น API หรือตรรกะการรับงาน
