# จุดเพิ่ม: ปุ่มแนบรูป/อัปเดตสถานะบนการ์ด + ล็อกตามเอกสาร

## ปัญหาตอนนี้
- การ์ดจุดดรอปตู้ / รับตู้ที่ดรอปไว้ / จุดส่งสินค้าเพิ่ม มีแค่ปุ่มโทรและเส้นทาง ปุ่มเช็คอิน (แนบรูป) ซ่อนอยู่ในหน้ารายละเอียดจุด คนขับเลยไม่เห็น
- กฎล็อกบางข้อยังไม่ครบตามเอกสาร

## สิ่งที่จะเปลี่ยน
1. **ปุ่ม "อัปเดตสถานะ" บนการ์ดจุดเพิ่มทุกใบ** วางแถวเดียวกับโทร / เส้นทาง เหมือนการ์ดหลัก
   - กดแล้วเปิดหน้าแนบรูป (บังคับอย่างน้อย 1 รูป) แล้วส่งไป `driver-checkin` ด้วยประเภทตามเอกสาร: ดรอปตู้ = `extra_drop`, รับตู้ที่ดรอปไว้ = `extra_drop_pickup`, จุดสินค้าเพิ่ม = `extra_cargo` พร้อม `extra_point_sequence`
   - ล็อก (สีเทา กดไม่ได้) เมื่อยังไม่ถึงขั้น, ซ่อนเมื่อเสร็จแล้ว, ซ่อนเมื่อเปิดจากประวัติ
   - กดตัวการ์ดยังเข้าหน้ารายละเอียดจุดได้เหมือนเดิม
2. **กฎล็อกตามเอกสาร (เฉพาะงานที่มีจุดเพิ่ม)**
   - ตู้ถูกดรอปไว้ที่ลาน (ดรอปแล้วยังไม่รับคืน): ล็อกจุดรับ/ส่งสินค้าหลัก, SOP/POD, จุดสินค้าเพิ่ม และจุดดรอปอื่น — เปิดให้กดได้แค่ "รับตู้ที่ดรอปไว้" ของจุดนั้น
   - คืนตู้: ปลดล็อกเมื่อจุดสินค้าเพิ่มครบ **และ** ทุกจุดดรอปทั้งดรอปแล้วและรับคืนแล้ว (ตอนนี้เช็คแค่จุดสินค้า)
   - ถ้าระบบหลักส่ง `extra_points_summary` มา ใช้ `can_continue_cargo` / `can_return_container` ประกอบด้วย
3. **สถานะจุด** อ่านเพิ่มจาก `is_dropped`, `is_picked_up`, รูปจาก `dropped_photo_urls` / `picked_up_photo_urls` / `completed_photo_urls` แสดงในหน้ารายละเอียดจุด
4. **ข้อความผิดพลาด** แปลรหัสจากระบบหลักเป็นภาษาคน: ต้องแนบรูป, ไม่พบจุด, ยังไม่ได้ดรอป, ตู้ยังอยู่ที่ลานดรอป, จุดยังไม่ครบก่อนคืนตู้

งานที่ไม่มีจุดเพิ่ม และงานในประเทศ: เหมือนเดิมทั้งหมด

## Technical details
- `DomesticJobDetail.tsx`: ส่ง `leadingAction={extraCheckinButton(done, locked, () => openExtraCheckin(...))}` ให้ ExtraPointCard ทั้ง drop และ cargo; ปุ่มใช้ label `jobDetail.updateStatus`
- `atDrop` = จุดที่ `dropState === 'dropped'`; ล็อก drop อื่น + cargo + เส้นหลักเมื่อ `atDrop`; `allDeliveriesCompleted = mainCargoCompleted && xcDone && allDropsPickedUp`
- `extraPoints.ts`: `dropState` รองรับ `is_dropped`/`is_picked_up`; เพิ่ม `canReturnContainer(job, checkins)` ใช้ summary ถ้ามี; อัปเดตเทสต์ (คืนตู้ล็อกเมื่อดรอปยังไม่รับคืน, `is_dropped` นับเป็นดรอปแล้ว)
- `ExtraPointCheckinPage.tsx`: map `error_code` → ข้อความ 4 ภาษา
- `ExtraPointDetailPage.tsx`: รวมรูปจาก 3 ฟิลด์
