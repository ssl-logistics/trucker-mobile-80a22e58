# แก้งานค้างในหน้าแรกหลังกดรับงาน/เริ่มงาน

## สาเหตุ (จากโค้ด `src/pages/Home.tsx`)
1. ตอนกดรับ/เริ่มงาน แอปลบงานออกจากรายการบนจอ แต่ **ไม่ได้ลบออกจากรายการที่จำไว้ในเครื่อง** — กลับมาหน้าแรกจึงเห็นงานเดิมจากที่จำไว้
2. ถ้าข้อมูลที่จำไว้อายุไม่ถึง 60 วินาที แอป **ข้ามการดึงใหม่** — งานค้างจึงไม่หายเอง
3. ระบบงานภายนอกอาจยังส่งงานนั้นกลับมาอีกชั่วครู่หลังรับ ทำให้โผล่ซ้ำ

## สิ่งที่จะแก้
1. ทุกจุดที่รับ/เริ่มงานสำเร็จ (ฟรีแลนซ์รับงานเช่าด่วน, เริ่มงานคนขับบริษัท/ภายนอก, รับงานโรงงาน) → ลบงานออกจากรายการที่จำไว้ด้วย ไม่ใช่แค่บนจอ
2. จำ "งานที่เพิ่งรับ" ไว้ในเครื่อง 30 นาที และกรองทิ้งทั้งตอนอ่านรายการที่จำไว้และตอนได้ข้อมูลใหม่จากระบบ — งานจะไม่เด้งกลับมา
3. หลังรับงาน ล้างเวลา "เพิ่งดึง" เพื่อให้กลับมาหน้าแรกครั้งต่อไปดึงข้อมูลใหม่ทันที
4. ฟรีแลนซ์รับงานเช่าด่วน: ลบงานออกจากจอทันทีหลังสำเร็จ (ตอนนี้รอโหลดใหม่ทั้งชุด)

ไม่เปลี่ยนกฎการกรองงานอื่น ๆ และไม่แตะหน้างานปัจจุบัน

## รายละเอียดทางเทคนิค
- helper ใน Home.tsx: `markJobTaken(driverId, orderCode)` เขียน `home_taken_orders_v1_<driverId>` (map orderCode → timestamp, TTL 30 นาที), แล้ว filter + rewrite `home_jobs_cache_v1_` และ `home_factory_jobs_cache_v1_`, และรีเซ็ตเวลา cache ให้ `homeCacheAge` เกิน 60s
- `readHomeCache` และผลลัพธ์ `loadJobs`/`loadFactoryJobs` กรอง order_code ที่อยู่ใน taken set
- เรียก `markJobTaken` ใน `confirmJobAcceptance` (+ `setJobs(prev => prev.filter(...))`), `handleStartAssignedJob` (บรรทัด ~1027), `handleAcceptFactoryJob` (~1176)
- ตรวจด้วย Playwright: รับงาน → ไปหน้างานปัจจุบัน → กลับหน้าแรก งานต้องไม่แสดง
