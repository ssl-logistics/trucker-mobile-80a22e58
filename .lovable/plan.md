# เอาจุด "กำลังโหลด..." ด้านล่างออกจากโครงหน้าตอนโหลด

## สิ่งที่จะเปลี่ยน

หน้าโครงจาง ๆ ตอนเปิดข้อมูลงาน จะเหลือเฉพาะกล่องจำลอง (หัวเรื่อง, ป้าย, ไทม์ไลน์, รายละเอียด, ปุ่ม) โดยไม่มีแถวไอคอนหมุนพร้อมข้อความ "กำลังโหลด..." ที่ใต้ปุ่มอีกต่อไป

เป็นการแก้เฉพาะส่วนแสดงผล (UI) ในไฟล์เดียวกันที่เห็นบนจอ — ไม่แตะวิธีดึงข้อมูล, เงื่อนไขงาน, การนำทาง, ระบบภาษา หรือไฟล์อื่นใด

- ผลกับหน้ารายละเอียดงานในประเทศ/ต่างประเทศ และหน้ารายละเอียดงานประมูล เพราะใช้โครงเดียวกัน
- หัวเรื่องยังห่างขอบบน 14px เหมือนเดิม, วิธีดึงข้อมูลและเงื่อนไขงานไม่แตะ

## รายละเอียดทางเทคนิค

- `src/components/job-detail/JobDetailLoadingState.tsx`: ลบแถวที่บรรทัด 47-50 (`flex items-center justify-center gap-2 py-2 ...` พร้อม `Loader2` และ `t('common.loading')`)
- ลบสิ่งที่กลายเป็นของไม่ใช้แล้วในไฟล์เดียวกัน: `import { Loader2 } from 'lucide-react'` (บรรทัด 1), `import { useLanguage } ...` (บรรทัด 2) และ `const { t } = useLanguage();` (บรรทัด 8) — `noUnusedLocals` ปิดอยู่จึงไม่ทำให้ typecheck พัง แต่ปล่อยไว้จะเหลือ import เปล่า ๆ และถูก ESLint เตือน
- คง `aria-busy="true" aria-live="polite"` บนตัวครอบ (บรรทัด 11) ไว้ เพื่อให้โปรแกรมอ่านจอยังบอกสถานะว่ากำลังโหลดอยู่
- ข้อความ `common.loading` ในระบบภาษายังคงใช้อยู่ที่อื่น จึงไม่ตัดคำแปลทิ้ง
- เพิ่มรายการใน `roadmap.md`
