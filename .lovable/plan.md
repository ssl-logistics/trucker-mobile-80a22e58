# ต้องเซ็นชื่อก่อนผ่านทุกจุดรับ-ส่ง

## สิ่งที่ผู้ใช้จะเห็น
- ปุ่มยืนยันอยู่ที่เดิมและกดได้ตามเดิม พอกดแล้วจะมีหน้าต่าง "ลายเซ็นผู้รับ/ผู้ส่ง" ขึ้นมาก่อนบันทึก ใช้กับทุกจุด:
  - งานในประเทศ: จุดรับสินค้า, จุดส่งสินค้าทุกจุด
  - งานต่างประเทศ: ลานรับตู้, จุดโหลดสินค้า, จุดส่งสินค้า, ลานคืนตู้
- ในหน้าต่างมีช่องกรอกชื่อผู้เซ็น, พื้นที่ให้เซ็นด้วยนิ้ว, ปุ่ม "ล้าง", "ยกเลิก" และ "ยืนยัน"
- ปุ่ม "ยืนยัน" ในหน้าต่างจะกดไม่ได้จนกว่าจะเซ็น พอเซ็นแล้วกดยืนยัน ระบบจะบันทึกจุดนั้นตามขั้นตอนเดิม ถ้ากดยกเลิกจะไม่บันทึกและยังอยู่หน้าเดิม
- ข้อความทั้งหมดรองรับ 4 ภาษา (ไทย/อังกฤษ/เกาหลี/จีน)

## สิ่งที่ไม่เปลี่ยน
- ขั้นตอนเดิม ลำดับหน้า รูปถ่าย OCR และการส่งสถานะทั้งหมดทำงานเหมือนเดิม เพิ่มแค่ลายเซ็นที่ต้องกรอกก่อนกดยืนยัน

## Technical details
- คอมโพเนนต์ใหม่ `src/components/job/SignaturePad.tsx`: วาดบน canvas ด้วย pointer events (ไม่ต้องเพิ่ม library), ใช้ได้ทั้งการแตะบนมือถือและบน Safari, ส่งค่า `{ dataUrl, signerName, isEmpty }` กลับไป
- `SignatureDialog` (Dialog ครอบ SignaturePad) ใน `SOPCheckInPage.tsx` (รับ/โหลดสินค้า), `DeliverySOPCheckInPage.tsx` (ส่งสินค้า), `ContainerSOPPage.tsx` (รับ/คืนตู้): ตอนนี้ปุ่มยืนยันเดิมจะเปิด dialog ยืนยันเดิม แต่จะเปลี่ยนให้เปิด SignatureDialog ก่อน แล้วเมื่อเซ็นเสร็จจึงเรียก `handleConfirmSOP` เดิม (ส่งลายเซ็นเข้าไปด้วย) การตรวจสอบเดิมใน `handleConfirmClick` คงไว้ทั้งหมด
- ตอนยืนยัน: อัปโหลดรูปลายเซ็น PNG ผ่าน `upload-to-s3` ที่มีอยู่แล้ว (พร้อมกับรูปอื่นๆ) และใส่ฟิลด์ใหม่ `signature_url` และ `signer_name` เข้าไปใน payload เช็คอิน/SOP เดิม เป็นฟิลด์เสริม ระบบ TMS จะไม่สนใจฟิลด์นี้จนกว่าจะเพิ่มคอลัมน์รองรับฝั่งนั้น
- เก็บสำเนาลายเซ็นไว้ใน localStorage ด้วย key `signature_${order}_${pointKey}` ไว้ดูย้อนหลัง/ส่งซ้ำ
- เพิ่ม i18n keys ทั้ง 4 ภาษา
- ต้องแจ้งทีม TMS ให้เพิ่มรองรับ `signature_url` / `signer_name` ใน endpoint เช็คอิน
