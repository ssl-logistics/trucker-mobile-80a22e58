# แยกงานตลาด 3 ประเภท + ปุ่มตามประเภท (UI รอ API)

## เป้าหมาย
หน้าตลาด (`/market`) แยกงานเป็น 3 แท็บ ตาม `job_category`/`job_type` จาก API:
1. **งานด่วน (urgent / container)** — ปุ่ม "รับงาน" กดรับได้เลย
2. **ประมูล (auction)** — ปุ่ม "เสนอราคา" เปิดกล่องใส่ราคาตัวเลขช่องเดียว
3. **สนใจรับงาน (auction_reference)** — ปุ่ม "สนใจรับงาน"

API ปลายทางสำหรับ 3 การกระทำนี้ยังไม่มี — ทำ UI พร้อมใช้งานรอไว้ เมื่อกดยืนยันจะแจ้งเตือนว่าระบบกำลังเชื่อมต่อ (ไม่ยิง API ผิดระบบเหมือนเดิม) และโครงโค้ดเตรียมจุดต่อ API ไว้ชัดเจน

## การจำแนกประเภทงาน
```text
job_category = "container" หรือ job_type = "urgent"  → แท็บงานด่วน
job_category = "auction"                              → แท็บประมูล
job_category = "auction_reference"                    → แท็บสนใจรับงาน
อื่น ๆ / ไม่ระบุ                                       → แท็บประมูล (ค่าเริ่มต้น)
```

## สิ่งที่จะทำ

### 1. โครงข้อมูล — `src/pages/MarketPage.tsx`
- เก็บ `marketType: 'urgent' | 'auction' | 'interest'` ติดไปกับงานแต่ละใบตอนแปลงข้อมูลจาก API (ตามกติกาด้านบน)
- เพิ่ม state แท็บปัจจุบัน; การค้นหา + แบ่งหน้า (5 ใบ/หน้า) ทำงานภายในแท็บที่เลือก
- ส่วนหัวแสดงจำนวนงานของแท็บนั้น

### 2. แท็บ 3 อัน
- ใช้ `Tabs` ของ shadcn ใต้ช่องค้นหา: "งานด่วน" / "ประมูล" / "สนใจรับงาน" พร้อมจำนวนงานในแต่ละแท็บ
- ข้อความแท็บผ่าน i18n ครบ 4 ภาษา (th ค่าเริ่มต้น)

### 3. ปุ่มตามประเภทบนการ์ด
- `JobCard` รับ prop ประเภทงาน แล้วเปลี่ยนปุ่ม:
  - งานด่วน → "รับงาน" (สไตล์เดิม)
  - ประมูล → "เสนอราคา" (เปิดกล่องใส่ราคา)
  - สนใจรับงาน → "สนใจรับงาน" (กล่องยืนยันสั้น ๆ)

### 4. กล่องเสนอราคา (ประมูล)
- Dialog ใหม่: แสดงรหัสงาน + เส้นทาง, ช่องกรอกราคาตัวเลขช่องเดียว (ฟอร์แมตคอมมา, บาท), ปุ่มยืนยัน/ยกเลิก
- ตรวจค่า: ต้องเป็นตัวเลขมากกว่า 0
- กดยืนยัน → toast "บันทึกความสนใจแล้ว ระบบเสนอราคาจะเปิดเร็ว ๆ นี้" (UI รอ API)
- โค้ดเว้นจุดเรียก `submitTaladBid()` ไว้ใน `src/lib/taladApi.ts` ให้เติม endpoint ทีหลัง

### 5. งานด่วน + สนใจรับงาน
- กดแล้วเปิดกล่องยืนยัน (ใช้ `ConfirmJobDialog` เดิมปรับข้อความตามประเภท)
- ยืนยัน → toast แจ้งสถานะ "รอเปิดระบบ" เช่นกัน; เตรียม `acceptTaladJob()` / `expressTaladInterest()` ใน `taladApi.ts`

### 6. ภาษา
- เพิ่ม key ใน `LanguageContext.tsx` ครบ th/en/ko/zh: ชื่อแท็บ 3 อัน, ปุ่ม 3 แบบ, หัวกล่องเสนอราคา, placeholder ราคา, ข้อความแจ้งเตือน

## ไฟล์ที่แตะ
- `src/pages/MarketPage.tsx` — แท็บ, จำแนกประเภท, ต่อปุ่ม
- `src/components/home/JobCard.tsx` — ปุ่มตามประเภทงาน
- `src/components/home/ConfirmJobDialog.tsx` — รองรับข้อความตามประเภท (ถ้าจำเป็น)
- `src/lib/taladApi.ts` — stub `submitTaladBid` / `acceptTaladJob` / `expressTaladInterest`
- `src/contexts/LanguageContext.tsx` — คำแปล

## ไม่ทำ
- ไม่ยิง API รับงาน/เสนอราคา/สนใจจริง (รอ endpoint จากทีม Talad)
- ไม่แตะหน้า Home / งานปัจจุบัน
- ไม่เปลี่ยน edge function `get-talad-jobs`

## ตรวจสอบ
- build ผ่าน, เปิดหน้า /market ด้วยบัญชีฟรีแลนซ์ เห็น 3 แท็บ จำนวนตรงกับข้อมูลจริง (ด่วน 2 / ประมูล 3 / สนใจ 3), กดปุ่มแต่ละแบบได้และเห็น toast รอระบบ
