# ไอคอนลอย debug การ์ดแนะนำเมนู (เฉพาะ preview)

## สิ่งที่ยืนยันแล้ว

- โค้ดการ์ดแนะนำทั้ง 6 เมนูถูกต้อง: ใช้ `isPreviewHost()` ตัวกลาง (ครอบคลุม `id-preview--...`, `*.lovable.app`, localhost) — บน preview ควรแสดงทุกครั้ง
- ทดสอบจำลองบัญชีในเครื่อง: การ์ดแจ้งซ่อมในหน้าตั้งค่าแสดงปกติแม้เคยกดรับทราบแล้ว
- log จาก preview ของคุณ: แอปโหลดปกติ ไม่มี error — แต่ยังบอกไม่ได้ว่าทำไมการ์ดไม่ขึ้นบนบัญชีจริงของคุณ

## สิ่งที่จะทำ

สร้าง **ไอคอนลอยสำหรับ debug** ที่แสดงเฉพาะบน preview host เท่านั้น (โดเมนจริงไม่เห็น):

1. ไอคอนลอยมุมจอ (เช่น รูปเฟือง/แมลง) กดเพื่อเปิด/ปิดแผง debug
2. แผงแสดงผลการตรวจแบบเรียลไทม์:
   ```text
   previewHost: true/false
   บัญชี: <driver id>
   แจ้งซ่อม: ควรแสดง / ไม่แสดง (เหตุผล)
   เอกสาร: ...
   ดูคิว: ไม่แสดง เพราะไม่มีงานในลิสต์ / ack แล้ว / ...
   สำรองจ่าย, ไมล์/น้ำมัน, ลายเซ็น: ...
   ```
3. เปิดหน้าตั้งค่าและหน้างานปัจจุบันใน preview แล้วกดไอคอนนี้ — จะเห็นทันทีว่าเงื่อนไขไหนทำให้การ์ดไม่ขึ้นบนบัญชีของคุณ
4. เมื่อเจอสาเหตุ แก้ให้ถูกจุด (ไอคอน debug เก็บไว้ใช้ต่อบน preview หรือเอาออกภายหลังก็ได้)

## รายละเอียดเทคนิค

- สร้างคอมโพเนนต์ `PreviewDebugFab` ใหม่ ติดตั้งครั้งเดียวใน `App.tsx` ครอบทุกหน้า
- แสดงเฉพาะเมื่อ `isPreviewHost()` เป็น true — production/โดเมนจริงไม่ render
- อ่านค่า localStorage key ของการ์ดทั้ง 6 (`repair_menu_intro_ack:*` ฯลฯ) และ state ที่เกี่ยวข้อง ไม่แก้ flow หรือการ์ดเดิม

## ขอบเขต

- เพิ่มเฉพาะไอคอน/แผง debug ไม่แตะ flow, API, หรือรูปแบบการ์ดเดิม
