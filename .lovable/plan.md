# แสดง "รหัสตู้" บนการ์ดงานต่างประเทศ

## สาระสำคัญ
งานต่างประเทศที่มาจากรหัสออเดอร์ชุดเดียวกัน เช่น `OR20260922002/01` และ `OR20260922002/02`
ปจจุบันบนการ์ดแสดงแค้ป้าย "Booking demo0101" เหมือนกันทังคู๋ จิงดูไม่ออกว่่าคืองานไหน
ส่วนที่ต่างกันคือเลขท้ายหลัง `/` (01 / 02) ซึ่่งคือ "รหัสตู้" ที่คณตองการใหเห็น

## จะเพิ่่มอะไร
บนการ์ดงานต่างประเทศในหน้างานปจจุบัน จะไม่แสดง "เลขตู้" อย่่างเดียว แตรวม "รหัสตู้" ดวย:

```text
[BL / Booking demo0101]                    22/09/2026 | 20:06
------------------------------------------------------------
ผสู้่ง : โรงงานบางบ่อ
[International (BL)]
  📦 เลขตู้ : TCLU1234567 / TCLU7654321     <- เมื่่อมีเลขจริง
  🔖 รหัสตู้ : 01                            <- สลัดจาก /01 เสมอ
------------------------------------------------------------
●  โรงงานบางบ่อ
|  ...
```

- **รหัสตู้** = ตัวเลขที่อยู่หลัง `/` สุดท้ายของรหัสออเดอร์ (`OR20260922002/01` → `01`)
- แสดงเฉพาะงานต่างประเทศ (มี BL / Booking / job_type international) และเฉพาะเมื่่อรหัสออเดอร์มี `/` จริง
- แสดงทังเมื่่อมีและไม่มีเลขตู้ — เคส OR20260922002/01 และ /02 ปจจุบันยังไม่มีเลขตู้ จิงจะเห็นแตรหัสตู้ ทำใหแยกงานกอนได
- ไม่มี `/` ในรหัสออเดอร์ (งานในประเทศ / งานปรกติ) → ไม่แสดงอะไรเลยการ์ดคงเดิม
- ตำแหน่ง: ใตปายประเภทงาน ติดกบัแถวเลขตู้ ใชรูปแบบเดกัน (ไอคอน + คำนอย + ค่าตัวหนา)
