# หน้างานปัจจุบัน: ยอด COD รวม + แท็บ งานปกติ / งาน COD

## สิ่งที่คนขับจะเห็น
- ด้านบนรายการมี 2 แท็บ: "งานปกติ (จำนวน)" และ "งาน COD (จำนวน)" — เปิดมาอยู่แท็บงานปกติเสมอ
  - งานปกติ = งานที่ไม่มีจุดส่งเก็บเงินเลย; งาน COD = มีอย่างน้อย 1 จุดส่งเก็บเงิน
  - ตัวเลขในแท็บนับจากรายการงานปัจจุบันที่แสดงจริง
  - แท็บที่ไม่มีงาน แสดงข้อความ "ไม่มีงาน" แบบเดิม
- การ์ดงาน COD: ใต้ป้าย "COD เก็บเงินปลายทาง" แสดง "ยอดเก็บเงินทั้งหมด ฿x,xxx" (รวมทุกจุดส่ง; งานหลายจุดแสดง "(n จุด)")
- ถ้ายอดยังไม่มีจากระบบ แสดงแค่ป้าย COD เหมือนเดิม
- ข้อความแท็บและยอดรวม แสดงตาม 4 ภาษาของแอป

## Technical details
- `src/lib/cod.ts`: เพิ่ม `codTotal(job)` → `{ total, points }` รวม `cod.amount` ของ `job.cod` + `destinations[].cod` (ไม่นับซ้ำงานจุดเดียว)
- `CurrentJobsPage.tsx`: state `tab: 'normal' | 'cod'` (default normal), filter รายการด้วย `jobHasCod`, แท็บสไตล์ปุ่มคู่เหมือนส่วนอื่นของแอป + badge จำนวน; แสดงยอดรวมใต้ป้าย COD (~line 1274)
- `LanguageContext.tsx`: `current.tab_normal`, `current.tab_cod`, `job.cod_total`, `job.cod_points` 4 ภาษา
- test: `codTotal` (หลายจุดรวมถูก, จุดเดียวไม่นับซ้ำ, ไม่มียอด = null)
