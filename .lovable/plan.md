# ล้างข้อมูลในหน้าแจ้งซ่อมหลังส่ง (ทั้งสำเร็จและล้มเหลว)

## พฤติกรรมที่จะทำ

**ส่งสำเร็จ**
- ขึ้นแจ้งเตือนสีเขียว "ส่งเรียบร้อย" เหมือนเดิม
- ล้างข้อมูลทั้งหมด: ช่องรายละเอียดว่างเปล่า, รูป/คลิปที่แนบไว้ถูกลบออกทั้งหมด, กลับเป็นช่อง "แตะเพื่อเพิ่มรูปหรือคลิป"
- อยู่ที่หน้าแจ้งซ่อมต่อ (ไม่เด้งกลับหน้าตั้งค่า) เพื่อกรอกใบใหม่ได้ทันที
- ตำแหน่ง GPS ที่จับไว้ยังใช้ต่อ (รถยังอยู่จุดเดิม) ไม่ต้องขออนุญาตใหม่

**ส่งไม่สำเร็จ**
- ขึ้นแจ้งเตือนสีแดงพร้อม "เหตุผล" ที่ระบบตอบกลับมา (เช่น รายละเอียดไม่ครบ / ระบบปลายทางปฏิเสธ / สัญญาณเน็ตปัญหา) แทนข้อความกว้าง ๆ อย่างเดียว
- ล้างข้อมูลออกทั้งหมดเหมือนกัน ตามที่เลือกไว้

**การตรวจสอบก่อนส่ง**
- ช่อง "รายละเอียดปัญหา" มีเครื่องหมาย * แต่ตอนนี้ยังไม่มีการเช็คจริง จะเพิ่มให้เตือนก่อนส่งถ้าปล่อยว่าง (เหตุผลชัดเจน ไม่ต้องรอระบบปฏิเสธ)
- ถ้าไม่มีข้อมูลรถ/ผู้ใช้ในระบบ จะเตือนว่าส่งไม่ได้เหมือนเดิม

## กรณียกเลิก
- กดปุ่มย้อนกลับก่อนส่ง: ออกจากหน้าตามปกติ (ข้อมูลไม่ถูกเก็บไว้ที่ไหนอยู่แล้ว)

## รายละเอียดเทคนิค

แก้ที่ `src/pages/RepairReportPage.tsx`:
- เพิ่มฟังก์ชัน `resetForm()` ที่เรียก `URL.revokeObjectURL` กับทุก preview URL, เคลียร์ `objectUrlsRef.current`, `setMedia([])`, `setNote("")`
- `handleSubmit`: แทน `navigate(-1)` หลัง toast สำเร็จด้วย `resetForm()`; ใน `catch` เรียก `resetForm()` เช่นกัน (ยังตั้ง `isSubmitting` กลับใน `finally`)
- เพิ่มการอ่านเหตุผลจาก response body ของ edge function เมื่อมี (`error.context` / `response.json()` ถ้า parse ได้) ใช้เป็น description ของ toast ความผิดพลาด มิฉะนั้น fallback เป็น `repairReport.submitFailed`
- เพิ่ม guard `if (!noteText)` ก่อน send → toast `repairReport.noteRequired`
- `licensePlate` ยังส่งไปใน payload เหมือนเดิม (prefill จากข้อมูลรถ แม้ไม่แสดงในหน้าจอ)

`src/contexts/LanguageContext.tsx`:
- แทนคีย์ `repairReport.plateRequired` ด้วย `repairReport.noteRequired` และลบ `repairReport.plateLabel` / `repairReport.platePlaceholder` ที่ไม่ใช้แล้ว — เพิ่ม/ลบทั้ง 4 ภาษา (th/en/ko/zh)
