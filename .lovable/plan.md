# ปุ่ม "อัปเดต" ของแต่ละจุดเปิดเป็นหน้าต่างกลางจอ

## สิ่งที่จะเปลี่ยน (แก้แค่หน้าตา ขั้นตอนเหมือนเดิม)
- กด "อัปเดต" ที่การ์ดของแต่ละจุด (รับตู้, จุดรับ/ส่งสินค้า, จุดดรอป, จุดเพิ่ม, คืนตู้) -> เปิดเป็นหน้าต่างลอยกลางจอ แทนแบบเด้งจากล่าง
- ขั้นตอนต่อเนื่อง (เช็คอิน -> SOP -> POD) อยู่ในหน้าต่างเดิมจนจบ ปิดแล้วหน้างานแสดงสถานะล่าสุด
- ปุ่มอื่นในหน้างาน (ดูค่าใช้จ่าย, เพิ่มค่าใช้จ่าย, เอกสาร, แจ้งปัญหา, กดการ์ดดูรายละเอียดจุด) กลับไปเปิดหน้าใหม่ตามเดิม
- ลิงก์จากแจ้งเตือน/เปิดตรง ยังเป็นหน้าเต็มเหมือนเดิม

## รายละเอียดทางเทคนิค
- `DomesticJobDetail.tsx`: เฉพาะการ navigate จากปุ่มอัปเดต ใส่ `state.stepModal = true` (คง state เดิมไว้ทั้งหมด)
- `JobStepRoutes.tsx`: เปิด overlay เฉพาะเมื่อ step แรกมาจาก `stepModal`; จำไว้ด้วย ref ให้ step ถัดไปในชุดเดียวกันยังอยู่ใน overlay; เปลี่ยน `Sheet` bottom เป็น `Dialog` กลางจอ (กว้าง ~94vw, max-w-lg, สูงสุด 90vh, เลื่อนได้, ปุ่ม X). step ที่ไม่มี flag แสดงหน้าเต็มเหมือนก่อนมี popup
- `ExtraPointCheckinSheet.tsx`: เปลี่ยนจาก bottom Sheet เป็น Dialog กลางจอ เนื้อหาเดิมครบ (ปุ่มค่าใช้จ่าย/เอกสาร/แจ้งปัญหา, รูป, หมายเหตุ, ยืนยัน/ยกเลิก)
