# หน้าที่เปิดจากแถบเมนู แสดงกล่องจาง ๆ ระหว่างโหลดข้อมูล

## ปัญหา
ตอนกดไอคอนในแถบเมนู (เช่น "ดูค่าใช้จ่าย") หน้าปลายทางแสดงวงกลมหมุน + ข้อความ "กำลังโหลด" เต็มจอ จนกว่าข้อมูลจะมา ทำให้รู้สึกช้าและกระพริบ

## สิ่งที่จะแก้ (frontend เท่านั้น ไม่แตะ flow/API)

1. **หน้าดูค่าใช้จ่าย (`JobExpensesPage`)** — เปลี่ยนจากวงกลมหมุนเต็มจอ + ข้อความ "กำลังโหลด" เป็นโครงหน้าจาง ๆ: แสดงหัวหน้า (header) ทันที ด้านล่างเป็นกล่องจาง ๆ (ใช้ `JobListSkeleton` ที่มีอยู่) แทนรายการค่าใช้จ่าย จนกว่าข้อมูลจะโหลดเสร็จ
2. **หน้าค่าใช้จ่ายตามเส้นทาง (`JobRouteExpensesPage`)** — แก้แบบเดียวกัน: ตัดวงกลมหมุน + ข้อความออก แสดงกล่องจาง ๆ แทน
3. **หน้าเพิ่มค่าใช้จ่าย (`AddExpensePage`)** — ถ้ามีช่วงรอข้อมูลงานตอนเปิด ให้แสดงกล่องจาง ๆ แทนจอว่าง/วงกลมหมุนด้วย
4. ไม่มีข้อความ "กำลังโหลด" เหลืออยู่ — เหลือแค่กล่องจาง ๆ เหมือนหน้างานปัจจุบัน/ประวัติงานที่ทำไปแล้ว

## รายละเอียดเทคนิค
- ใช้ `src/components/job/JobListSkeleton.tsx` ที่มีอยู่ (variant="list") ไม่สร้าง skeleton ใหม่
- แก้ early return `if (loading)` ของ JobExpensesPage (บรรทัด ~442) และ JobRouteExpensesPage (บรรทัด ~318): คง header ไว้ แทนส่วนเนื้อหาด้วย skeleton
- ตรวจ AddExpensePage ว่ามีจุดรอข้อมูลตอนเปิดหรือไม่ ถ้ามีใช้ skeleton เช่นกัน
- ตรรกะโหลดข้อมูล/ส่ง API เดิมไม่เปลี่ยน
- ตรวจด้วย npx tsgo + build
