# งานต่างประเทศ: สแกน QR ที่จุดรับ/โหลดสินค้า

## สิ่งที่ผู้ใช้ต้องการ
งานต่างประเทศทั้งสองแบบต้องมีขั้นสแกน QR ตอนโหลดสินค้า ไม่ใช่ที่จุดรับตู้เปล่า:
- **Booking (ขาออก)** — สแกนที่การ์ด "จุดรับสินค้า"
- **BL (ขาเข้า)** — ไม่มีการ์ดจุดรับสินค้า สแกนที่การ์ดตู้ (ขั้นโหลดสินค้า/แนบหลักฐานตู้)

ส่วนเช็คอินและแนบหลักฐานยังใช้ flow API เดิมทั้งหมด

## สิ่งที่จะทำ
1. **Booking**: หลังเช็คอินจุดรับสินค้า ปุ่มหลักบนการ์ดเปลี่ยนเป็น "สแกนโหลดสินค้า" (ข้ามได้) แล้วค่อยเป็น "แนบหลักฐาน"
2. **BL**: หลังเช็คอินที่การ์ดตู้ ก่อนเข้าหน้าแนบหลักฐานตู้ ให้สแกน QR ก่อน (ข้ามได้)
3. สแกนสำเร็จ → ยิงเส้น queues/scan ของระบบคิวเหมือนงานในประเทศ (external_ref = เลขออเดอร์, station_token = ค่าจาก QR) แบบไม่รอผล + แถบเขียว "สแกนโหลดสินค้าแล้ว (เวลา)" บนการ์ดนั้น
4. จุดรับตู้เปล่าและจุดคืนตู้ไม่มีขั้นสแกน; สถานะสแกนเก็บต่อออเดอร์ในเครื่องเหมือนเดิม

## ไม่เปลี่ยน
- flow เช็คอิน / แนบหลักฐาน / SOP / ลายเซ็น / OCR ของทุกประเภทงาน
- เงื่อนไขล็อกการ์ดจุดรับสินค้าของงาน Booking (รอตู้เปล่าเสร็จก่อน)

## Technical details
- `DomesticJobDetail.tsx`:
  - `needsLoadingQr` (การ์ดจุดรับสินค้า): เปลี่ยนจาก `!job.bl_no && !job.booking_no` เป็น `!job.bl_no`
  - แถบเขียวบนการ์ดจุดรับสินค้า (~2013): เงื่อนไขเดียวกัน
  - การ์ดตู้ (~1773-1789): เพิ่ม `needsLoadingQrContainer = job.bl_no && emptyContainerCheckedIn && !isContainerStepCompleted && !loadingQr && !isFromHistory` — ปุ่มเปลี่ยน label เป็น loadingQr.button และเปิด LoadingQrScanDialog แทน navigate; แถบเขียวบนการ์ดตู้เมื่อสแกนแล้ว
  - `handleLoadingQrDone` ใช้ของเดิม (บันทึก localStorage + ยิง qtruck-queue-scan)
- ไม่แตะ edge function หรือ i18n
