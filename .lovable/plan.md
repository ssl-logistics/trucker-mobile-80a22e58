# งานต่างประเทศ: สแกน QR + อัปเดตสถานะคิวที่จุดรับ/ส่งสินค้า

## สรุป flow ที่ยืนยันแล้ว
- **Booking (ขาออก):** จุดรับตู้เปล่า → จุดรับสินค้า → คืนตู้หนักที่ท่า
- **BL (ขาเข้า):** จุดรับตู้หนัก → จุดส่งสินค้า → คืนตู้เปล่า

จุดสแกน QR และการอัปเดตสถานะคิวทำเหมือนกันทั้งสองฝั่ง ที่การ์ดสินค้า (Booking = จุดรับสินค้า, BL = จุดส่งสินค้า):

```text
เช็คอิน → ส่ง processing เข้าคิว → ปุ่ม "สแกนโหลดสินค้า" (ข้ามได้) → ยืนยัน SOP/POD → ส่ง completed เข้าคิว
```

## สิ่งที่จะทำ
1. **Booking**: หลังเช็คอินจุดรับสินค้า ปุ่มหลักเปลี่ยนเป็น "สแกนโหลดสินค้า" (ข้ามได้) แล้วค่อยเป็น "แนบหลักฐาน" (เช็คอิน/SOP จุดนี้ส่ง processing/completed อยู่แล้ว)
2. **BL**: ที่การ์ดจุดส่งสินค้า —
   - เช็คอินจุดส่ง → ส่ง processing เข้าคิว (เพิ่มใหม่ — ตอนนี้หน้าจุดส่งยังไม่ได้ส่ง)
   - หลังเช็คอิน ปุ่มหลักเปลี่ยนเป็น "สแกนโหลดสินค้า" (ข้ามได้) ก่อนเข้าหน้าอัปโหลดเอกสารขนส่ง
   - ยืนยัน POD สำเร็จ → ส่ง completed เข้าคิว (เพิ่มใหม่)
3. สแกนสำเร็จ → ยิงเส้น queues/scan (external_ref = เลขออเดอร์, station_token = ค่าจาก QR) แบบไม่รอผล + แถบเขียว "สแกนโหลดสินค้าแล้ว (เวลา)" บนการ์ดนั้น
4. จุดรับตู้เปล่า/ตู้หนักและจุดคืนตู้ไม่เพิ่มขั้นสแกน (สถานะคิวตอนเช็คอิน/ยืนยันตู้ที่ส่งอยู่แล้วคงเดิม)

## ไม่เปลี่ยน
- flow เช็คอิน / แนบหลักฐาน / SOP / POD / ลายเซ็น / OCR ของทุกประเภทงาน
- เงื่อนไขล็อกการ์ดตามลำดับขั้นตอนเดิม

## Technical details
- `DomesticJobDetail.tsx`:
  - `needsLoadingQr` (การ์ดจุดรับสินค้า): เปลี่ยนจาก `!job.bl_no && !job.booking_no` เป็น `!job.bl_no`
  - แถบเขียวบนการ์ดจุดรับสินค้า (~2013): เงื่อนไขเดียวกัน
  - การ์ดจุดส่ง (~2045+): เพิ่ม `needsLoadingQrDelivery = !!job.bl_no && isCheckedIn && !isPodCompleted && !loadingQr && !isFromHistory` — ปุ่มหลักเปลี่ยน label เป็น loadingQr.button และเปิด LoadingQrScanDialog แทน navigate; แถบเขียวเมื่อสแกนแล้ว
  - `handleLoadingQrDone` ใช้ของเดิม (บันทึก localStorage + ยิง qtruck-queue-scan)
- `DeliveryDetailPage.tsx`: หลัง driver-checkin จุดส่งสำเร็จ → `notifyQtruckQueueStatus(order, 'processing')` เฉพาะงาน BL
- `DeliverySOPCheckInPage.tsx` (หรือหน้ายืนยัน POD): หลังยืนยัน POD สำเร็จ → `notifyQtruckQueueStatus(order, 'completed')` เฉพาะงาน BL
- ทุกจุด fire-and-forget; ไม่แตะ edge function หรือ i18n
