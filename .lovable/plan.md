# แสดงจุดรับ/ส่งสินค้าเพิ่มในงานต่างประเทศ (OR20261016015/06)

## สิ่งที่ตรวจพบ
- ข้อมูลงานส่ง `extra_cargo_points` มาจริง 1 จุด: "คลังสินค้าเดโม บางนา" (ผู้ติดต่อ คุณสมชาย เดโม) งานนี้เป็น BL ทางเรือ
- การ์ดจุดเพิ่มถูกวางไว้ข้างในเงื่อนไขของการ์ด "จุดคืนตู้" ซึ่งเช็ค `job_type === 'international'` และต้องมีที่อยู่คืนตู้ แต่ API ส่ง `job_type: "bl"` จึงอาจไม่ผ่านเงื่อนไข การ์ดจุดเพิ่มเลยหายไปด้วย
- อีกจุดที่อาจทำให้หาย: ตอนแปลงข้อมูลงานเป็นข้อมูลหน้ารายละเอียด field จุดเพิ่มอาจไม่ถูกส่งต่อ (จะตรวจยืนยันเป็นขั้นแรก)

## สิ่งที่จะแก้
- ย้ายการ์ดจุดสินค้าเพิ่มออกมาไว้เดี่ยวๆ ต่อจากจุดสินค้าหลัก แสดงเมื่อเป็นงานต่างประเทศ (BL/Booking) และมีจุดเพิ่ม ไม่ต้องพึ่งการ์ดคืนตู้
- ให้ข้อมูลจุดเพิ่มถูกส่งต่อทุกทางที่เปิดหน้ารายละเอียด (จากงานปัจจุบัน, ลิงก์ตรง, รีเฟรชหน้า)
- การ์ดคืนตู้และ flow เดิมไม่เปลี่ยน; งานในประเทศไม่แสดง

## รายละเอียดทางเทคนิค
- `DomesticJobDetail.tsx`: render `ExtraPointCard` นอก block container-return โดยใช้ `isInternationalJobItem(job)`
- ตรวจ mapping ใน `JobDetailPage.tsx` / `CurrentJobsPage.tsx` ให้ส่ง `extra_cargo_points`, `extra_drop_points` ผ่าน
- ทดสอบด้วย Playwright เปิด `/job/OR20261016015%2F06` ยืนยันการ์ดสีน้ำเงินแสดง
