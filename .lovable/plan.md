# แก้หน้า Login ไม่ให้เลื่อนลงได้เมื่อจอพอดี

## สาเหตุที่คาดไว้ (ต้องยืนยันก่อนแก้)
หน้า Login ตั้งความสูงเป็น "อย่างน้อยเท่าจอ" และเว้นขอบบนสำหรับรอยบากเพิ่มเข้าไป รวมกับรูปแบนเนอร์ที่สูงตามสัดส่วน และเมนูภาษาด้านล่าง ทำให้เนื้อหาเกินจอเล็กน้อยจึงเลื่อนได้ ขั้นแรกจะวัดความสูงจริงบนจอ 393x805 เพื่อยืนยันว่าเกินตรงไหน

## สิ่งที่จะทำ (แก้เฉพาะหน้า Login)
1. ล็อกความสูงหน้าให้เท่าจอพอดี และไม่ให้เลื่อนเมื่อเนื้อหาพอดีจอ
2. ให้รูปแบนเนอร์ยืดหยุ่นลดความสูงได้เล็กน้อยเมื่อพื้นที่ไม่พอ (รูปไม่บีบ ไม่ยืด มุมโค้งยังครบ)
3. ลดช่องว่างด้านล่างที่เกินออก ให้เมนูภาษาอยู่ล่างสุดในจอ
4. จอเตี้ยมาก (ต่ำกว่า ~600px) ยังเลื่อนได้ เพื่อไม่ให้ปุ่มหรือเมนูภาษาถูกตัดหายจนกดไม่ได้

## ตรวจสอบ
- ทดสอบที่ความสูงจอ 805 / 740 / 667 / 640 px: เลื่อนไม่ได้ เห็นฟอร์ม ปุ่ม และเมนูภาษาครบ
- ที่ 568 px: เข้าถึงเมนูภาษาได้
- ไม่แตะขั้นตอนเข้าสู่ระบบ ภาษา หรือรูปแบนเนอร์
