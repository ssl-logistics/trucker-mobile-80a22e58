# เปิดหน้าใหม่ในเมนูล่าง: อยู่บนสุดของหน้าเสมอ (ไม่มีการเลื่อนจอ)

## ปัญหา
เปิดหน้าใหม่ (เช่นหน้าแรก) แล้วหน้าจอไม่ได้อยู่บนสุดเสมอ — ตำแหน่งเลื่อนค้างจากหน้าก่อนหน้า

## สาเหตุ (ยืนยันจากโค้ดแล้ว)
- ตัวเลื่อนหลักของแอปคือ `#root` เพียงตัวเดียว
- ตอนเปลี่ยนหน้าในเมนูล่าง `TabLayout` (`src/App.tsx`) จะรีเมาต์เนื้อหาตาม path (`key={location.pathname}`) แต่ไม่มีการรีเซ็ตตำแหน่ง `#root.scrollTop` เลย จึงค้างจากตำแหน่งที่เลื่อนไว้ในหน้าก่อน
- ตรวจทั้งโปรเจกต์แล้ว: ไม่มีการรีเซ็ตตำแหน่งเลื่อนตอนเปลี่ยนหน้าในเชลล์แท็บใด ๆ (มีเฉพาะในหน้ารายละเอียดงานซึ่งอยู่นอกเชลล์)

## การเปลี่ยนแปลง (UI เท่านั้น ไฟล์เดียว)
- `src/App.tsx` — ใน `TabLayout` เพิ่ม useEffect ที่ทำงานเมื่อ `location.pathname` เปลี่ยน: ตั้งตำแหน่งเลื่อนกลับบนสุดทันที (ไม่มี animation เลื่อน):
  ```ts
  useEffect(() => {
    const root = document.getElementById('root');
    if (root) root.scrollTop = 0;
    window.scrollTo(0, 0);
  }, [location.pathname]);
  ```
- ผลคือทุกหน้าในเมนูล่าง (หน้าแรก, แชท, ตั้งค่า, งานปัจจุบัน, ประวัติงาน, บัญชี ฯลฯ) เปิดมาอยู่บนสุดเสมอโดยไม่มีการเลื่อนจอให้เห็น

## สิ่งที่ไม่แตะ
- ข้อมูลงาน, แคช, การกรอง, การค้นหา, flow กดรับงาน/เริ่มงาน/เช็คอิน ทั้งหมดคงเดิม
- การ์ดแนะนำเมนูและการเลื่อนไปการ์ดขั้นตอนในหน้ารายละเอียดงานคงเดิม (อยู่นอกเชลล์แท็บ)
- การเลื่อนเองของผู้ใช้ระหว่างอยู่ในหน้าเดียวกันไม่ถูกรบกวน

## ตรวจสอบ
- typecheck (`npx tsgo --noEmit -p tsconfig.app.json`) + build ผ่าน
- ทดสอบใน preview: เลื่อนลงในหน้าใดหน้าหนึ่งของเมนูล่าง → สลับไปหน้าแรก/หน้าอื่น → หน้าที่เปิดใหม่ต้องอยู่บนสุดทันที ไม่มีจอกระดก
