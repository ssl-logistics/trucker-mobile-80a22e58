# เคลียร์ยอดได้เฉพาะงานที่ "ปิดงาน" จริง

## สิ่งที่ผู้ใช้จะเห็น
- งานที่ส่งครบแล้วแต่ระบบหลักยังไม่ปิด (เช่น OR20261027001) จะขึ้นป้าย "ส่งครบแล้ว" แทน "ปิดงานแล้ว"
- ข้อความใต้การ์ด: "ยังเคลียร์ไม่ได้: งานยังไม่ปิด" และไอคอนเคลียร์เป็นสีเทา กดไม่ได้
- เมื่อระบบหลักปิดงาน การ์ดจะเปลี่ยนเป็น "ปิดงานแล้ว · พร้อมเคลียร์" เองตอนเปิดหน้าใหม่
- เลขแดงบนเมนูยังนับงานที่ยังไม่เคลียร์ทั้งหมดเหมือนเดิม
- การแจ้งเตือน 05:00/05:30 เตือนเฉพาะงานที่ปิดแล้วและยังไม่เคลียร์
- รองรับ 4 ภาษา

## Technical
- `src/lib/codClear.ts`: `isClosedStatus` นับเฉพาะ `closed` (ไม่รวม completed/delivered/ว่าง)
- `CodClearPage.tsx`: ป้ายสถานะ 3 แบบ (กำลังวิ่ง / ส่งครบแล้ว = completed,delivered / ปิดงานแล้ว = closed) + ข้อความ 4 ภาษา
- `cod-clear-reminder`: เงื่อนไขเดียวกัน แล้ว deploy
- อัปเดตเทสต์: completed → canClear false, closed → true
