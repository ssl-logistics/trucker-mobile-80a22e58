# แถบรถด้านล่างของป๊อปอัพคิว: ฟ้าอ่อนพื้นสีเดียว

## สิงที่จะเปลี่ยน

หน้าต่างคิว (ป๊อปอัพที่เปิดจากปุ่มคิวในหน้างานปัจจุบน) ส่วนล่างสุดที่มีรูป รถ บรรทุก ปัจจุบนเป็นสีสองชั้นซ้อนกັນ (ฟ้าอ่อนมาก ๆ ด้านบน + ฟ้าเข้มขึ้ นกว่าเป็นแถบอยู่ ด้านล่าง) ทำให้เห็นเป็นเส้นตัดกลางแถบ รูปที่ส่งมาตรงกกัน

แก้ให้กลายเป็น:

- **พื้ นหลังสีเดียวเดียวกันทัว้ งแถบ** – ไม่มีแถบสีสองซ้อนข้ างล่าง ไม่มีเส้นตัดกลาง
- **สีสันนุมลง** – เป็นฟ้าอ่อนจาง ๆ ทั้ งแถบ
- **ไอคอนรถสฟ้ า** ยงั อยู่กลางแถบ ตำแหน่งเดิม

งานนี้เปี่ยนเฉพาะหน้าตา ข้อมูลคิว การดึงข้อมูล และการอัปเดตทุก 1 นาทียังทำงานเหมือนเดิมทุกอย่าง (ไม่มีสริงผลกบั ปุ่ มคิวในหน้างานอื่ น เพราะใช้ป๊อปอัพตวั เดยีวกนั)

## รายละเอียด technical

ไฟล์ `src/components/job/JobQueueDialog.tsx` (แถว 161-163 + 140)

1. แถบล่าง (แถว 161): เปลี่ยนจาก `bg-secondary/5` เป็น `bg-secondary/[0.07]` เป็นพื้ นฟ้ าอ่อนชั้ นเดียว
2. ลบชั้ นที่ทำให้เห็นเป็นเส้นตัด (แถว 162): `<div className="absolute inset-x-0 bottom-0 h-10 bg-secondary/10" />` ออกทังบรรทุก
3. ไอคอนรถ (แถว 163): `text-secondary` → `text-secondary/75` ให้ดนูุ่ มลง คง `mb-3` การวางกลาง และ effect เลื่ อนไว
4. เส้นคั นด้านบนของชองประตู/เวลา (แถว 140): `border-y border-border/70` → `border-t border-border/70` เพือไม่มีเสนเขินซ้ำตรงรอยตอกับแถบรถ

คงทังหมด: semantic token (`--secondary` คือบสีฟ้ าของแอป) ไมฮ่ ารดโคดสี, rounded/overflow ของ Dialog, คลาส `motion-safe`
