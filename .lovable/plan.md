# งานต่างประเทศ: สแกน QR ที่จุดรับสินค้า

## สิ่งที่ผู้ใช้ต้องการ
งานต่างประเทศให้สแกน QR ที่การ์ด "จุดรับสินค้า" (ไม่ใช่จุดรับตู้เปล่า) — การ์ดนี้แสดงเฉพาะงาน Booking (ขาออก) และถูกล็อกจนกว่าขั้นตู้เปล่าจะเสร็จ ส่วนเช็คอินและแนบหลักฐานยังใช้ flow API เดิมทั้งหมด

## สิ่งที่จะทำ
1. เปิดขั้นตอนสแกนบนการ์ดจุดรับสินค้าของงาน Booking: หลังเช็คอินจุดรับสินค้า ปุ่มหลักเปลี่ยนเป็น "สแกนโหลดสินค้า" (ข้ามได้) แล้วค่อยเป็น "แนบหลักฐาน" ตามเดิม
2. สแกนสำเร็จ → ยิงเส้น queues/scan ของระบบคิวเหมือนงานในประเทศ (external_ref = เลขออเดอร์, station_token = ค่าจาก QR) แบบไม่รอผล + แถบเขียว "สแกนโหลดสินค้าแล้ว (เวลา)" บนการ์ด
3. งาน BL (ขาเข้า) ไม่มีการ์ดจุดรับสินค้าอยู่แล้ว → ไม่มีขั้นสแกน
4. จุดรับตู้เปล่าและจุดคืนตู้ไม่มีขั้นสแกน

## ไม่เปลี่ยน
- flow เช็คอิน / แนบหลักฐาน / SOP / ลายเซ็น / OCR ของทุกประเภทงาน
- เงื่อนไขล็อกการ์ดจุดรับสินค้าของงานต่างประเทศ (รอตู้เปล่าเสร็จก่อน)

## Technical details
- `DomesticJobDetail.tsx`:
  - `needsLoadingQr`: เปลี่ยนเงื่อนไขจาก `!job.bl_no && !job.booking_no` เป็น `!job.bl_no` (Booking ได้สแกน, BL ไม่มีการ์ดนี้อยู่แล้ว)
  - แถบสถานะเขียว (~บรรทัด 2013): เปลี่ยนเป็น `!job.bl_no` เช่นกัน
  - `handleLoadingQrDone` ใช้ของเดิม (ยิง qtruck-queue-scan อยู่แล้ว)
- ไม่แตะ edge function หรือ i18n
