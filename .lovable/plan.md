# แถบรถด้านล่างของป๊อปอัปคิว: ฟ้าอ่อนพื้นสีเดียว

## สิ่งที่เปลี่ยน

ด้านล่างสุดของป๊อปอัปคิว (ที่เปิดจากปุ่มคิวในหน้างานปัจจุบัน) มีรูปรถบรรทุก ปกติเป็นสีสองชั้นซ้อนกัน (ฟ้าอ่อนมากด้านบน + ฟ้าเข้มกว่าเป็นแถบด้านล่าง) ทำให้เห็นเป็นเส้นตัดกลางแถบ ตามรูปที่ส่งมา

แก้ให้เป็น:

- **พื้นหลังสีเดียวทั้งแถบ** ไม่มีแถบสีสองซ้อนข้างล่าง ไม่มีเส้นตัดกลาง
- **สีอ่อนลง** เป็นฟ้าอ่อนจาง ๆ ทั้งแถบ
- **ไอคอนรถสีฟ้า** อยู่กลางแถบตำแหน่งเดิม

งานนี้เปลี่ยนเฉพาะหน้าตา ข้อมูลคิว การดึงข้อมูล และการอัปเดตทุก 1 นาที ทำงานเหมือนเดิมทั้งหมด (ไม่กระทบปุ่มคิวในหน้าอื่น เพราะป๊อปอัปตัวเดียวกัน)

## รายละเอียด technical

ไฟล์ `src/components/job/JobQueueDialog.tsx` (บรรทัด 140, 161-163)

1. แถบล่าง (บรรทัด 161): เปลี่ยนจาก `bg-secondary/5` เป็น `bg-secondary/[0.07]` เป็นพื้นฟ้าอ่อนชั้นเดียว
2. ลบชั้นที่ทำให้เห็นเป็นเส้นตัด (บรรทัด 162): `<div className="absolute inset-x-0 bottom-0 h-10 bg-secondary/10" />` ออกทั้งบรรทัด
3. ไอคอนรถ (บรรทัด 163): `text-secondary` → `text-secondary/75` ให้ดูนุ่มขึ้น คง `mb-3` การวางกลาง และเอฟเฟกต์เลื่อนไว้
4. เส้นคั่นด้านบนของช่องประตู/เวลา (บรรทัด 140): `border-y border-border/70` → `border-t border-border/70` เพื่อไม่ให้มีเส้นเขินซ้ำตรงรอยต่อ กับแถบรถ

คงไว้ทั้งหมด: semantic token (`--secondary` คือสีฟ้าของแอป) ไม่ฮาร์ดโค้ดสี, rounded/overflow ของ Dialog, คลาส `motion-safe`
