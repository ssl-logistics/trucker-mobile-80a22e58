# บล็อกการกรอกภาษาไทยในช่องชื่อผู้ใช้ (หน้าเข้าสู่ระบบ)

## สิ่งที่จะทำ
ช่อง "ชื่อผู้ใช้" (`#email`) ในหน้าเข้าสู่ระบบจะรับได้เฉพาะอักขระที่ไม่ใช่ภาษาไทย

1. กรองอักขระไทยออกทันทีขณะพิมพ์/วาง (รวมกรณีคีย์บอร์ดไทยบนมือถือ) ผู้ใช้จะเห็นเฉพาะตัวอักษรที่อนุญาต
2. เพิ่มการตรวจสอบใน schema ของฟอร์ม: ถ้ามีอักขระไทยหลงเข้ามา แสดงข้อความเตือนใต้ช่อง
3. เพิ่มคำแปลข้อความเตือน (ไทย/อังกฤษ/จีน/เกาหลี) เช่น "ชื่อผู้ใช้กรอกภาษาไทยไม่ได้"

## ขอบเขต
- แก้เฉพาะช่องชื่อผู้ใช้ในหน้าเข้าสู่ระบบเท่านั้น ไม่แตะช่องรหัสผ่านหรือหน้าสมัครสมาชิก
- ไม่เปลี่ยน logic การเรียก API หรือฐานข้อมูล

## รายละเอียดทางเทคนิค
- ไฟล์: `src/pages/SignIn.tsx` — เปลี่ยน `register("email")` ให้มี `onChange` ที่ strip ด้วย regex `/[\u0E00-\u0E7F]/g` และเพิ่ม `.regex()` ใน zod schema
- ไฟล์: `src/contexts/LanguageContext.tsx` — เพิ่มคีย์ข้อความเตือนครบทุกภาษา
