# เพิ่มปุ่มคิวและป๊อปอัปในหน้างานปัจจุบัน

## เป้าหมาย
เพิ่มปุ่ม **คิว** ทางขวาของปุ่ม **ดูข้อมูลงาน** ในการ์ดหน้างานปัจจุบัน เฉพาะงานที่มีข้อมูลคิว ส่วนงานที่ไม่มีข้อมูลคิวยังคงแสดงปุ่มดูข้อมูลงานเต็มความกว้างเพียงปุ่มเดียว

## การเปลี่ยนแปลง

### 1. ปุ่มด้านล่างการ์ด
- ปรับเฉพาะการ์ดใน `CurrentJobsPage`
- งานที่มีข้อมูลคิว: แสดงปุ่มสองช่องขนาดเท่ากัน — ซ้าย **ดูข้อมูลงาน**, ขวา **คิว** พร้อมไอคอนที่สื่อถึงลำดับคิว
- งานที่ไม่มีข้อมูลคิว: คงปุ่ม **ดูข้อมูลงาน** แบบเต็มความกว้างเหมือนเดิม
- การกดปุ่มคิวจะไม่พาไปหน้ารายละเอียดงาน และไม่กระทบการกดส่วนอื่นของการ์ด

### 2. ป๊อปอัปคิวตามภาพตัวอย่าง
- เปิดเป็นกล่องกลางหน้าจอบนพื้นหลังทึบ และปิดได้ด้วยปุ่มกากบาทหรือแตะด้านนอก
- แสดงข้อมูลตัวอย่างก่อน ได้แก่:
  - คิวของฉัน: `0015`
  - สถานะ: `รอเรียกคิว`
  - คิวที่กำลังให้บริการ: `Q012`
  - เหลือก่อนถึงคิว: `2 คิว`
  - เวลาคาดการณ์: `23/09/2026 09:00 - 10:00`
- ใช้รูปแบบสีและลำดับข้อมูลใกล้เคียงภาพอ้างอิง โดยใช้ไอคอนรถจากชุดไอคอนของแอป ไม่ฝังรูปอ้างอิงเป็นรูปภาพในแอป

### 3. จุดรองรับข้อมูลจริงภายหลัง
- เพิ่มโครงข้อมูลคิวแบบ optional ให้กับข้อมูลงาน เพื่อให้ตรวจได้ว่างานใดมีคิว
- รอบนี้ค่าภายในป๊อปอัปเป็นข้อมูลตัวอย่างตามที่เลือกไว้
- แยกส่วนตรวจเงื่อนไขและส่วนแสดงป๊อปอัปออกจากกัน เพื่อเปลี่ยนเป็นเงื่อนไข/API จริงภายหลังได้โดยไม่ต้องรื้อหน้าตา
- หากยังไม่มีข้อมูลคิวในงาน ปุ่มคิวจะไม่แสดง

### 4. ภาษา
- เพิ่มข้อความของปุ่มและป๊อปอัปให้รองรับภาษาไทย อังกฤษ เกาหลี และจีนตามภาษาระบบ

## การตรวจสอบ
- ตรวจว่างานที่มีข้อมูลคิวแสดงสองปุ่ม และเปิด/ปิดป๊อปอัปได้
- ตรวจว่างานที่ไม่มีข้อมูลคิวยังคงมีปุ่มดูข้อมูลงานเพียงปุ่มเดียว
- ตรวจว่าปุ่มคิวไม่เปิดหน้ารายละเอียดงานโดยไม่ตั้งใจ
- ตรวจการแสดงผลบนหน้าจอมือถือและข้อความทั้ง 4 ภาษา

## ยังไม่ทำในรอบนี้
- ยังไม่เชื่อม API คิวหรือกำหนดเงื่อนไขธุรกิจว่างานประเภทใดมีคิว
- ยังไม่อัปเดตคิวแบบเรียลไทม์
