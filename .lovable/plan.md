# หน้าแรก (Home) เปิดแล้วอยู่บนสุดเสมอ

## ปัญหา
เปิดหน้าแรกแล้วหน้าจอไม่ได้อยู่บนสุดเสมอ ตำแหน่งเลื่อนค้างจากหน้าก่อนหน้า

## สาเหตุ (ยืนยันจากโค้ดแล้ว)
- ตัวเลื่อนหลักของแอปคือ `#root` (เดียวกับที่แก้ในหน้ารายละเอียดงาน)
- ตอนเปลี่ยนหน้าในเมนูล่าง `TabLayout` จะรีเมาต์เนื้อหาตาม path (`key={location.pathname}`) แต่ตำแหน่ง `#root.scrollTop` ไม่ถูกรีเซ็ต จึงค้างจากหน้าที่เลื่อนไว้ก่อนหน้า
- หน้าแรก (`src/pages/Home.tsx`) ไม่มีการรีเซ็ตตำแหน่งเลื่อนตอนเปิดหน้าเลย (มีเฉพาะ scrollTo ตอนกดเปลี่ยนหน้า pagination)

## การเปลี่ยนแปลง (frontend เท่านั้น ไฟล์เดียว)
- `src/pages/Home.tsx`: เพิ่ม useEffect ตอนหน้าถูกเปิด (mount) ให้เลื่อน `#root` กลับบนสุดทันที:
  ```ts
  useEffect(() => {
    document.getElementById('root')?.scrollTo({ top: 0 });
    window.scrollTo({ top: 0 });
  }, []);
  ```
- เพราะหน้าแรกถูก remount ทุกครั้งที่เข้า `/home` การรีเซ็ตจึงเกิดตอน "เปิดหน้า" เท่านั้น — ระหว่างใช้งานอยู่บนหน้าแรก (ค้นหา, กรอง, เปลี่ยนหน้ารายการ) จะไม่มีการดึงจอกลับบนสุดโดยไม่ได้ตั้งใจ

## สิ่งที่ไม่แตะ
- ข้อมูลงาน, แคช, การกรอง, การค้นหา, pagination, flow กดรับงาน/เริ่มงาน ทั้งหมดคงเดิม
- ไม่เพิ่มการรีเซ็ตหน้าอื่น (ตามที่ผู้ใช้สั่ง "ตรงนี้ด้วย" = เฉพาะหน้าแรก)

## ตรวจสอบ
- typecheck (`npx tsgo --noEmit -p tsconfig.app.json`) + build ผ่าน
- ทดสอบใน preview: เลื่อนลงในหน้าอื่น (เช่น งานปัจจุบัน) → สลับเมนูมาหน้าแรก → หน้าต้องอยู่บนสุดทันที และการใช้งานต่อ (กรอง/เปลี่ยนหน้ารายการ) ยังทำงานปกติ
