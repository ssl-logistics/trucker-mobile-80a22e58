# ปรับไอคอนปุ่ม "เอกสาร" ให้สไตล์และสีเดียวกับปุ่มอื่น

## ปัญหา

แถวปุ่มงาน (ดูค่าใช้จ่าย / เพิ่มค่าใช้จ่าย / แจ้งปัญหา / เอกสาร) ปุ่มเอกสารใช้ไอคอน Lucide `FileText` (เส้นบาง สไตล์ outline) ทำให้หนา/สไตล์ต่างจากปุ่มอื่นที่ใช้ไอคอน SVG เติมสี (fill) สีเขียวหัวเป็ด `#0A8778`

## สิ่งที่จะทำ

1. สร้าง `src/assets/documents-icon.svg` — ไอคอนเอกสารแบบ fill สี `#0A8778` ขนาด 32x32 สไตล์เดียวกับไอคอนปุ่มอื่น (เส้นโค้งมน, กระดาษเอกสารพร้อมมุมพับ + ขีดบรรทัด 3-4 เส้น)
2. แก้ `src/components/job/JobActionButtons.tsx`:
   - เปลี่ยนปุ่มเอกสารจาก `<FileText className="w-8 h-8" />` เป็น `<img src={documentsIcon} className="w-8 h-8" />` ให้เหมือนปุ่มอื่น
   - ลบ import `FileText` ที่ไม่ใช้แล้ว

## ไม่แตะ

- หน้าต่างเอกสาร (JobDocumentsSheet) และหัวข้อภายใน ไม่เกี่ยวกับแถวปุ่ม
- ตรรกะการซ่อน/แสดงปุ่มเดิมทั้งหมด

## ผลลัพธ์

แถวปุ่มทั้ง 4 ปุ่มมีไอคอนสไตล์และสีเดียวกันหมด
