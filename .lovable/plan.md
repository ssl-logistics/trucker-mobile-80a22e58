# แสดงสาเหตุจริงเมื่อเคลียร์ยอดไม่สำเร็จ

## สิ่งที่ตรวจแล้ว
- งาน OR20261027001 ในระบบหลัก: ปิดงานแล้ว (completed), สถานะยังไม่เคลียร์, ยอด ฿1 — งานพร้อมเคลียร์
- ระบบหลักตอบเหตุผลกลับมาเสมอเมื่อปฏิเสธ (เช่น "ต้องแนบรูป", "ข้อมูลไม่ถูกต้อง: ประเภทคนขับ / ลิงก์รูป")
- แต่แอปทิ้งเหตุผลนั้นไป แล้วขึ้นแค่ "ส่งไม่สำเร็จ ลองใหม่อีกครั้ง" — จึงยังบอกไม่ได้ว่าครั้งนี้ถูกปฏิเสธเพราะอะไร

## สิ่งที่จะแก้
- เมื่อส่งไม่สำเร็จ ให้แสดงเหตุผลจริงจากระบบหลัก (แปลเป็น 4 ภาษาสำหรับรหัสที่รู้จัก เช่น ต้องแนบรูป, งานยังไม่ปิด, ไม่พบงาน, เคลียร์ไปแล้ว; ถ้าไม่รู้จักให้แสดงข้อความจากระบบหลักตรง ๆ)
- ถ้าระบบหลักบอกว่าออเดอร์นี้เคลียร์ไปแล้ว ให้ย้ายไปแท็บ "เคลียร์แล้ว" ทันที
- บันทึกเหตุผลการปฏิเสธไว้ในบันทึกของระบบ เพื่อให้ผมตรวจย้อนหลังได้
- หลังแก้ ให้ลองกดยืนยันอีกครั้ง แล้วผมจะดูเหตุผลจริงและแก้ต้นเหตุต่อ

## Technical
- `submitCodClear` (`src/lib/codClear.ts`): parse error body `{error_code, error}` / zod `fieldErrors`, return `{ data: body, error }` instead of `data: null`
- `CodClearPage.tsx` send: use `data.error_code`; add `ALREADY_CLEARED` text; fallback toast description = server message
- `cod-clear-proxy`: `console.log` upstream status + body when status >= 400; redeploy
