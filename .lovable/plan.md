# ต้องเซ็นชื่อก่อนผ่านทุกจุดรับ-ส่ง

## สิ่งที่ผู้ใช้จะเห็น
- ทุกหน้ายืนยัน SOP ของทุกจุด ทั้งงานในประเทศและต่างประเทศ (จุดรับสินค้า, จุดส่งสินค้า, ลานรับตู้, ลานคืนตู้) จะมีกล่อง "ลายเซ็นผู้รับ/ผู้ส่ง" เพิ่มก่อนปุ่มยืนยัน
- ในกล่องมีช่องกรอกชื่อผู้เซ็น, พื้นที่ให้เซ็นด้วยนิ้ว และปุ่ม "ล้าง"
- ปุ่มยืนยันกดไม่ได้จนกว่าจะเซ็นแล้ว ถ้ายังไม่เซ็นจะมีข้อความเตือน "กรุณาให้ผู้รับ/ผู้ส่งเซ็นชื่อก่อนยืนยัน"
- ข้อความทั้งหมดรองรับ 4 ภาษา (ไทย/อังกฤษ/เกาหลี/จีน)

## สิ่งที่ไม่เปลี่ยน
- ขั้นตอนเดิม ลำดับหน้า รูปถ่าย OCR และการส่งสถานะทั้งหมดทำงานเหมือนเดิม เพิ่มแค่ลายเซ็นที่ต้องกรอกก่อนกดยืนยัน

## Technical details
- คอมโพเนนต์ใหม่ `src/components/job/SignaturePad.tsx`: วาดบน canvas ด้วย pointer events (ไม่ต้องเพิ่ม library), ใช้ได้ทั้งการแตะบนมือถือและบน Safari, ส่งค่า `{ dataUrl, signerName, isEmpty }` กลับไป
- ใส่ไว้ใน `SOPCheckInPage.tsx` (รับสินค้า), `DeliverySOPCheckInPage.tsx` (ส่งสินค้า), `ContainerSOPPage.tsx` (รับ/คืนตู้) ก่อนปุ่มยืนยัน ใน `handleConfirmClick` ถ้า `isEmpty` ให้หยุดพร้อมแสดง toast
- ตอนยืนยัน: อัปโหลดรูปลายเซ็น PNG ผ่าน `upload-to-s3` ที่มีอยู่แล้ว (พร้อมกับรูปอื่นๆ) และใส่ฟิลด์ใหม่ `signature_url` และ `signer_name` เข้าไปใน payload เช็คอิน/SOP เดิม เป็นฟิลด์เสริม ระบบ TMS จะไม่สนใจฟิลด์นี้จนกว่าจะเพิ่มคอลัมน์รองรับฝั่งนั้น
- เก็บสำเนาลายเซ็นไว้ใน localStorage ด้วย key `signature_${order}_${pointKey}` ไว้ดูย้อนหลัง/ส่งซ้ำ
- เพิ่ม i18n keys ทั้ง 4 ภาษา
- ต้องแจ้งทีม TMS ให้เพิ่มรองรับ `signature_url` / `signer_name` ใน endpoint เช็คอิน
