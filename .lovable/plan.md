# เพิ่แถว "ส่งที่" บนการ์ดงานต่างประเทศ

## สิงที่จะได้รบั

ในหน้างานปัจจุบัน การ์ดงานต่างประเทศจะเพิ่แถว **"ส่งที่ : บจก. โกลเด้นเวย์ 21"** (ชื่อสถานที่รบั สินคาเท่านั้ น) ขึ้ นไว้กอนแถว "ปลายทาง" ทำให้อานไดต้ ามลำดบั การงานจริง:

```text
ต้นทาง    : โรงงานบางบ่อ
ส่งที่      : บจก. โกลเด้นเวย์ 21     <- เพิ่ใหม
ปลายทาง   : Rojana บ่อวิน (แหล่งคืนตู้)
```

- แสดงเฉพาะงานตางประเทศ และเฉพาะตอนท่ี API ส่งชื่ อสถานที่มาให (ถาไม มีชื่ อจะไม แสดงแถวน้ี)
- ปาย "ปลายทาง" ยังแสดงแหล่งคืนตู้ตามเดิม ไม เปลี่ นคำ
- งานในประเทศ และหน้าแรก/ประวัต/ิ รายละเอยด: ไม มี การเปลี่ นแปลง

## ขั้ นตอนการทำ

1. **เพิ่ มคำแปล** `job.deliveryTo` ใน `src/contexts/LanguageContext.tsx` ครบ 4 ภาษา (ไทย `ส่งที่`, อังกฤษ `Deliver to`, เกาหลี `배송지`, จีน `送达地`) วางไว ขางหลังคีย์ `job.destination` ของแตละภาษา
2. **เพิ่ มแถวใน การ์ด** `src/pages/CurrentJobsPage.tsx` สว นเรนเดอร ตำแหน งของงานตางประเทศ (บรรทัด ~1282-1298): แทรกระหวางแถวตนทางกับแถวปลายทาง ใช อ ikon ท่ีตางจากikon โหมดpin ของปลายทาง (เช น ikon รถบรสิ ง/หีบห อ) แสดงก็ ตอเมื่ อ `job.destination_name` ไม วางา
3. **ตรวจโค้ ด** `bunx tsgo --noEmit -p tsconfig.app.json` + ดู `tail /tmp/observability/build-errors.log`
4. **ทดสอบดว ย Playwright** จำลองงาน 3 แบบ (ตางประเทศมีชื่ อส งถิง / ตางประเทศไม มี ชื่ อส งถิง / งานในประเทศ) แล วถายส กรีนช อตยืนยันดวยภาพ
5. **บันทึ กงาน** ลง `roadmap.md` และความจำโ ครงการ

## รายละเอยดทางเทคนิค

- **แหล งขอมูล**: API `get-driver-assigned-jobs` ส งชอง `destination_name` มาให แล ว (ตรวจจากขอมูลจริง: `OR20260922002/01` = โรงงาน Ford ระยอง, `OR20260922002/02` = บจก. โกลเด้นเวย์ 21) และบล็อกงานจากบรริ ัทในแอปผานขอมูลน ้ีตอการดวยการ spread (`...job`) ดังนั้ น **ไม ตองแก ้ การดึงขอมูล**
- **เงื่ อนไขแสดง**: ใช้ตวั ช้ีงานตางประเทศแบบเดียงกกับแถวเลขตู (job_type international หรือมี bl_no/booking_no) + `destination_name` มีคา
- **รูปแลว การ์ด**: การ์ดงานตางประเทศจะส งข้ ึนประมาณ 1 แถว (~20px) เฉพาะงานที่มีชื่ อส งถิง
