# เมนูสรุปยอดเงิน: ไอคอนไม่กะพริบ และเลขแดงขึ้นทันที

## สิ่งที่ผู้ใช้จะเห็น
- ไอคอน "สรุปยอดเงิน" ขึ้นพร้อมไอคอนอื่นทันที ไม่โหลดรูปใหม่ทุกครั้งที่กลับมาหน้าแรก
- เลขแดงจำนวนออเดอร์ค้างเคลียร์ขึ้นทันทีจากจำนวนล่าสุดที่เคยดึงไว้ แล้วอัปเดตเงียบ ๆ เมื่อได้ข้อมูลใหม่
- สลับหน้าไปมาไม่ทำให้เลขหายแล้วค่อยขึ้นใหม่

## Technical
- `AppHeader.tsx`: ฝังไอคอน cod-clear เป็นข้อมูลในตัว (`?inline`) ให้แสดงได้ทันทีโดยไม่ต้องโหลดไฟล์
- `usePendingCodClears.ts`: เก็บรายการล่าสุดไว้ในหน่วยความจำร่วม (ระดับโมดูล) + localStorage ต่อคนขับ; เริ่มต้น state จากค่านี้; ถ้าเพิ่งดึงไม่เกิน 60 วินาทีไม่ดึงซ้ำตอนสลับหน้า; หน้าสรุปยอดเงินยังดึงใหม่ทุกครั้งที่เปิดเหมือนเดิม
