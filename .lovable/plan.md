# แผน: คำหน้าชื่อบริษัทบนหน้าแรก — แยกตามข้อมูลงานจริง "โรงงาน" / "บริษัท"

## ปัญหาตอนนี้

คำหน้าชื่อบริษัทบนการ์ดงานหน้าแรกยังไม่ได้เช็คจากข้อมูลที่ API ส่งมา แต่ตัดสินจากแท็บที่เลือก + ประเภทคนขับ/รถ (`isFactoryJob` prop): แท็บงานโรงงาน/คนขับในบริษัท → "โรงงาน", งานเช่าด่วนของฟรีแลนซ์ → "ผู้จ้าง" ทำให้งานเช่าด่วนที่จริงโพสต์จากโรงงานก็ยังแสดง "ผู้จ้าง" — การใช้ประเภทคนขับหรือรถมาตัดสินไม่ถูกต้อง เพราะมีกรณีรถบริษัทแต่วิ่งให้โรงงาน

## สิ่งที่จะทำ

เปลี่ยนมาเช็คจากข้อมูลงานจริงที่ API ส่งมา แล้วแสดง 2 คำ:

- งานที่มีข้อมูลโรงงาน (`factory_id` หรือ `factory_name` ไม่ว่าง) → **"โรงงาน : ..."**
- งานที่ไม่มีข้อมูลโรงงาน (งานบริษัท/งานทั่วไป) → **"บริษัท : ..."** (เปลี่ยนจากคำว่า "ผู้จ้าง")

ตัวอย่าง:
- `โรงงาน : บจก.ตัวอย่าง`
- `บริษัท : บริษัท สหพันธ์ เทรดดิ้ง กรุ๊ป จำกัด`

## รายละเอียดทางเทคนิค

- `src/pages/Home.tsx` — ตอน map ข้อมูลจาก 2 API (งานโรงงาน/งานที่ได้รับมอบหมาย และงานเช่าด่วน) เพิ่ม field `is_factory_job: !!(item.factory_id || isValidName(item.factory_name))` ให้ทุกงาน
- `src/components/home/JobCard.tsx` (บรรทัด 160) — เลือกคำจาก `job.is_factory_job` ก่อน ถ้าไม่มีข้อมูล (undefined) ค่อย fallback เป็น prop `isFactoryJob` เดิม (กันหน้าอื่นที่ยังไม่ส่ง field ใหม่)
- เปลี่ยนค่า translation `job.employer` ใน `src/contexts/LanguageContext.tsx` ครบ 4 ภาษา: th `ผู้จ้าง`→`บริษัท`, en `Employer`→`Company`, ko `고용주`→`회사`, zh `雇主`→`公司` — key นี้ถูกใช้ใน 4 จุด (การ์ดหน้าแรก, การ์ดประวัติงาน, งานปัจจุบัน, หน้าประมูล) ทุกจุดจะแสดง "บริษัท" ให้คำเรียกสอดคล้องกันทั้งแอป
- ไม่แตะ: การดึงข้อมูลชื่อบริษัท (employer_name fallback chain), flow การรับงาน, ปุ่มต่างๆ, หน้าแสดง "โรงงาน" สำหรับคนขับในบริษัท (internal/external) ตามเดิม
