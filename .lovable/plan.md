# ปรับหน้าโลโก้ตอนเปิดแอปให้สวยขึ้น ไม่มีข้อความ

## สิ่งที่จะทำ (แก้เฉพาะ UI หน้าโลโก้ 3 วินาที)

แก้ไฟล์เดียว: `src/components/StartupSplash.tsx` + เพิ่ม keyframes ใน `src/index.css`

1. **เอาข้อความ "กำลังโหลด..." ออกทั้งหมด** — เหลือแค่โลโก้ + แอนิเมชันโหลด
2. **แอนิเมชันใหม่แทนจุด 3 จุดเดิม**:
   - โลโก้ The Truckers ขยับ "ลอยหายใจ" เบา ๆ (ขึ้นลง 4px, ช้า ๆ 2 วินาทีต่อรอบ)
   - วงแหวนโหลดสีเขียวแบรนด์: วงกลมบาง ๆ หมุนตรงใต้โลโก้ — เส้นสี primary หมุนรอบวงสีเทาจาง ๆ
3. **พื้นหลังเพิ่มมิติเล็กน้อย**: วงกลมสีเขียวจาง ๆ โปร่งแสง 2 วง อยู่หลังโลโก้ (เบลอ/โปร่ง) ให้ดูนุ่มไม่ว่างเปล่า — ใช้สีจาก token เดิม ไม่ใส่สีตายตัว
4. **ตอนจบจางออกเหมือนเดิม** (300ms fade) — เวลา 3 วินาที, การโหลดข้อมูลเบื้องหลัง, การซ่อนเมนูล่างช่วงโลโก้ ทุกอย่างคงเดิมไม่แตะ

## ข้อจำกัดที่คงไว้

- แสดงทุกอุปกรณ์ 3 วินาทีเหมือนเดิม
- รองรับ reduced motion (ผู้ใช้ตั้งปิดแอนิเมชัน → แสดงแบบนิ่ง)
- ใช้สีจาก design token เท่านั้น (primary เขียวแบรนด์)
- ไม่แตะ API, การโหลดข้อมูล, flow เดิม

## ตรวจสอบ

- typecheck + build ผ่าน
- เปิดหน้า preview ดูหน้าโลโก้ด้วย Playwright จับภาพหน้าจอยืนยันความสวยและไม่มีข้อความ
