# ไม่เลื่อนจอเมื่องานอยู่จุดแรก — ให้หน้าอยู่บนสุดเป็น default

## ปัญหา
เปิดหน้ารายละเอียดงาน ระบบเลื่อนไปการ์ดขั้นตอนปัจจุบันอัตโนมัติ แต่เมื่องานอยู่ขั้นแรก (การ์ดแรกสุด) การเลื่อนไป "กลางจอ" ของการ์ดแรกทำให้จอขยับลงโดยไม่จำเป็น — ผู้ใช้อยากให้อยู่บนสุดเฉย ๆ

## การแก้ (frontend เท่านั้น)
ไฟล์เดียว: `src/components/job-detail/DomesticJobDetail.tsx` (useEffect auto-scroll บรรทัด ~1368–1410)

เพิ่มเงื่อนไข: ถ้าการ์ดเ标ปลายทางที่คำนวณได้คือ **การ์ดแรกสุดของหน้า** ให้ข้ามการเลื่อน (ไม่เรียก scrollIntoView) — หน้าคงอยู่บนสุด:

- งานต่างประเทศ (BL/Booking): ถ้า `!isContainerStepCompleted` (ขั้นปัจจุบัน = รับตู้ การ์ดแรก) → ไม่เลื่อน
- งานในประเทศ: ถ้า `!pickupDone` (ขั้นปัจจุบัน = จุดรับสินค้า การ์ดแรก) → ไม่เลื่อน

ขั้นอื่นทั้งหมด (ขั้น 2 เป็นต้นไป, คืนตู้, จุดส่ง) คงเลื่อนอัตโนมัติเหมือนเดิม รวมถึงกรณี fallback ที่ target กลายเป็น `card1Ref` ก็ไม่เลื่อนด้วย

## สิ่งที่ไม่แตะ
- flow เช็คอิน / SOP / POD / สแกน QR / ลายเซ็น / OCR / การส่ง API ทั้งหมดคงเดิม
- เงื่อนไขเลื่อนครั้งเดียวต่อออเดอร์ (autoScrolledOrderRef) คงเดิม
- ไม่แก้ edge function หรือ backend
