# แถบเมนูปุ่ม (ดูค่าใช้จ่าย / เพิ่มค่าใช้จ่าย / แจ้งปัญหา / เอกสาร) กระพริบตอนโหลด

## ปัญหา
แถบเมนูปุ่มบนหน้าต่าง ๆ (SOP, เช็คอินตู้, สรุปตู้, จุดรับ, จุดส่ง ฯลฯ) กระพริบตอนเปิดหน้า เพราะ
1. ไอคอน 4 ตัวเป็นไฟล์ SVG แยก ต้องโหลด/ถอดรูปใหม่ทุกครั้งที่เปิดหน้า
2. จำนวนปุ่มที่แสดงขึ้นกับข้อมูลที่โหลดทีหลัง (เช่น POD เสร็จหรือยัง, มาจากประวัติหรือไม่) ทำให้ปุ่มขึ้นก่อนแล้วหาย/เปลี่ยนจำนวน ตารางปุ่มขยับ

## สิ่งที่จะแก้ (frontend เท่านั้น ไม่แตะ flow/API)

1. **ฝังไอคอนไว้ในตัวแอป** — เปลี่ยน import ไอคอน 4 ตัวใน `JobActionButtons.tsx` เป็น `?inline` (data URI) เหมือนที่ทำกับไอคอนเมนูด่วนหน้าแรก ไอคอนจะขึ้นพร้อมหน้าทันที ไม่แวบ
2. **แสดงกล่องจาง ๆ แทนระหว่างโหลด** — เพิ่ม prop `isLoading` ให้ `JobActionButtons`: ถ้าหน้ายังโหลดข้อมูลงาน/สถานะอยู่ ให้แสดงกล่องจาง ๆ 4 กล่อง (skeleton) แทนปุ่มจริง พอโหลดเสร็จค่อยแสดงปุ่มชุดเดียวที่ถูกต้องทันที ไม่เปลี่ยนจำนวนทีหลัง
3. **ส่งสถานะโหลดเข้าจากทุกหน้าที่ใช้** — 8 หน้า: SOPCheckInPage, ContainerCheckInPage, ContainerSOPPage, ContainerSummaryPage, DeliveryDetailPage, DeliverySOPCheckInPage, PickupDetailPage, PickupSummaryPage — ส่ง flag โหลดที่มีอยู่แล้วของแต่ละหน้าเข้า prop นี้

## รายละเอียดเทคนิค
- `src/components/job/JobActionButtons.tsx`: import ไอคอนด้วย `?inline`, เพิ่ม prop `isLoading?: boolean` → แสดง skeleton grid 4 กล่อง (rounded, bg-muted animate-pulse) เมื่อ true
- หน้าทั้ง 8: `<JobActionButtons ... isLoading={loading} />` โดยใช้ตัวแปร loading ที่มีอยู่แล้วของแต่ละหน้า (ไม่เพิ่มการโหลดใหม่)
- ตรรกะการซ่อน/แสดงปุ่มเดิม (POD, history, หมดอายุ 3 วัน) คงเดิมทั้งหมด
- ตรวจด้วย npx tsgo + build
