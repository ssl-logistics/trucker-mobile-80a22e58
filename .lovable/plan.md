# ดู/เพิ่มค่าใช้จ่าย เปิดเป็นหน้าต่างในหน้าต่างเช็คอินจุดเพิ่ม

ในหน้าต่างเช็คอินของจุดดรอป / รับตู้ที่ดรอปไว้ / จุดส่ง-รับสินค้าเพิ่ม: ตอนนี้ปุ่ม "ดูค่าใช้จ่าย" และ "เพิ่มค่าใช้จ่าย" จะพาออกไปอีกหน้า จะเปลี่ยนให้เปิดเป็นหน้าต่างเด้งซ้อนขึ้นมาแทน ไม่ต้องออกจากหน้างาน

## การทำงาน
- กด "ดูค่าใช้จ่าย" → หน้าต่างรายการค่าใช้จ่ายของงานนี้ (เนื้อหาเหมือนหน้าเดิมทุกอย่าง แก้/ลบได้เหมือนเดิม)
- กด "เพิ่มค่าใช้จ่าย" → หน้าต่างฟอร์มเพิ่มค่าใช้จ่าย (ประเภท, จำนวนเงิน, แนบใบเสร็จ เหมือนเดิม)
- บันทึกเสร็จหรือกดปิด → กลับมาที่หน้าต่างเช็คอินเดิม รูปที่แนบไว้ยังอยู่
- เอกสาร และ แจ้งปัญหา เป็นหน้าต่างอยู่แล้ว ไม่เปลี่ยน

## ไม่เปลี่ยน
- ข้อมูลที่ส่ง/บันทึกค่าใช้จ่ายเหมือนเดิม
- ปุ่มค่าใช้จ่ายที่จุดอื่นๆ (รับตู้, จุดหลัก, คืนตู้, ประวัติงาน) ยังเปิดเป็นหน้าเหมือนเดิม

## Technical details
- `JobActionButtons`: เพิ่ม prop `expenseMode?: 'page' | 'sheet'` (ค่าเริ่มต้น 'page'); ใน `ExtraPointCheckinSheet` ส่ง `'sheet'`
- เมื่อเป็น sheet: เปิด `Sheet` เต็มจอ render `JobExpensesPage` / `AddExpensePage` แบบ embedded
- เพิ่ม prop เสริมในสองหน้านั้น: `embeddedJobId`, `embeddedState`, `onClose` — ใช้แทน `useParams`/`location.state` และแทน `navigate(-1)`/navigate กลับ เมื่อส่งมา; ซ่อน header BackButton แล้วใช้ปุ่มปิดของ sheet
- จากรายการค่าใช้จ่ายใน sheet การกดเพิ่ม/แก้ไข สลับเนื้อหาภายใน sheet เดียวกัน
