# แก้หน้าสรุปยอดเงินที่ยังแสดงแบบเดิม

## สิ่งที่พบ
- โค้ดหน้าใหม่ (หัวข้อ "สรุปยอดเงิน", ช่องสรุป 3 ช่อง, รายการจุดส่ง, ปุ่มไอคอนเคลียร์) บันทึกอยู่ในแอปแล้ว
- แต่รูปที่ส่งมายังเป็นหน้าเก่า (หัวข้อ "เคลียร์ยอด", การ์ดมีลูกศร >) แปลว่าหน้าตัวอย่างยังไม่ได้โหลดเวอร์ชันใหม่ หรือมีอะไรทำให้หน้าใหม่ไม่ขึ้น ยังไม่ยืนยันสาเหตุ

## ขั้นตอน
1. เปิดหน้าสรุปยอดเงินในเบราว์เซอร์ทดสอบ (ล็อกอินเป็นคนขับ) แล้วถ่ายภาพหน้าจอ เพื่อดูว่าขึ้นหน้าใหม่หรือไม่
2. ถ้าขึ้นหน้าใหม่: แจ้งให้โหลดหน้าตัวอย่างใหม่ และส่งภาพยืนยันให้ดู
3. ถ้ายังเป็นหน้าเก่าหรือมีข้อผิดพลาด: หาสาเหตุจากข้อผิดพลาดของหน้า แล้วแก้ให้หน้าใหม่แสดงครบ:
   - หัวข้อ "สรุปยอดเงิน"
   - สรุปรวม ต้องเก็บ / เก็บแล้ว / ค้าง
   - การ์ดทุกงาน COD ทั้งงานที่กำลังวิ่งและปิดแล้ว พร้อมยอดแต่ละจุด เงินสด/QR และสถานะเก็บแล้ว/ยังไม่เก็บ
   - ปุ่มไอคอนกระเป๋าเงิน กดได้เมื่อเก็บครบและปิดงานแล้วเท่านั้น
4. ยืนยันด้วยภาพหน้าจอว่าเห็นงาน OR20261025011 (฿500 + ฿700) ก่อนแจ้งว่าเสร็จ
5. ข้อความทั้งหมดรองรับ 4 ภาษาตามแอป และสรุปผลเป็นภาษาไทย
