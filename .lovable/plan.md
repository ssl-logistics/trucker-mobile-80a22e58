# เพิ่ มแถว "ส งที่" บนการด์งานต างประเทศ

## สິ่ งท่ีจะไดร้ ับ

ในหน้างงานปั จจุบนั การด์ งานต างประเทศจะเพิ่ มแถว **"ส งที่ : บจก. โกลเด้นเว ย์ 21"** (ชื่ อสถานท่ีรบั บ สິ นค าเท ่านั้ น) ข้ ึ นไว ก อ นแถว "ปลายทาง" ทำให อ านตามลำดบั งานจร งได ้:

```text
ต นทาง    : โรงงานบางบ่อ
ส งที่      : บจก. โกลเด้นเว ย์ 21      <- เพิ่ มใหม
ปลายทาง   : Rojana บ่อวิน (แหล งค นต ู)
```

- แสดงเฉพาะงานต างประเทศ และเฉพาะตอนท่ี API ส งชื่ อสถานท่ีมาให ้ (ถ าไม มี ชื่ อจะไม แสดงแถวน้ี)
- ป ้าย "ปลายทาง" ยั งแสดงแหล งค นต ูตามเดิ ม ไม เปลี่ นคำ
- งานในประเทศ และหน าแรก/ประวตั ิ/รายละเอยด: ไม ม การเปลี่ ยนแปลง

## ขั้ นตอนการทำ

1. **เพิ่ มคำแปล** `job.deliveryTo` ใน `src/contexts/LanguageContext.tsx` ครบ 4 ภาษา (ไทย `ส งที่`, อັ งกฤษ `Deliver to`, เกาหลี `배송지`, จนี `送达地`) วางไว ข างหลั งคีย์ `job.destination` ของแต ละภาษา
2. **เพิ่ มแถวในการด์ ** `src/pages/CurrentJobsPage.tsx` ส วนเรนเดอรตำ แหน งของงานต างประเทศ (บรรทั ด ~1282-1298): แทรกระหว างแถวต นทางกั บแถวปลายทาง ใช ไອคอนท่ีต างจากไอคอนหมำยเล ักโ ดกpin ของปลายทาง (เช นไอคอนรถบรรท ึก/หีบห อ) แสดงก ต อเมื่ อ `job.destination_name` ไม าวาง
3. **ตรวจโคด** `bunx tsgo --noEmit -p tsconfig.app.json` + ดู `tail /tmp/observability/build-errors.log`
4. **ทดสอบด วย Playwright** จำลองงาน 3 แบบ (ต างประเทศมีชื่ อส งถึ ง / ต างประเทศไม มีชื่ อส งถึ ง / งานในประเทศ) แล วถ ายส กรีนช ็อตย ืนยันด วยภาพ
5. **บันทึ กงาน** ลง `roadmap.md` และความจำโครงการ

## รายละเอยดทางเทคนิ ค

- **แหล งข อมูล**: API `get-driver-assigned-jobs` ส งช อง `destination_name` มาให ้แล ้ว (ตรวจจากข อมูลจร ิง: `OR20260922002/01` = โรงงาน Ford ระยอง, `OR20260922002/02` = บจก. โกลเด้นเว ย์ 21) และบล็อกงานจากบริ ัษทในแอปผ านข อมูลน ้ีต อการด วยการ spread (`...job`) ดั งนั้ น **ไม ต องแก การดึ งข อมูล**
- **เงื่ อนไขแสดง**: ใช ้ตั วช ้งานต างประเทศแบบเดี ยวกั บแถวเลขต ู (job_type international หรื อมี bl_no/booking_no) + `destination_name` มี ค ่า
- **ร ูปแล การด์**: การด์ งานต างประเทศจะส ูงข ้ึ นประมาณ 1 แถว (~20px) เฉพาะงานท่ีมี ชื่ อส งถึ ง
