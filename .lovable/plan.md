# แผน: ไอคอนเมนูลัดหน้าแรกโหลดครั้งเดียว ไม่แวบใหม่

## สาเหตุ
ไอคอน 4 จุดในส่วนหัว (งานปัจจุบัน / ตลาดงาน / รายได้ / ประวัติงาน) ถูกฝังเป็น data URI ในโค้ด (`?inline`) ทุกครั้งที่หน้าถูกสร้างใหม่ เบราว์เซอร์ต้องถอดรหัสและวาดรูปใหม่ทุกครั้ง จึงเห็นแวบ/โหลดซ้ำบ่อย ทั้งที่เป็นรูปเดิม

## สิ่งที่จะทำ (แก้เฉพาะ UI/การโหลดรูป)
1. **AppHeader.tsx** — เปลี่ยน import ไอคอนทั้ง 4 (`current-job-icon.svg`, `market-icon-new.webp`, `income-icon.svg`, `job-history-icon.svg`) จาก `?inline` เป็น import ปกติ ให้ Vite แยกเป็นไฟล์จริงที่มีชื่อ hash — เบราว์เซอร์จะจำไฟล์ไว้ถาวร (cache แบบ immutable) โหลดครั้งแรกครั้งเดียว เปลี่ยนหน้าไปมาแสดงทันทีจากแคช
2. คงโค้ดอุ่นแคช (`new Image()`) ไว้เหมือนเดิม เพื่อให้รูปพร้อมตั้งแต่เปิดแอป
3. เช็คซ้ำไอคอนแถบเมนูล่าง (BottomNavigation) ให้ใช้วิธีเดียวกันถ้ายังฝัง data URI อยู่ — ให้ทุกไอคอนของแอปโหลดครั้งเดียวแล้วจำไว้

## ไม่แตะต้อง
- หน้าตา ขนาด ตำแหน่ง และข้อความของไอคอน/เมนูเดิม
- flow งานและข้อมูลทั้งหมด

## รายละเอียดเทคนิค
- ไฟล์ที่แก้: `src/components/layout/AppHeader.tsx` (และ `BottomNavigation.tsx` ถ้าจำเป็น)
- ตรวจด้วย `npx tsgo --noEmit -p tsconfig.app.json` และ build
