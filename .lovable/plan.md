# การ์ดแนะนำปุ่ม "ดูคิว" ในหน้างานปัจจุบัน (กดรับทราบ)

## สิ่งที่จะทำ
- เมื่อหน้างานปัจจุบันมีงานที่มีปุ่ม **ดูคิว** แสดงการ์ดแจ้งบอกแนะนำปุ่มนี้:
  - ไฮไลต์ปุ่ม ดูคิว ของงานใบแรกที่มีคิว ด้วยกรอบสีส้ม + เลื่อนจอให้เห็น
  - การ์ดข้อความใต้ปุ่ม: "เมนูใหม่! ดูคิว — กดเพื่อดูลำดับคิวและเวลาโดยประมาณของงานนี้" + ปุ่ม **รับทราบ**
  - ข้อความเปลี่ยนตามภาษาแอป (ไทย/อังกฤษ/เกาหลี/จีน)
- กด **รับทราบ** → การ์ดหาย และบันทึกว่าบัญชีนี้ (ตาม user id คนขับ) รับทราบแล้ว
- กดปุ่ม ดูคิว ตอนการ์ดแสดงอยู่ = นับว่ารับทราบ แล้วเปิดหน้าต่างคิวตามปกติ
- ถ้าไม่มีงานที่มีคิวเลย จะไม่แสดงการ์ด

## เงื่อนไขการแสดง (เหมือนการ์ดแจ้งซ่อม)
- **หน้า preview** (URL ที่มี `id-preview--`): แสดงทุกครั้งที่มีงานมีคิว แม้กดรับทราบแล้ว — ทดสอบซ้ำได้
- **production จริง**: แสดงครั้งเดียวต่อบัญชี — กดรับทราบแล้วไม่แจ้งอีก; บัญชีใหม่ที่ยังไม่เคยกดจะเห็นการ์ด
