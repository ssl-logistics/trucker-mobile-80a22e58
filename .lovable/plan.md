# แก้การโหลดซ้ำหลายครั้งและซ่อนข้อความ "กำลังโหลด"

## ปัญหา
1. หน้ารายละเอียดงาน (DomesticJobDetail) โหลดสถานะเช็คอินซ้ำหลายครั้ง — ทุกครั้งที่ข้อมูลงาน (jobApplication) เปลี่ยน reference ฟังก์ชัน `fetchStatuses` ถูกสร้างใหม่ ทำให้ useEffect รันใหม่แบบ `showLoading=true` → รีเซ็ตสถานะทั้งหมดเป็น false แล้วแสดง skeleton ซ้ำ การ์ดจึงกระพริบ/หายไปหลายรอบ
2. กล่อง skeleton มีข้อความ "กำลังโหลด..." แสดงอยู่ — ผู้ใช้ไม่ต้องการให้เห็นข้อความนี้

## การแก้ไข (frontend เท่านั้น ไม่แตะ flow/API เดิม)

### 1. ลบข้อความ "กำลังโหลด" ออกจาก skeleton
- `src/components/job/JobListSkeleton.tsx`: ลบ `<p>{t('common.loading')}</p>` ออก เหลือแค่กล่องจาง ๆ (ใช้ร่วมกันทั้งหน้ารายละเอียดงาน, งานปัจจุบัน, ประวัติงาน — ข้อความจะหายทุกหน้า)

### 2. โหลดแบบเต็มจอครั้งเดียวต่อออเดอร์ ครั้งถัดไปโหลดเงียบ ๆ
- `src/components/job-detail/DomesticJobDetail.tsx`:
  - เก็บ `jobApplication` ล่าสุดไว้ใน ref แล้วให้ `fetchStatuses` อ่านจาก ref แทนการใส่ใน dependency — ฟังก์ชันจะไม่ถูกสร้างใหม่เมื่อข้อมูลงานอัปเดต จึงไม่เรียกโหลดซ้ำ
  - ใช้ ref จำว่าออเดอร์นี้โหลดครั้งแรกไปแล้วหรือยัง — useEffect เรียก `fetchStatuses(true)` เฉพาะครั้งแรกของออเดอร์นั้น; ถ้าฟังก์ชันถูกเรียกซ้ำด้วยเหตุอื่น ให้เรียกแบบ `fetchStatuses(false)` (ไม่รีเซ็ตสถานะ ไม่แสดง skeleton การ์ดไม่หาย)
  - การ re-fetch ตอนกลับมาที่แท็บ (focus/visibilitychange) และ burst-poll หลังเช็คอิน เป็นแบบเงียบอยู่แล้ว คงไว้เหมือนเดิม

### 3. จำสถานะเช็คอินไว้ในเครื่อง เปิดซ้ำ/กดกลับแสดงทันที
- หลัง `fetchStatuses` สำเร็จ เก็บผลสถานะ (pickup/delivery/container/destination checkins + SOP) ลง sessionStorage key `checkinStatus:${order_code}` (ผ่าน `pageCache.ts` ที่มีอยู่)
- ตอนเปิดหน้า: ถ้ามีแคชของออเดอร์นั้น ให้ set สถานะจากแคชทันทีและไม่แสดง skeleton เลย แล้วค่อยโหลดข้อมูลใหม่เงียบ ๆ ด้านหลัง
- ครั้งแรกสุดที่ยังไม่มีแคช: แสดงกล่อง skeleton จาง ๆ (ไม่มีข้อความ) ตามเดิม

## ไฟล์ที่แก้
- `src/components/job/JobListSkeleton.tsx` — ลบข้อความกำลังโหลด
- `src/components/job-detail/DomesticJobDetail.tsx` — กันโหลดซ้ำ + แคชสถานะเช็คอิน

## ไม่เปลี่ยนแปลง
- flow เช็คอิน / SOP / POD / สแกน QR / ลายเซ็น / OCR / การส่ง API ทั้งหมดคงเดิม
- ปุ่มและเงื่อนไขการล็อกการ์ดตามลำดับขั้นตอนคงเดิม
