# เปิดหน้ารายละเอียดงานแล้วเลื่อนไปที่การ์ดขั้นตอนปัจจุบันอัตโนมัติ

## ปัญหา
เปิดหน้ารายละเอียดงานมาแสดงที่ด้านบนเสมอ ทั้งที่งานเดินไปถึงขั้นตอนท้าย ๆ แล้ว (เช่น คืนตู้แล้ว) ผู้ใช้ต้องเลื่อนลงเองทุกครั้ง

## สิ่งที่จะทำ
- หลังโหลดสถานะเช็คอินเสร็จ ให้หน้าเลื่อน (smooth scroll) ไปที่การ์ดของ "ขั้นตอนปัจจุบัน" อัตโนมัติ — การ์ดแรกที่ยังทำไม่เสร็จ:
  - งานในประเทศ: จุดรับสินค้า → จุดส่งสินค้า (จุดที่ยังไม่ POD)
  - Booking (ขาออก): รับตู้เปล่า → รับสินค้า → คืนตู้หนัก
  - BL (ขาเข้า): รับตู้หนัก → ส่งสินค้า → คืนตู้เปล่า
- ถ้างานเสร็จครบทุกขั้นแล้ว เลื่อนไปที่การ์ดสุดท้าย (เช่น การ์ดคืนตู้) แทน
- เลื่อนเฉพาะครั้งแรกที่เปิดหน้า (ต่อการเปิด 1 ครั้ง) — ไม่เลื่อนซ้ำตอนรีเฟรชเบื้องหลัง, ตอนกลับมาที่แท็บ, หรือหลังผู้ใช้เลื่อนเองแล้ว
- รอให้ skeleton หายและการ์ดแสดงจริงก่อนค่อยเลื่อน (ใช้ requestAnimationFrame/timeout สั้น ๆ)
- หน้าที่เปิดจากประวัติงาน (read-only) ก็เลื่อนไปที่การ์ดสุดท้ายที่ทำเสร็จแล้วเช่นกัน

## รายละเอียดทางเทคนิค
- `DomesticJobDetail.tsx`: มี ref ของการ์ดอยู่แล้ว (`card1Ref`, `emptyContainerRef`, `deliveryCardRefs`, `containerReturnRef`)
- เพิ่ม useEffect ที่รอ `!isLoadingCheckinStatus` แล้วคำนวณการ์ดเป้าหมายจากสถานะเช็คอิน/SOP/POD ที่มีอยู่ จากนั้นเรียก `el.scrollIntoView({ behavior: 'smooth', block: 'center' })`
- ใช้ ref flag กันเลื่อนซ้ำ (key ตาม order_code — เปลี่ยนออเดอร์แล้วเลื่อนใหม่ได้)
- ไม่แตะ flow เช็คอิน/SOP/POD/สแกน QR/การส่ง API ใด ๆ

## ตรวจสอบ
- `npx tsgo` + build ผ่าน
- เปิดงานที่คืนตู้แล้ว → หน้าเลื่อนไปที่การ์ดคืนตู้เอง
- เปิดงานที่ยังไม่เช็คอิน → อยู่ด้านบนตามเดิม (การ์ดแรกคือเป้าหมาย)
