# แผน: เติมข้อความเกาหลี/จีนให้แจ้งเตือนคิวเก่าที่เก็บไว้แล้ว

## ปัญหา
แจ้งเตือนคิว QTruck ที่สร้างก่อนเพิ่มการแปล 4 ภาษา มีเฉพาะไทย/อังกฤษ — คนขับที่ใช้ภาษาเกาหลีหรือจีนจะเห็นข้อความภาษาไทยแทน (หน้าแจ้งเตือน fallback กลับไปที่ title_th) พบ 5 รายการในตาราง notifications ที่ title_ko/title_zh เป็น NULL

## สิ่งที่จะทำ
รัน SQL อัปเดตข้อมูลย้อนหลัง (backfill) ในตาราง `notifications` เฉพาะแถวที่ `notification_type = 'qtruck_queue'` และยังไม่มี title_ko/title_zh:

1. **หัวข้อ (title)** — แปลตาม title_th เดิม:
   - "ใกล้ถึงคิวแล้ว" → 곧 차례가 됩니다 / 快排到您了
   - "ถึงคิวแล้ว!" → 차례가 되었습니다! / 排到您了！
   - "กำลังขึ้น/ลงสินค้า" → 상/하차 진행 중 / 正在装/卸货
   - "คิวเสร็จสิ้น" → 대기열 완료 / 队列已完成
   - "คิวถูกย้าย" → 대기열이 이동되었습니다 / 队列已移动
   - "คิวถูกยกเลิก" → 대기열이 취소되었습니다 / 队列已取消

2. **รายละเอียด (description)** — แปลโดยดึงเลขคิวและชื่อประตูออกจาก description_th เดิมด้วย pattern เดิม (เช่น "คิว 2 ที่ประตู GATE4 เสร็จเรียบร้อยแล้ว" → "대기열 2번 GATE4 게이트 완료" / "队列 2 在 GATE4 闸门已完成") ใช้รูปแบบประโยคเดียวกับที่ webhook สร้างใหม่

3. คงข้อความต่อท้าย "โรงงาน/ทะเบียน" (ถ้ามี) ไว้ใน description_ko/description_zh ด้วยป้ายภาษานั้น (공장/차량번호, 工厂/车牌)

## ไม่แตะต้อง
- ไม่แก้โค้ด webhook หรือหน้าแอป (แปล 4 ภาษาใหม่ทำงานถูกแล้ว)
- ไม่แตะแจ้งเตือนประเภทอื่น
- ไม่ส่ง push ซ้ำ

## ตรวจสอบหลังทำ
- query ยืนยันว่าไม่เหลือแถว qtruck_queue ที่ title_ko/title_zh เป็น NULL
- เปิดหน้าแจ้งเตือนสลับภาษาเป็นเกาหลี/จีน เห็นข้อความแปล
