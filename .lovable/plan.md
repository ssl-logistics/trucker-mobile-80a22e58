# แสดงสินค้าในการ์ดจุดเพิ่ม / จุดดรอป

## สิ่งที่ผู้ใช้จะเห็น
- การ์ดจุดเพิ่ม (หน้ารายละเอียดงาน และหน้ารายละเอียดจุด) มีหัวข้อ "สินค้า" ต่อจากผู้ติดต่อ/เบอร์โทร
- แต่ละรายการแสดง: ชื่อสินค้า (มีรหัสสินค้าต่อท้ายถ้ามี), จำนวน + หน่วย (แปลหน่วย เช่น box = กล่อง, pallet = พาเลท), น้ำหนัก (กก.) ถ้ามี, หมายเหตุ ถ้ามี
- ค่าที่เป็น null ไม่แสดงแถวนั้น
- ไม่มีสินค้า: ไม่แสดงหัวข้อนี้ (การ์ดเหมือนเดิม)
- ไม่เปลี่ยนขั้นตอนเช็คอินหรือการล็อกใดๆ

## Technical details
- `src/lib/extraPoints.ts`: เพิ่ม `products?: ExtraPointProduct[]` ใน `ExtraPoint` (product_code, product_name, quantity, unit, weight, notes)
- `ExtraPointCard.tsx`: เพิ่มบล็อกรายการสินค้า (ไอคอน Package) สไตล์เดียวกับรายการสินค้าในการ์ดหลัก; หน่วยแปลผ่านตัวแปลหน่วยที่ใช้อยู่ใน `apiDataTranslations` (ถ้าไม่มีใช้ค่าดิบ)
- ตรวจว่า `JobDetailPage.tsx` ส่ง `products` ของแต่ละจุดผ่านไปครบ (ไม่ถูกตัดตอน map)
- คำแปล "สินค้า"/"น้ำหนัก"/"รหัส" ใช้คีย์เดิมของการ์ดหลักใน 4 ภาษา
