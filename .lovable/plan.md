# กดไอคอนแชทมุมขวาล่าง เปิดรายการแชท (Mockup UI) สำหรับฟรีแลนซ์

## เป้าหมาย
เมื่อผู้ใช้ฟรีแลนซ์กดไอคอนแชท (MessageCircle) มุมขวาล่าง แทนที่จะนำไปหน้า `/chat` ให้เปิดแผง/หน้าต่างแสดง "รายการแชท" แบบ mockup (ข้อมูลตัวอย่าง) กางออกมาบนหน้าปัจจุบัน เพื่อดูหน้าตาก่อนเชื่อมข้อมูลจริง

## ขอบเขต
- เฉพาะ role `freelance_driver`
- เป็น mockup UI เท่านั้น — ไม่เชื่อม API แชทจริง ไม่ส่งข้อความได้
- ปุ่มบอทของ role อื่นคงเดิมทุกอย่าง

## การแก้ไข

### 1. สร้าง `src/components/chat/ChatListSheet.tsx` (ใหม่)
- แผงเลื่อนขึ้นจากล่าง (ใช้ `Dialog` หรือ `Sheet` ที่มีอยู่ในโปรเจกต์ สไตล์เดียวกับ `ChatbotDrawer`)
- Header: ชื่อ "แชท" + ปุ่มปิด (X)
- เนื้อหา: รายการแชท mockup 4–6 รายการ แต่ละแถวมี:
  - Avatar (ตัวอักษรย่อชื่อ)
  - ชื่อคู่สนทนา เช่น "บริษัท ขนส่ง A", "โรงงาน B", "แอดมินตลาด"
  - ข้อความล่าสุดตัวอย่าง + เวลา
  - จุด/ตัวเลข unread บางรายการ
- แตะที่รายการ: ยังไม่ทำอะไร (mockup) หรือแสดง toast "เร็วๆ นี้"
- ปุ่ม "ดูประวัติการโทร" เล็กๆ ที่นำไป `/chat` ของจริง (เผื่อเข้าหน้าเดิม)

### 2. ปรับ `src/components/chatbot/FloatingChatbot.tsx`
- เปลี่ยนปุ่มแชทของฟรีแลนซ์จาก `navigate("/chat")` เป็น `setShowChatList(true)`
- render `<ChatListSheet open={showChatList} onOpenChange={setShowChatList} />`
- เงื่อนไขการแสดง (หน้า / การตั้งค่า / role) คงเดิม

## วิธีทดสอบ
1. ล็อกอินฟรีแลนซ์ → หน้า `/home` กดไอคอนแชทมุมขวาล่าง → แผงรายการแชท mockup กางขึ้น
2. กด X หรือแตะพื้นหลัง → แผงปิด
3. ล็อกอิน role อื่น → ยังเห็นปุ่มบอทและ ChatbotDrawer เดิม
