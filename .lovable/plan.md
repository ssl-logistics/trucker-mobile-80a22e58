# แผน: คำหน้าชื่อบริษัทบนการ์ดงาน — "โรงงาน" / "บริษัท"

## สิ่งที่จะทำ

แยกคำหน้าชื่อบริษัทบนการ์ดงานตามประเภทงาน:

- **งานโรงงาน** → แสดงคำว่า **"โรงงาน : ..."** (คงเดิม)
- **งานเช่าด่วน / งานบริษัท** → เปลี่ยนจาก **"ผู้จ้าง"** เป็น **"บริษัท"**

ตัวอย่างบนหน้าแรก:
- การ์ดงานโรงงาน: `โรงงาน : บจก.ตัวอย่าง`
- การ์ดงานเช่าด่วน: `บริษัท : บริษัท สหพันธ์ เทรดดิ้ง กรุ๊ป จำกัด`

## รายละเอียดทางเทคนิค

- เปลี่ยนค่า translation ของ key `job.employer` ใน `src/contexts/LanguageContext.tsx` ครบ 4 ภาษา:
  - th: `ผู้จ้าง` → `บริษัท`
  - en: `Employer` → `Company`
  - ko: `고용주` → `회사`
  - zh: `雇主` → `公司`
- key `job.employer` ถูกใช้ใน 4 จุด (JobCard, HistoryJobCard, CurrentJobsPage, BiddingPage) — ทุกจุดจะเปลี่ยนเป็น "บริษัท" ให้คำเรียกสอดคล้องกันทั้งแอป ไม่ต้องแก้ logic ประเภทงานเดิมที่เลือกแสดง "โรงงาน" สำหรับงานโรงงานอยู่แล้ว
- ไม่แตะ: การดึงข้อมูลชื่อบริษัท (employer_name fallback chain), flow การรับงาน, หน้าอื่นๆ
