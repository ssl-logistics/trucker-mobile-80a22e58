# ลดความสูงหัวเรื่องหน้า "เพิ่มค่าใช้จ่าย" ให้เท่ากับหน้า "ค่าใช้จ่าย"

## ปญหา

แถววหัวข้อของหน้า "เพิ่มค่าใช้จ่าย" สูงกวาหน้า "ค่าใช้จ่าย" ที่เป็นตัวอ้างอิง 11px (วดได้จริง 87px เทียบกับ 76px) ทำใหดู้หนาและกินพื้นที่มากกวาที่ควร

| หน้า | ความสูงแถวหัวข้อ (วดจริง) |
| --- | --- |
| ค่าใช้จ่าย (อ้างิง) | 76px |
| เพิ่มค่าใช้จ่าย | 87px |

## สิงที่จะปรับ

- ลดช่องวางสางบน-ล่างของแถวหัวข้อหน้า "เพิ่มค่าใช้จ่าย" จาก 16px ลงเหลือ 11px → ความสูงรวม 76px เทากับหน้า "ค่าใช้จ่าย" พอดีกน
- ปุ่มนอกกลบยงคงขนาดเดิม (แตะงายเหมือนเดิม)
- สี พนหลัง ขอบ และตำแหน่งตัวอักษรคงเดิม ทงหมด (ไมไดเปลี่นรูปแบบอืน)
- หน้า "ค่าใช้จ่าย" ไมไดแกอะไร เพราะเป็นตัวอ้างิง

## หลงแกแลว

```text
กอน:  [ < ]  เพิ่ มค ่าใช ้จ ่าย      87px
หลงั:  [ < ]  เพิ่ มค ่าใช ้จ ่าย      76px   = เทาหน้า "ค่าใช ้จ ่าย"
```

## รายละเอยดทางเทคนิค

- ไฟลที่แก: `src/pages/AddExpensePage.tsx` บรรทัด 642
  - `className="px-4 py-4 flex items-center gap-3"` → `className="px-4 py-[11px] flex items-center gap-3"`
- คำนวณ 76px: พื้ นทีกนรอยบักจอบน 14px (`.app-sticky-header` ใน `src/index.css` บรรทัด 290) + ปุ่ มยอนกลบ 40px + ช่องวางบน-ล่าง 11×2 = 76px
- ตัวอางิง: `src/pages/JobExpensesPage.tsx` บรรทัด 473 ใช `px-4 py-6` + ปุ่ ม `p-1` = 76px
- หมายเหตุ: 11px เปนคาเฉพาะจุดถาตองการได 78px (คาที่ใชทั่วไปในแอป เช่น `PlaceBidPage`) ใช `py-3` แทนได แพงกัน 2px
- บนมือถอทมีุ่มจอกวาง (notch) แอปจะเวนนพื้ นทีกนรอยบักเพิ่มอัติโนมัติตามมาตรฐาน ระบบ — หวั เรือง "เพิ่ มคาใช ้จ ่าย" จะยงไม ทับกบั รอยบัก (หน้า "คาใช ้จ ่าย" ไม มสว นน)
- ไม มการแกขอ มลู ราคาคาใช ้จ ่าย หรือการคำนวณใดๆ

## วธิีตรวจสอบ

1. วดความสุงแถวหัวข้อทังสองหนาดวย Playwright ใหม 76px เทากน (ท่ 393×805)
2. วดซำท่ความสุงจอ 805 / 667 / 568px: หน้า Login-ไมตองเลอนจอยงคงเดิม และแถวหัวข้อไมกดบังปุม "เพิ่มรายการ"
3. ตรวจ `build-errors.log` วาดบิลผาน
