# หน้าสรุปยอดเงิน: แสดงเฉพาะงานของคนขับที่เข้าระบบ

## สิ่งที่ผู้ใช้จะเห็น
- หน้าสรุปยอดเงินแสดงเฉพาะงาน COD ของคนขับที่เข้าระบบอยู่เท่านั้น งานของคนขับคนอื่น (เช่น OR20261025011) จะไม่ขึ้น
- ยอดรวม 3 ช่องคำนวณจากงานของตัวเองเท่านั้น
- ตัวเลขบนเมนูหน้าแรกและแจ้งเตือนเคลียร์ยอดตอน 05:00/05:30 ใช้กฎเดียวกัน
- เปลี่ยนบัญชีแล้ว ข้อมูลของบัญชีเก่าไม่ค้าง

## Technical
- สาเหตุ: รายการเช็คอินจากระบบหลักส่งเช็คอินของคนขับหลายคนกลับมา (ไม่ได้กรองตามคนขับ) แอปจึงเอางานของคนอื่นมาแสดง
- `src/lib/codClear.ts`: เพิ่ม `checkinsForDriver(checkins, driverId)` เก็บเฉพาะแถวที่ `freelance_driver_id` / `internal_driver_id` / `external_driver_id` ตรงกับคนขับ ใช้ใน `fetchCodSummaries` และ `fetchPendingCodClears` ก่อนหาออเดอร์
- `cod-clear-reminder`: กรองแบบเดียวกันต่อคนขับ แล้ว deploy ใหม่
- cache ใน localStorage: ล้างเมื่อ driverId ไม่ตรง
- เพิ่ม test: เช็คอินของคนขับอื่นถูกตัดออก
