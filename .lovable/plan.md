# แผน: งานจบแล้ว redirect ไปหน้างานปัจจุบัน

## เป้าหมาย
เมื่องานทำจบแล้ว (ยืนยัน POD จุดส่งสุดท้าย หรือคืนตู้คอนเทนเนอร์เสร็จ) ให้ redirect ไปหน้า **งานปัจจุบัน** (`/current-jobs`) แทนที่จะกลับหน้ารายละเอียดงานหรือหน้าแรก ส่วนจุดที่ยังไม่จบให้กลับหน้ารายละเอียดงานเหมือนเดิม

## พฤติกรรมปัจจุบัน (ตรวจจากโค้ดแล้ว)
- ยืนยัน POD เสร็จ → กลับหน้ารายละเอียดงานเสมอ (`DeliveryDetailPage.tsx:818`, `DeliverySOPCheckInPage.tsx:337`)
- คืนตู้สำเร็จ → ไปหน้าแรกสุด `/` (`ContainerSOPPage.tsx:1562`)
- งานที่จบแล้วถูกซ่อนจากหน้างานปัจจุบันอยู่แล้ว (POD ครบ / คืนตู้แล้ว)

## การเปลี่ยนแปลง

### 1. `src/pages/ContainerSOPPage.tsx` — คืนตู้เสร็จ
- เปลี่ยน `navigate('/')` เป็น `navigate('/current-jobs')` เฉพาะกรณี `isContainerReturn` (งานต่างประเทศจบสมบูรณ์)
- กรณีรับตู้ (ยังไม่จบ) กลับหน้ารายละเอียดงานเหมือนเดิม

### 2. `src/pages/DeliveryDetailPage.tsx` — ยืนยัน POD
หลัง POD สำเร็จ แยกกรณี:
- **งานต่างประเทศ** (BL/Booking/international): กลับหน้ารายละเอียดงานเหมือนเดิม เพราะต้องคืนตู้ต่อ
- **งานในประเทศ**: ตรวจว่าเป็น "จุดส่งสุดท้าย" หรือไม่ โดยนับ sequence ที่มี `delivery_confirmed` จาก checkins ที่โหลดไว้ (`filteredCheckins`) รวมกับ sequence ที่เพิ่งยืนยัน และ optimistic checkins — ถ้าครบทุกจุดส่งของงาน → `navigate('/current-jobs')`; ถ้ายังเหลือจุดอื่น → กลับหน้ารายละเอียดงานเหมือนเดิม

### 3. `src/pages/DeliverySOPCheckInPage.tsx` — ยืนยัน POD (อีก flow)
- ใช้กฎเดียวกัน: นับ `delivery_confirmed` จาก optimistic checkins + ข้อมูล destinations ของงาน — ครบทุกจุด → `/current-jobs`; ไม่ครบ → กลับหน้ารายละเอียดงาน

## เงื่อนไข "จุดสุดท้าย"
```text
จำนวน sequence ที่มี delivery_confirmed (รวมจุดที่เพิ่งยืนยัน)
  >= จำนวนจุดส่งทั้งหมดของงาน (destinations.length, ขั้นต่ำ 1)
```

## สิ่งที่ไม่เปลี่ยน
- flow เช็คอิน / SOP / POD / คืนตู้ และ payload ที่ส่ง API ทั้งหมด
- งานต่างประเทศยังต้องคืนตู้ก่อนจึงจะถือว่าจบ
- หน้างานปัจจุบันซ่อนงานที่จบแล้วตามเดิม (งานที่เพิ่งจบจะไม่โผล่ในลิสต์ — เป็นพฤติกรรมที่ตั้งใจ)
- กรณีมาจากหน้าประวัติ (read-only) ไม่เกี่ยวข้อง เพราะกดยืนยันไม่ได้อยู่แล้ว

## การทดสอบ
- typecheck (`tsgo`) + build ผ่าน
- ตรวจใน preview: งานจุดเดียว POD แล้วเด้งไปงานปัจจุบัน; งานหลายจุด POD จุดแรกยังกลับหน้ารายละเอียด; คืนตู้เสร็จเด้งไปงานปัจจุบัน
