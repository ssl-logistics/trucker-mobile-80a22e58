# ล็อกไม่ให้ปิดหน้าต่างเช็คอิน/อัปโหลด ระหว่างกำลังส่งข้อมูล

## สิ่งที่ผู้ใช้จะเห็น
- ระหว่างกดยืนยันแล้วกำลังอัปโหลดรูป/ส่งข้อมูล หน้าต่างจะปิดไม่ได้ทุกวิธี: ปุ่ม X, ปุ่มยกเลิก, แตะพื้นหลัง, ปัดลง, ปุ่มย้อนกลับ
- ปุ่ม X / ยกเลิก เป็นสีจาง กดไม่ได้ และมีข้อความกำลังส่ง (มีอยู่แล้ว)
- ส่งเสร็จ: ปิดเองตามเดิม / ส่งล้มเหลว: ปลดล็อก แสดงข้อผิดพลาด ข้อมูลและรูปยังอยู่ กดส่งใหม่ได้

## หน้าต่างที่จะปรับ
- เช็คอินจุดเพิ่ม (ดรอปตู้/รับตู้ที่ดรอป/จุดสินค้าเพิ่ม)
- เก็บเงิน COD + รูปหลักฐาน และหน้าต่างเคลียร์ยอด
- แจ้งอุบัติเหตุ/แนบหลักฐาน
- สแกน OCR / ยืนยันตู้-ซีล / สลิปคืนตู้ / สแกน QR โหลดสินค้า
- ลายเซ็น (ล็อกอยู่แล้ว ตรวจให้ครบ)

## รายละเอียดทางเทคนิค
- ส่งสถานะ busy จากฟอร์มขึ้นไปที่ Dialog/Drawer/Sheet: `onOpenChange={(o) => !busy && set(o)}`
- ใส่ `onPointerDownOutside`/`onEscapeKeyDown`/`onInteractOutside` preventDefault เมื่อ busy; Drawer ใช้ `dismissible={!busy}`
- ซ่อน/disable ปุ่มปิดของ DialogContent ขณะ busy
- ใช้ `try/finally` รีเซ็ต busy เสมอ เพื่อไม่ค้างล็อกเมื่อ API ล้มเหลว
- แก้เฉพาะหน้าจอ (frontend) เท่านั้น ไม่แก้ API, ข้อมูลที่ส่ง, ระบบหลังบ้าน หรือขั้นตอนการทำงานใดๆ
