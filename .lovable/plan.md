# หน้า Login: ลดความสูงรูปด่ายบนให้พอດีจอ ไมต่้องเลื่อน

## สิ่่งท่ีผ้้ใชจ้ะได

- กรอบรูปด่ายบนของหน้าเข้าสู่ระบบส้ันลงมาก (จาก ~322px เหลือ ~118–177px ตามความส้งจอ) และหน้า Login ไมต่้องเลื่อนลงอีก ทังบนจอเตี้ยและจอส้ง
- ภาพไม่ย้ืด ไมบ่ีบ เพราะใช้วิธตีัดขอบออก (object-cover) และใชรู้ปใหมท่ีผ้้ใชจ้ะส่่งมา (อตัราส่ว้นกว้้าง)
- ฟอรม์ และเมนูภาษาเข้้าถึงไดท้้ังหมดโดยไมต่้องเลื่อน

## ขั้่นตอนการทำงาน

1. ใชรู้ปใหมท่ีผ้้ใชส้่่งมา (แนะนำ 1200x480 px) วางแทนท่ีรูปเดิมในตำแหน່งเดิม
2. เปลี่่ยนความส้งกรอบรูปในหน้า Login เป็็นค่าทีอยุ่ตวั: `max(72px, min(22vh, calc(100dvh - 450px)))`
   - 450px ค่อพื้่นท่ีจริงทฟ่ี อรม์+เมนูภาษาต้องการ (ว้ัดจากหน้าจอจริง)
   - ผล: จอ 805px ไดร้ปูสู้ง ~177px, จอ 667px ~147px, จอ 568px ~118px — ท่กขนาดไม่มีscroll
3. คง `object-cover` ไว้ (กัันภาพยื้ด) และคงกติิิการเดิมของหน้า Login: ฟอรม์เต็มความกว้้าง, pt-12, ไมซ่้อนส่ว้นเกืน
4. ตรวจด้้วย Playwright บนความส้งจอ 805 / 740 / 700 / 667 / 640 / 600 / 568: ไม่มี scroll, ฟอรม์ครบ, เมนูภาษาเห็็นและกดได,้ รูปไมถ่ ูกตัดจนเสียของสำคัญ
5. บันทึกงานน้ีลง roadmap.md และเก็็บข้้อเท็็จจริงเรื่้องรูป/ขนาดไว้ใน memory

## รายละเอียดทางเทคนิิค

- ไฟลร์ูป: `public/lovable-uploads/login-background-2.png` (เดิม 375x380 px RGBA PNG, 177KB) — วางไฟล์ใหมท่ับชื่อเดิม
- ขนาดแนะนำ: **กว້าง 1200 x ส้้ง 480 px** (แนวนอน, 2.5:1) — ภาพต້องกว້างกว่่าส้้ง เพราะกรอบแสดงเต็็มกว້างจอแตส้้่งแค่ ~118–177px; อย้่้ในชว่่ง 2.2:1 ถิง 3:1 ก็ได,้ PNG/WebP <= ~300KB
- จุ้ดแกไ้ค้โค้ด: `src/pages/SignIn.tsx` บรรทัด 346-348
  - `<div className="relative h-[40vh] flex-shrink-0">` → `<div className="relative flex-shrink-0" style={{ height: "max(72px, min(22vh, calc(100dvh - 450px)))" }}>`
  - `<img ... className="absolute inset-0 w-full h-full object-cover" ... />` คงไว้
- หน้า "ลืมรหัสผ่าน" และ "ตัง้ รหัสผ่านใหม" ใชอ้ีกไฟลห์ นึ่ง (`src/assets/login-background.png` 1125x1140, 1.3MB) — จะแกใ้ห้ตรงกนั ตอ่ เมื่ อผ้้ใชส้ั่ ง
- ข้้อควรทราบ: การ์ด "การแจ้่งเตอื่ นถกู ปิ ดอย่้" ท่ีขึ้้นตอนเปิ ดครัง้ แรกอาจบังเมนูภาษา (เป็็นคนละสว่้นกัับความส้งรูป) — ยงั ไม่แกไ้ ในแผนน้ี
