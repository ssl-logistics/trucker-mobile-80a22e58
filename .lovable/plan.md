เพิ่มปุ่ม "ดูข้อมูลงาน" ในการ์ดดรอปตู้ (แสดงหน้าจออย่างเดียว)

## สิ่งที่ผู้ใช้จะเห็น
- การ์ดดรอปตู้สีส้มในหน้า "งานปัจจุบัน" มีปุ่มเพิ่ม "ดูข้อมูลงาน" ใต้ปุ่มโทร / เส้นทาง
- กดแล้วเปิดหน้าข้อมูลดรอปตู้ แสดง:
  - หัวข้อ: BL/Booking + รหัสตู้ (เช่น 06)
  - ลำดับขั้น 2 ขั้น ที่สถานที่เดียวกัน:
    1. ดรอปตู้ — สถานที่, ที่อยู่, ผู้ติดต่อ/เบอร์, หมายเหตุ, ปุ่มโทร/เส้นทาง
    2. รับตู้ (จุดเดิม) — ข้อมูลเดียวกัน
  - ยังไม่มีปุ่มเช็คอิน / ไม่ส่งข้อมูลใด ๆ (รอข้อมูลจากหลังบ้าน)
- แก้คำว่า "jobDetail.place" ที่แสดงเป็นรหัส ให้เป็น "สถานที่" (และภาษาอื่น)
- ไม่กระทบขั้นตอนงานหลัก

## Technical
- `DropPointListCard.tsx`: เพิ่มปุ่ม navigate ไป `/job/:jobId/extra-point/drop/:seq` (route มีอยู่แล้ว) ส่ง `state: { jobData, point }`
- `ExtraPointPage.tsx`: ปรับเป็นหน้าแสดงอย่างเดียว — header + 2 การ์ด (ดรอปตู้ / รับตู้) ใช้ `ExtraPointCard` พร้อม timeline dot, ไม่มี action เช็คอิน; fallback อ่านจุดจาก `location.state` แล้ว `getExtraDropPoints`
- เพิ่ม translation keys `jobDetail.place`, `dropPoint.viewJob`, `dropPoint.dropStep`, `dropPoint.pickupStep` ครบ 4 ภาษา
