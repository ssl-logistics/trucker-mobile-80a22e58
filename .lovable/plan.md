# งานต่างประเทศ: จุดรับ/ส่งสินค้าเพิ่ม และจุดดรอปตู้ (การ์ดแยก)

## สิ่งที่คนขับจะเห็น

### 1) หน้างานปัจจุบัน: ดรอปตู้เป็นการ์ดแยกด้านนอก
ตู้ที่มี `extra_drop_points` จะมีการ์ดแยกในรายการงานปัจจุบัน 1 ใบต่อจุดดรอป อยู่ต่อจากการ์ดงานหลักของตู้นั้น:

```text
[BL OQLU2339283950]  รหัสตู้ 01          <- การ์ดงานหลัก (เดิม)
[ดรอปตู้ #1]  ป้ายส้ม  รหัสตู้ 01        <- การ์ดใหม่ แยกด้านนอก
   ลาน: ลาน X   ที่อยู่ ...   ผู้ติดต่อ/เบอร์
   [ดูข้อมูลงาน]  [โทร] [นำทาง]
```

- กด "ดูข้อมูลงาน" บนการ์ดดรอปตู้ → หน้าดรอปตู้ของจุดนั้น: ขั้น "วางตู้" (เช็คอิน + รูปตู้) และ "รับตู้กลับ" (เช็คอิน + รูปตู้) ไม่มีขั้นสินค้า/POD
- ทำครบแล้วการ์ดดรอปตู้หายจากงานปัจจุบัน
- **flow เดิมของงานหลักคงเดิมทั้งหมด** — การ์ดดรอปตู้และจุดสินค้าเพิ่มเป็นส่วนเสริม ไม่ล็อก ไม่เปลี่ยนลำดับ และไม่เพิ่มเงื่อนไขให้ขั้นเดิม (รับตู้, SOP, POD, คืนตู้, ย้ายไปประวัติ)
- ค้นหา/ตัวกรองเห็นการ์ดดรอปตู้ไปพร้อมกับงานหลัก

### 2) หน้ารายละเอียดงาน: จุดรับ/ส่งสินค้าเพิ่ม
```text
[รับตู้]                         (เดิม)
[จุดรับ/ส่งสินค้า หลัก]           (เดิม)
[จุดรับ/ส่งสินค้า เพิ่ม #1]  ป้ายน้ำเงิน   <- extra_cargo_points
[คืนตู้ / ส่งตู้]                 (เดิม)
```

- การ์ดหน้าตาเหมือนจุดสินค้าเดิม: ชื่อสถานที่, ที่อยู่, ผู้ติดต่อ, เบอร์, หมายเหตุ, ปุ่มโทร/นำทาง, เช็คอิน → แนบหลักฐาน → ยืนยัน
- เรียงตาม `sequence`; ตู้ที่ไม่มีจุดเพิ่มเติม หน้าจอและขั้นตอนเหมือนเดิม 100%
- ข้อความครบ 4 ภาษา (ไทย/อังกฤษ/เกาหลี/จีน)

## ต้องยืนยันก่อนเริ่ม (ขั้นแรกของงาน)
1. ดูข้อมูลจริงจาก API งานคนขับว่ามี `extra_cargo_points` / `extra_drop_points` ส่งมาแล้ว
2. การเช็คอินของจุดเพิ่มส่งอะไรไปหลังบ้าน — คู่มือยังไม่ได้ระบุ ข้อเสนอ:
   - จุดสินค้าเพิ่ม: `checkin_type` เดิมของจุดรับ/ส่ง + `extra_point_sequence`
   - ดรอปตู้: `checkin_type = container_drop` และ `container_drop_pickup` + `extra_point_sequence`
   ถ้าหลังบ้านยังไม่รองรับ จะเก็บสถานะในเครื่องชั่วคราวและแจ้งก่อนทำต่อ

## ไม่แตะ
flow จุดหลักเดิม (รับตู้, SOP, POD, คืนตู้), QTruck, การเงิน, เมนูเอกสาร, งานในประเทศ

## รายละเอียดทางเทคนิค
- `src/components/job-detail/DomesticJobDetail.tsx`: อ่าน `job.extra_cargo_points` (เรียง `sequence`) เรนเดอร์การ์ดเพิ่มหลังจุดสินค้าหลัก; ไม่แก้เงื่อนไข/ปุ่มของการ์ดเดิมใดๆ
- `src/pages/CurrentJobsPage.tsx`: แตกการ์ดดรอปตู้จาก `extra_drop_points` เป็นรายการแยกต่อจากการ์ดงานหลัก
- คอมโพเนนต์ใหม่ `ExtraCargoPointCard` และ `DropPointCard` ใน `src/components/job-detail/`
- เส้นทางขั้นตอน: จุดสินค้าเพิ่มใช้หน้า check-in/SOP เดิมโดยส่ง `extraPoint` ใน `location.state`; ดรอปตู้ใช้ `ContainerCheckInPage`/`ContainerSOPPage` ด้วย `checkinType` ใหม่
- mapping ข้อมูลงานใน `CurrentJobsPage.tsx` / ตัวดึงงาน ให้ส่งสอง field นี้ผ่าน `jobData`
- `utils/jobCompletionFilter.ts`: งานจะย้ายไปประวัติเมื่อครบเงื่อนไขเดิม (ไม่เพิ่มเงื่อนไข) + เทสต์
- i18n คีย์ `extraPoint.*`, `dropPoint.*` ใน `LanguageContext.tsx`
- ทดสอบ Playwright ด้วยข้อมูลจำลองตู้ที่มี 1 จุดสินค้าเพิ่ม + 1 ดรอปตู้ และตู้ที่ไม่มี
