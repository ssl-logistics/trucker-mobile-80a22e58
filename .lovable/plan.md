# เพิ่มการ์ดแนะนำเมนู "สำรองจ่าย" ในหน้าเพิ่มค่าใช้จ่าย

## สิ่งที่จะทำ (frontend เท่านั้น ไม่แตะ flow เดิม)

ไฟล์: `src/pages/AddExpensePage.tsx`, `src/contexts/LanguageContext.tsx`

1. **การ์ดแนะนำสวิตช์ "สำรองจ่าย"** — เปิดหน้าเพิ่มค่าใช้จ่ายครั้งแรก จะมีกรอบสีส้มครอบสวิตช์ "สำรองจ่าย" พร้อมการ์ดอธิบายใต้สวิตช์:
   - หัวข้อ: "เมนูใหม่! สำรองจ่าย"
   - คำอธิบาย: "เปิดสวิตช์นี้เมื่อยอดค่าใช้จ่ายนี้เป็นเงินสำรองจ่าย"
   - ปุ่ม "รับทราบ"
2. **เงื่อนไขการแสดง** (เหมือนการ์ดเมนูอื่น):
   - production: แสดงครั้งเดียวต่อบัญชี เก็บ localStorage key `advance_payment_intro_ack:<driverId>` (บัญชีใหม่ยังเห็น)
   - preview (hostname มี `id-preview--`): แสดงทุกครั้งเพื่อทดสอบ
   - กด "รับทราบ" หรือกดสวิตช์สำรองจ่าย = นับว่ารับทราบ การ์ดหายไป
3. **ขนาดการ์ด** — กว้างคงที่ `w-64 max-w-[calc(100vw-2rem)]` จัดชิดขวาใต้สวิตช์ ไม่บีบตามความกว้างสวิตช์ (เรียนจากบั๊กการ์ดเอกสาร)
4. **ข้อความ 4 ภาษา** (ไทย/อังกฤษ/เกาหลี/จีน) เพิ่ม keys `expense.advance_intro_title/desc/ack` ใน LanguageContext

## ตรวจสอบ
- `npx tsgo --noEmit -p tsconfig.app.json` ผ่าน + build OK
- เปิดหน้าเพิ่มค่าใช้จ่ายใน preview (จอ 393px) ยืนยันการ์ดแสดงถูกตำแหน่ง ไม่ล้นขอบจอ
