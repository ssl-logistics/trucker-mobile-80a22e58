# แก้หน้าเคลียร์ยอดยังไม่แสดงงาน OR20261025010

## สาเหตุ (ตรวจแล้วจากข้อมูลจริง)
1. **แอปเรียกเช็คยอดไม่ได้เลย (Load failed)** — ระบบหลักไม่อนุญาตให้แอปส่ง key แบบที่ใช้กับเส้นเช็คอิน เวลาเรียกเส้นเช็คยอด COD จากหน้าแอปเบราว์เซอร์จึงบล็อกทุกครั้ง ส่วนเส้นเช็คอินอนุญาตไว้แล้ว
2. **สถานะงานไม่ตรงกับที่แอปคาดไว้** — ถ้าเรียกจากฝั่งเซิร์ฟเวอร์ ระบบตอบกลับปกติ: OR20261025010 `status: pending` ยอด 120 บาท แต่ `order_status` เป็น `completed` ขณะที่แอปกรองเอาเฉพาะ `closed` เลยตัดงานนี้ทิ้ง

## สิ่งที่จะแก้
1. เพิ่มตัวกลางฝั่ง backend `cod-clear-proxy` (GET เช็คยอด / POST เคลียร์ยอด) เรียกระบบหลักด้วย key เดิม (`EXPRESS_RENT_API_KEY`) แล้วให้แอปเรียกผ่านตัวนี้แทน จะได้ไม่โดนบล็อก ไม่ต้องรอระบบหลักแก้
2. ถือว่างานปิดแล้วเมื่อ `order_status` เป็น `closed`, `completed`, `delivered` หรือไม่มีค่า
3. ตัวแจ้งเตือน 05:00/05:30 ใช้เงื่อนไขสถานะเดียวกัน แล้ว deploy ใหม่
4. อัปเดตเทสต์ให้งาน `completed` ที่ยัง pending ถูกแสดง

## หมายเหตุทางเทคนิค
- ตัวกลางใส่ `x-app-secret` ไว้ในรายการ header ที่อนุญาต (CORS) ตามกฎของโปรเจกต์
- อีกทางหนึ่งคือให้ทีมระบบหลักเพิ่ม `x-api-key` ใน CORS ของ `driver-cod-clear` แต่ใช้ตัวกลางจะเร็วกว่า
