# แก้หน้าต่างเอกสาร: โหลดใหม่ทุกครั้งที่กด + แสดงเฉพาะเอกสารของออเดอร์นั้น

## ปัญหาที่พบ

1. **เลขออเดอร์ติดเลขจุดส่งมาด้วย** — หน้ารายละเอียดงานส่ง `jobId` จาก URL ให้แถวปุ่ม ซึ่งอาจเป็น `OR20260929003/01` (มี `/NN` ต่อท้าย) แต่ API (`get-driver-sop`, `get-driver-checkins`) ค้นหาด้วยเลขออเดอร์ล้วน `OR20260929003` → ดึงไม่เจอ หน้าเอกสารว่าง
2. **ยังไม่การันตีการโหลดใหม่** — ตอนนี้ดึงใหม่ตอนเปิดอยู่แล้ว แต่ไม่ได้ล้างข้อมูลเก่าตอนปิด ทำให้รูปเก่าค้างระหว่างรอโหลด

## การแก้ไข (แตะ 1 ไฟล์)

### `src/components/job/JobDocumentsSheet.tsx`

1. **ตัดเลขต่อท้ายจุดส่งออก** — ก่อนเรียก API ให้ normalize เลขออเดอร์: เอาเฉพาะส่วนก่อน `/` (เช่น `OR20260929003/01` → `OR20260929003`) เพื่อให้ API ค้นเจอเฉพาะเอกสารของออเดอร์นั้น
2. **ล้างข้อมูลตอนปิดหน้าต่าง** — เมื่อ `open` เปลี่ยนเป็น false ให้เคลียร์ `groups`/`failed` ทิ้ง เพื่อให้การกด "เอกสาร" ครั้งถัดไปโหลดข้อมูลล่าสุดจาก API เสมอ ไม่แสดงรูปเก่าค้าง
3. **ลบ state `loadedKey` ที่ไม่ได้ใช้** ออก

## สิ่งที่ไม่เปลี่ยน

- ยังดึงเฉพาะเอกสารของออเดอร์นั้นจาก API 2 เส้นเดิม (`get-driver-sop` + `get-driver-checkins` พร้อม `order_number`) — ไม่ดึงของออเดอร์อื่น
- ยังรวมเอกสารจากคนขับคนก่อนหน้าในออเดอร์เดียวกัน (`allDrivers=true`) สำหรับกรณีรับช่วงงาน — ยังคงเป็นเอกสารของออเดอร์นั้นเท่านั้น
- หน้าตา หมวดหมู่ และปุ่มอื่นๆ คงเดิมทั้งหมด

## ตรวจสอบหลังแก้

- typecheck + build ผ่าน
- เปิดหน้างานที่มี `/NN` ใน URL แล้วกด "เอกสาร" → ต้องแสดงรูปของออเดอร์นั้น (ไม่ว่าง)
- กดปิดแล้วเปิดใหม่ → โหลดใหม่ทุกครั้ง
