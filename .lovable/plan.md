# OR20260915019/14 : จุดรับตู้ในหน้าประวัติยังขึ้น "รอเช็คอิน / อัปเดตสถานะ"

## สาเหตุที่ตรวจพบในโค้ด

หน้ารายละเอียดงานดึงรายการเช็คอินแบบ "เฉพาะคนขับที่ล็อกอิน" เท่านั้น จะดึงแบบรวมทุกคนขับเมื่อ
งานถูกทำเครื่องหมายว่า "โอนงานแล้ว" (`is_transferred`) หรือเมื่อดึงมาแล้วได้ 0 รายการ

กรณีนี้เป็นงานที่ **รับต่อจากคนขับคนก่อน**:
- จุดรับตู้ถูกเช็คอินโดยคนขับคนก่อน → ไม่อยู่ในรายการของคนขับปัจจุบัน
- แต่จุดส่งของคนขับปัจจุบันมีเช็คอิน (POD สำเร็จ) → จำนวนรายการไม่เป็น 0
- เงื่อนไขสำรอง (ดึงรวมทุกคนขับ) จึงไม่ทำงาน การ์ดจุดรับตู้เลยคิดว่ายังไม่เช็คอิน และแสดงหัวข้อ
  "รอเช็คอิน" พร้อมปุ่ม "อัปเดตสถานะ"

หมายเหตุ: ปุ่มในหน้าประวัติถูกปิดการกดอยู่แล้ว (เงื่อนไข `isFromHistory && !isContainerStepCompleted`)
ปัญหาคือการ "แสดงสถานะผิด" ไม่ใช่การกดอัปเดตได้จริง

ยังไม่ยืนยันจากข้อมูลจริงว่าออเดอร์นี้มีเช็คอินจุดรับตู้ของคนขับคนก่อนอยู่หรือไม่ (ข้อมูลเช็คอิน
อยู่ที่ระบบภายนอก ไม่ใช่ฐานข้อมูลของแอป) จึงให้ขั้นแรกของแผนคือตรวจสอบข้อมูลจริงก่อน

## แผนการแก้

1. ตรวจข้อมูลจริงของ OR20260915019/14 จาก API เช็คอิน แบบรวมทุกคนขับ เพื่อยืนยันว่ามีเช็คอิน
   จุดรับตู้จากคนขับคนก่อนจริง
2. ปรับเงื่อนไขการดึงเช็คอินในหน้ารายละเอียดงาน: ให้ดึงแบบรวมทุกคนขับเพิ่มเติมเมื่อ
   "มีเช็คอินขั้นตอนหลัง แต่ขาดเช็คอินขั้นตอนก่อนหน้า" (เช่น มีจุดส่ง/POD แต่ไม่มีจุดรับตู้หรือจุดรับสินค้า)
   แล้วกรองเฉพาะรายการของออเดอร์นี้มารวมกับของเดิม
3. ผลลัพธ์: การ์ดจุดรับตู้จะแสดงเป็น "เสร็จสิ้น" ตามที่คนขับคนก่อนทำไว้ และไม่แสดงปุ่มอัปเดตสถานะ
4. ไม่แตะพฤติกรรมของหน้างานปัจจุบัน ไม่แก้ฐานข้อมูล ไม่แก้ API ภายนอก
