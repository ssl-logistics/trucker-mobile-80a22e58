# แสดงข้อมูลการ์ดจุดดรอป / จุดส่งเพิ่ม ให้ครบตามที่ระบบส่งมา

## ผลตรวจข้อมูลจริง
ระบบหลักส่งข้อมูลจุดเพิ่มมาแบบนี้: สถานที่, ที่อยู่, อำเภอ, จังหวัด, พิกัด, ผู้ติดต่อ, เบอร์, หมายเหตุ, **วันเวลานัด (scheduled_at)**, **สถานะ**, **เวลาเสร็จ (completed_at)**, **รูปที่ถ่ายตอนเช็คอิน (completed_photo_urls)**
ตอนนี้การ์ดแสดงแค่ สถานที่ / ที่อยู่ / ผู้ติดต่อ / หมายเหตุ — ยังขาด วันเวลานัด, เวลาเสร็จ, รูปเช็คอิน และที่อยู่ซ้ำอำเภอ/จังหวัด (ที่อยู่มีจังหวัดอยู่แล้ว)
(ข้อมูลจุดดรอปยังไม่มีส่งมาในงานที่เปิดดู แต่ใช้การ์ดเดียวกัน จึงได้ผลเหมือนกัน)

## สิ่งที่จะเปลี่ยน (หน้าตาเหมือนการ์ดจุดปกติ)
- เพิ่มแถว "วันที่/เวลา" จาก scheduled_at (ไม่มีข้อมูลแสดง "-") เหมือนการ์ดจุดหลัก
- ที่อยู่: ไม่ต่ออำเภอ/จังหวัดซ้ำ ถ้าที่อยู่มีคำนั้นอยู่แล้ว
- ผู้ติดต่อ แยกแถว "เบอร์โทร" เหมือนการ์ดหลัก
- เมื่อเสร็จแล้ว: แสดงเวลาที่เช็คอินเสร็จ และรูปที่ถ่าย (รูปย่อ กดดูใหญ่ได้)
- สถานะ: ใช้ is_completed / status จากระบบหลักร่วมด้วยในการถือว่าจุดนั้นเสร็จ
- ไม่เปลี่ยนขั้นตอนเดิม งานไม่มีจุดเพิ่มเหมือนเดิม

## Technical
- `extraPoints.ts`: เพิ่ม field scheduled_at, is_completed, completed_at, completed_photo_urls ใน `ExtraPoint`; `extraPointAddress` ข้าม district/province ที่มีอยู่แล้วใน address; `cargoDone` / `dropState` เคารพ `is_completed`
- `ExtraPointCard.tsx`: แถววันที่/เวลา (format แบบ dateUtils เดิม), แถวเบอร์, ส่วนเวลาเสร็จ + รูปย่อผ่าน `usePresignedImageUrl` / EditablePhoto viewer เดิม
- เพิ่ม test: address ไม่ซ้ำ, is_completed นับเป็นเสร็จ
