# แสดง "ชื่ อสถานท่ี" ในแถว สถานท่ี ของงานต างประเทศ

## ป ั ญหาท่ีเจ าหน ้าก ำลังเจอ

ตอนเปิ ดงานต างประเทศแบบ Booking (เช น `OR20260922002/02`) แถว **สถานท่ี** ในหน าข อมูลงานแสดง
**เลขท่ีตึก** (`670/50 หมู 10 ถ.รัชดา`) แต **ไม แสดงชื่ อสถานท่ี** (`บจก. โกลเด นเว ย์ 21`) ทั้งท่ี API ส งชื่ อมาให ้แล ้ว
ท ำให ้คนข ับไม ร ู้ว าต องไปส ง/ร ับส ินค าท่ีไหน (ต องเดาจากท่ีอยู ่)

## สิ่ งท่ีจะได ้ร ับ

แถวสถานท่ีในหน าข อมูลงานจะแสดง **ชื่ อสถานท่ี** เป ็นต ัวแรก ส วนท่ีอยู ่ละเอียดย ้ายไปแถว **ท่ีอยู ่**:

```text
ก อนแก ้                            หลังแก ้
สถานท่ี : 670/50 หมู 10 ถ.รัชดา      สถานท่ี : บจก. โกลเด นเว ย์ 21
ท่ีอยู ่  : สมุทรสาคร เมืองสมุทรสาคร   ท่ีอยู ่  : 670/50 หมู 10 ถ.รัชดา สมุทรสาคร เมืองสมุทรสาคร
```

- ไม เพิ่ มแถวใหม และไม เปลี่ยนคำสั่ งใด — แถว สถานท่ี เดิมก ้อแสดงชื่ อสถานท่ี
- ถ ้างานไหน API ไม ส งชื่ อมา จะแสดงท่ีอยู ่แทนเหมื อนเดิ ม (ไม มี ช ่องว างา)
- ใช ้ก ับงานต างประเทศท ุกแบบ ทั้ ง Booking (จ ุดร ับส ินค ้า) และ BL (จ ุดส งส ินค ้า)

## ขั้ นตอนการทำ

แก ้ที่ **จ ุดเดี ยว** ท่ีแอปแปลงข อมูลก อนแสดง (ไม แตะการด ึงข อมูล, ไม แตะการเก บข อมูล):

1. **จ ุดร ับส ินค ้าของงาน Booking** (`src/pages/JobDetailPage.tsx` ~บรรท ัด 679-688)
   - `origin_location` (แถว สถานท่ี) = ชื่ อสถานท่ี จากนั้ นตกgo มาที่อยู ่ถ ้าไม มี ชื่ อ
   - `origin_address` (แถว ท่ีอยู ่) = ท่ีอยู ่เต็ม + จั งหว ัด/อำเภอน (เพิ่ มท่ีอยู ่เ เดิมเข ้ามา ไม หายไปไหน)
2. **จ ุดส งส ินค ้าของงาน BL** (ไฟล เดียวกัน ~บรรท ัด 663-675 และ 690-714)
   - แถว สถานท่ี / ชื่ อบริ ัษัท = ชื่ อสถานท่ี (เดิ มเป ็นเลขตึก)
   - แถว ท่ีอยู ่ = ท่ีอยู ่เ + จั งหว ัด/อำเภอน
3. **รายชื่ อจ ุดส ง** ท่ีแสดงในหน าเดี ยวก ัน (บรรท ัด 690-714) ใช ้ชื่ อสถานท่ีเช นก ัน เพื่ อชื่ อเดี ยวก ันท ุกจ ุด
4. **ตรวจ** `bunx tsgo --noEmit -p tsconfig.app.json` + `tail /tmp/observability/build-errors.log`
5. **ทดสอบ** ด วย Playwright เปิ ดหน า `/#/job/OR20260922002/02` ด วยบั ญชี่ คนข ับจร ิง ถ ายส กรีนช อตยืนย ันว า
   แถว สถานท่ี แสดง `บจก. โกลเด นเว ย์ 21` และแถว ท่ีอยู ่ ยั งมี `670/50 หมู 10 ถ.รัชดา` + จั งหว ัด
6. **บันทึ ก** ลง `roadmap.md` และความจ ำโครงการ

## รายละเอีย ดทางเทคนิ ค

- **แหล งข อมูล**: API `get-driver-assigned-jobs` ส ง `cargo_point = { name, address, province, district, ... }`
  (จ ร ิง: `/02` → name `บจก. โกลเด นเว ย์ 21`, address `670/50 หมู 10 ถ.รัชดา`, province `สมุทรสาคร`)
- **ต ัว maps เดิม** (JobDetailPage บรรท ัด 663-688) เอา `cargo_point.address` ไปใส ่ท ั้ง
  `origin_location`, `destination_company_name`, `destination_location`, `destinations[0].company_name`
  ท ำให ้ `cargo_point.name` ไม ได ้แสดงท่ีไหนเลย (เก บไว ้ใน `cargo_factory_name` เท ่านั้ น)
- **ผลกระทบ**: เป ็นการเปลี่ ยน "ค ่าท่ีแสดง" เท ่านั้ น พิก ัด GPS (latitude/longitude) ชื่ อผ ู ติ ดต ่อ เบอร โ ทร และ
  ปุ่ ม โทร/แผนท่ี ย ังใช ้ค ่าเดิ ม ไม กระทบขั้ นตอน check-in/SOP/POD และงานในประเทศไม ผ านส วน maps น้ี จ ึงไม าก ับข ้อ
  น้ี
- **ย ังไม แตะ**: การ์ดรายการงานในหน ้างานป ัจจ ุบัน (ถ ้าต องการชื่ อสถานท่ีบนการด์ ด้ วย บอกได ้เลย)
