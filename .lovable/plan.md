# แสดงกำลังโหลดและกันกดยืนยันซ้ำหลังเซ็นลายเซ็น

## สถานะปัจจุบัน (ตรวจสอบแล้ว)
- หลังเซ็นสำเร็จ หน้าต่างลายเซ็นปิดและเริ่มส่ง SOP/POD ตาม flow เดิม
- ปุ่มหลักด้านล่างของ `SOPCheckInPage`, `DeliverySOPCheckInPage` และ `DeliveryDetailPage` ยังแสดงข้อความยืนยันเดิมระหว่างส่งข้อมูล แม้มี state กำลังส่งอยู่แล้ว
- `ContainerSOPPage` แสดง “กำลังบันทึก...” และปิดปุ่มอยู่แล้ว แต่จะปรับให้ใช้รูปแบบและตัวป้องกันการกดซ้ำแบบเดียวกัน
- ข้อความกำลังบันทึกเดิมมีเฉพาะไทย/อังกฤษ จึงยังไม่ครบ 4 ภาษาของระบบ

## สิ่งที่จะปรับ
1. เมื่อผู้ใช้เซ็นและกดยืนยันในหน้าต่างลายเซ็น:
   - ปิดหน้าต่างลายเซ็นตามเดิม
   - ปุ่มหลักของหน้าที่อยู่ด้านหลังเปลี่ยนทันทีเป็นไอคอนหมุนพร้อมข้อความ “กำลังบันทึก...” ตามภาษาระบบ
   - ปิดการกดปุ่มจนกว่าการส่ง SOP/POD/รับตู้/คืนตู้จะสำเร็จหรือล้มเหลว
2. ครอบคลุมทุกจุดที่ใช้ลายเซ็น:
   - รับสินค้า / ยืนยัน SOP
   - ส่งสินค้า / ยืนยัน POD ทุกจุดส่ง
   - รับตู้
   - คืนตู้
3. เพิ่มตัวล็อกแบบทันทีในฟังก์ชันส่งข้อมูล เพื่อกันการเรียกซ้ำแม้ผู้ใช้แตะเร็วหลายครั้งก่อนหน้าจออัปเดต
4. เพิ่มข้อความกำลังบันทึกให้ครบไทย อังกฤษ เกาหลี และจีน โดยใช้ข้อความเดียวกันทุกหน้าที่เกี่ยวข้อง

## สิ่งที่คงเดิม
- ขั้นตอนเช็คอิน, SOP, POD, รับตู้, คืนตู้ และลำดับการนำทางทั้งหมด
- การส่งลายเซ็นไป API แยกแบบไม่บล็อก และ payload เดิมทั้งหมด
- การตรวจรูป, OCR, EIR, งานหลายจุด และ `destination_sequence_number`
- หากบันทึกล้มเหลว ปุ่มกลับมากดได้เพื่อให้ลองใหม่ โดยไม่ล้างข้อมูลหรือรูปที่ผู้ใช้เตรียมไว้

## การตรวจสอบ
- ทดสอบแต่ละหน้าว่าหลังเซ็น modal ปิด ปุ่มหลักแสดงกำลังบันทึกตามภาษาที่เลือก และกดซ้ำไม่ได้
- ทดสอบการแตะยืนยันติดกันอย่างรวดเร็วว่ามีการส่ง flow หลักเพียงครั้งเดียว
- ตรวจกรณีส่งล้มเหลวว่าปุ่มกลับมาใช้งานได้
- รัน typecheck, tests ที่เกี่ยวข้อง และตรวจ build ของ preview
