# แก้หน้าต่างเอกสาร: โหลดใหม่ทุกครั้งที่กด

## ปัญหา

ตอนนี้หน้าต่างเอกสารดึงข้อมูลตอนเปิด แต่ไม่ได้ล้างข้อมูลเก่าตอนปิด — รูปเก่าค้างแสดงระหว่างรอโหลด และไม่การันตีว่าข้อมูลที่เห็นเป็นล่าสุดเสมอ

## การแก้ไข (แตะ 1 ไฟล์)

### `src/components/job/JobDocumentsSheet.tsx`

1. **ล้างข้อมูลตอนปิดหน้าต่าง** — เมื่อ `open` เปลี่ยนเป็น false ให้เคลียร์ `groups`/`failed` ทิ้ง
2. **โหลดใหม่ทุกครั้งที่กด "เอกสาร"** — ทุกครั้งที่เปิดหน้าต่างจะเรียก API ดึงข้อมูลล่าสุดของออเดอร์นั้นใหม่เสมอ ไม่ใช้ข้อมูลค้างจากครั้งก่อน
3. ลบ state `loadedKey` ที่ไม่ได้ใช้ออก

## สิ่งที่ไม่เปลี่ยน

- ยังดึงเฉพาะเอกสารของออเดอร์นั้นจาก API 2 เส้นเดิม — ไม่ดึงของออเดอร์อื่น
- หน้าตา หมวดหมู่ และปุ่มอื่นๆ คงเดิมทั้งหมด
- เรื่องเลขออเดอร์ที่ติด `/NN` ต่อท้าย (ทำให้บางงานดึงเอกสารไม่เจอ) เก็บไว้แก้ทีหลังตามที่สั่ง

## ตรวจสอบหลังแก้

- typecheck + build ผ่าน
- กด "เอกสาร" ปิดแล้วเปิดใหม่ → โหลดข้อมูลใหม่ทุกครั้ง ไม่มีรูปเก่าค้าง
