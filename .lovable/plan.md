# เช็คอินเสร็จ ปิดหน้าต่างทันที ปุ่มเปลี่ยนเลย จออยู่ที่เดิม (งานในประเทศ)

## สิ่งที่คนขับจะเห็น
- กดเช็คอินสำเร็จ หน้าต่างปิดทันที (ไม่รอโหลดอย่างอื่นต่อในหน้าต่าง)
- กลับมาหน้างาน จออยู่ตำแหน่งเดิม ไม่เด้งขึ้นบนสุด
- ปุ่มของจุดที่เพิ่งเช็คอินเปลี่ยนสถานะทันที แล้วระบบดึงข้อมูลล่าสุดเงียบๆ ด้านหลัง

## ไม่เปลี่ยน
- ขั้นตอนเช็คอิน / SOP / POD / COD และข้อมูลที่ส่งไประบบ
- เปิดจากแจ้งเตือน/ลิงก์ตรง ยังเป็นหน้าเต็มเหมือนเดิม

## Technical details
- หน้าเช็คอิน (DeliveryDetailPage และหน้าเช็คอินอื่นที่เปิดในหน้าต่าง): เมื่อเช็คอินสำเร็จ บันทึก optimistic check-in แล้ว navigate กลับ `/job/:id` ทันที (ปิด modal) งานเบื้องหลังที่เหลือทำแบบ non-blocking
- `JobStepRoutes.tsx`: เลิก remount ด้วย `reloadKey` (ต้นเหตุจอเด้งบนสุด/ปุ่มช้า); ตอนปิดให้ dispatch `job-step-closed`
- `DomesticJobDetail.tsx`: ฟัง `job-step-closed` → merge optimistic cache ทันที + silent refetch (ไม่ set loading, ไม่ auto-scroll ซ้ำ)
- ตรวจด้วย Playwright: เลื่อนลงไปจุดส่ง เช็คอิน → หน้าต่างปิดทันที, scrollTop เท่าเดิม, ปุ่มเปลี่ยน
