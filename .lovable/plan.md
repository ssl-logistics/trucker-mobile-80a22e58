# งานต่างประเทศ: สแกน QR ตอนโหลด/ส่งสินค้า

## สรุป flow ที่ยืนยันแล้ว
- **Booking (ขาออก):** จุดรับตู้เปล่า → จุดรับสินค้า → คืนตู้หนักที่ท่า → **สแกน QR ที่จุดรับสินค้า**
- **BL (ขาเข้า):** จุดรับตู้หนัก → จุดส่งสินค้า → คืนตู้เปล่า → **สแกน QR ที่จุดส่งสินค้า**

เช็คอินและแนบหลักฐาน/เอกสารขนส่งยังใช้ flow API เดิมทั้งหมด

## สิ่งที่จะทำ
1. **Booking**: หลังเช็คอินจุดรับสินค้า ปุ่มหลักบนการ์ดเปลี่ยนเป็น "สแกนโหลดสินค้า" (ข้ามได้) แล้วค่อยเป็น "แนบหลักฐาน"
2. **BL**: หลังเช็คอินที่การ์ด "จุดส่งสินค้า" ก่อนเข้าหน้าอัปโหลดเอกสารขนส่ง/ยืนยัน POD ให้สแกน QR ก่อน (ข้ามได้)
3. สแกนสำเร็จ → ยิงเส้น queues/scan ของระบบคิวเหมือนงานในประเทศ (external_ref = เลขออเดอร์, station_token = ค่าจาก QR) แบบไม่รอผล + แถบเขียว "สแกนโหลดสินค้าแล้ว (เวลา)" บนการ์ดนั้น
4. จุดรับตู้เปล่า/ตู้หนักและจุดคืนตู้ไม่มีขั้นสแกน; สถานะสแกนเก็บต่อออเดอร์ในเครื่องเหมือนเดิม

## ไม่เปลี่ยน
- flow เช็คอิน / แนบหลักฐาน / SOP / POD / ลายเซ็น / OCR ของทุกประเภทงาน
- เงื่อนไขล็อกการ์ดตามลำดับขั้นตอนเดิม

## Technical details
- `DomesticJobDetail.tsx`:
  - `needsLoadingQr` (การ์ดจุดรับสินค้า): เปลี่ยนจาก `!job.bl_no && !job.booking_no` เป็น `!job.bl_no`
  - แถบเขียวบนการ์ดจุดรับสินค้า (~2013): เงื่อนไขเดียวกัน
  - การ์ดจุดส่ง (~2045+): เพิ่ม `needsLoadingQrDelivery = !!job.bl_no && isCheckedIn && !isPodCompleted && !loadingQr && !isFromHistory` — ปุ่มหลักเปลี่ยน label เป็น loadingQr.button และเปิด LoadingQrScanDialog แทน navigate; แถบเขียวบนการ์ดจุดส่งเมื่อสแกนแล้ว
  - `handleLoadingQrDone` ใช้ของเดิม (บันทึก localStorage + ยิง qtruck-queue-scan)
- ไม่แตะ edge function หรือ i18n
