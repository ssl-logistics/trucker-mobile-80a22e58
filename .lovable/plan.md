ไม่ต้องแก้แอป รายละเอียดด้านล่างคือเส้น API ที่ใช้อยู่ตอนนี้

**ยืนยันรับตู้ (งานต่างประเทศ)** — เรียกตามลำดับนี้
1. `save-ocr-scan` (POST) ส่งเลขตู้ เลขซีล และผล OCR ถ้าระบบตอบว่าตู้ซ้ำ (409) จะหยุดตรงนี้
2. `driver-checkin` (POST) โดยใช้ `checkin_type: 'container_pickup_confirmed'` ถ้าระบบตอบว่าตู้นี้มีรถคันอื่นรับไปแล้ว แอปจะขึ้นข้อความ "ตู้ซ้ำ" พร้อมทะเบียนรถ
3. ถ้าเป็นงาน BL แอปจะเรียก `notify-container-return-deadline` เพิ่ม เพื่อเตือนวันคืนตู้ ฟังก์ชันนี้อยู่บนระบบของแอปเอง

**ยืนยันคืนตู้**
1. `driver-checkin` (POST) โดยใช้ `checkin_type: 'container_return_confirmed'` ถ้าเรียกไม่สำเร็จ แอปจะทำขั้นต่อไปต่อเลย
2. `save-ocr-scan` (POST) ส่งข้อมูลตอนคืนตู้ คือชื่อลานคืนตู้ และเลข BL หรือ Booking ที่อ่านได้จากใบ EIR ถ้าเรียกไม่สำเร็จ แอปก็ทำต่อเช่นกัน
